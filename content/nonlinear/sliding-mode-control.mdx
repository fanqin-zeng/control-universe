# 滑模控制

## 引言

想象你在滑雪，目标是从山顶滑到山谷的某个指定位置。山坡上有很多不规则的凸起和凹陷（相当于模型不确定性），还有阵风干扰（外部扰动）。如果你只是简单地朝着目标方向滑，很可能被一个小坑带偏，或者被风吹离轨道。

滑模控制（Sliding Mode Control, SMC）的思路完全不同：它在状态空间里"挖"出一条固定的沟渠（称为**切换面**或**滑动面**），无论你从哪里出发，控制器都会用强大的推力把你强行推到这条沟里，然后你只能沿着沟滑到终点。这条沟的设计使得沿它滑动时系统是渐近稳定的。

这种方法的最大优势是**对匹配不确定性的完全鲁棒性**——只要不确定性满足匹配条件（即出现在控制通道中），无论它有多大（只要有界），滑模控制器都能完全抑制它。这在工程上极其珍贵：机器人关节摩擦系数不确定、电机负载转矩波动、航天器转动惯量误差……滑模控制都能应对。

但代价也很明显：为了维持这种鲁棒性，控制律需要在切换面两侧高频切换，导致执行机构不停地快速开关，这种现象称为**抖振**（chattering）。抖振会引起机械磨损、能量损耗、甚至激发未建模动态。因此，滑模控制的工程核心就是在鲁棒性和抖振之间找到平衡。

> 📐 本文用到了Lyapunov稳定性理论和符号函数的概念，详见 [李雅普诺夫稳定性](/nonlinear/lyapunov-stability)。

## 滑模控制的基本概念

### 两阶段机制

滑模控制的工作过程分为两个阶段：

**阶段1：到达阶段（Reaching Phase）**
系统状态从初始位置出发，在切换控制的作用下，在有限时间内到达切换面 s(x) = 0。这个阶段控制量通常很大，目的是快速"捕获"状态。

**阶段2：滑动阶段（Sliding Phase）**
一旦状态到达切换面，控制律切换到等效控制，维持状态在面上滑动，同时降阶系统（sliding mode dynamics）渐近收敛到平衡点。在这个阶段，系统对匹配不确定性完全鲁棒。

### 切换函数与切换面

对于一个 n 阶系统，切换函数 s(x) 通常设计为状态的线性组合：

$$s(x) = c_1 x_1 + c_2 x_2 + \cdots + c_{n-1} x_{n-1} + x_n$$

其中系数 $c_1, c_2, \ldots, c_{n-1}$ 的选择使得多项式 $p^{n-1} + c_{n-1}p^{n-2} + \cdots + c_1$ 是Hurwitz的（所有根在左半平面）。这样当 s(x) = 0 时，降阶系统是渐近稳定的。

**切换面**（Sliding Surface）就是 s(x) = 0 定义的 (n-1) 维超平面。对于二阶系统，切换面是一条直线；对于三阶系统，是一个平面；更高维则是超平面。

### 控制律结构

滑模控制律由两部分组成：

$$u = u_{eq} + u_{sw}$$

- **等效控制** $u_{eq}$：通过令 $\dot{s} = 0$ 解出，作用是维持系统在切换面上滑动
- **切换控制** $u_{sw} = -K \cdot \text{sgn}(s)$：提供足够的控制力把状态推向切换面，K > 0 是切换增益，$\text{sgn}(\cdot)$ 是符号函数

符号函数定义为：

$$\text{sgn}(s) = \begin{cases} 1 & s > 0 \\ 0 & s = 0 \\ -1 & s < 0 \end{cases}$$

## 二阶系统的滑模控制器设计

### 问题描述

考虑二阶非线性系统：

$$\ddot{x} = f(x, \dot{x}) + b(x, \dot{x})u + d(t)$$

其中：
- $x$ 是状态变量
- $u$ 是控制输入
- $f(\cdot)$ 和 $b(\cdot)$ 是已知的光滑函数，且 $b(x, \dot{x}) \neq 0$
- $d(t)$ 是有界扰动，$|d(t)| \leq D$，D 是已知的上界

我们的目标是设计控制律 u，使得系统状态跟踪期望轨迹 $x_d(t)$。

### 步骤1：定义跟踪误差和切换函数

定义跟踪误差：

$$e = x - x_d$$

切换函数设计为：

$$s = \dot{e} + \lambda e$$

其中 $\lambda > 0$ 是设计参数，决定了滑动模态的收敛速度。当 s = 0 时，有 $\dot{e} = -\lambda e$，即误差按指数 $e^{-\lambda t}$ 收敛。

### 步骤2：推导等效控制

对 s 求时间导数：

$$\dot{s} = \ddot{e} + \lambda \dot{e} = \ddot{x} - \ddot{x}_d + \lambda \dot{e}$$

代入系统方程：

$$\dot{s} = f(x, \dot{x}) + b(x, \dot{x})u + d(t) - \ddot{x}_d + \lambda \dot{e}$$

在滑动模态下，s = 0 且 $\dot{s} = 0$。令 $\dot{s} = 0$，解出等效控制：

$$u_{eq} = \frac{1}{b(x, \dot{x})}\left[-f(x, \dot{x}) + \ddot{x}_d - \lambda \dot{e} - d(t)\right]$$

但 $d(t)$ 未知，所以我们无法直接使用这个表达式。解决方案是用切换项来补偿不确定性。

### 步骤3：设计完整控制律

完整控制律为：

$$u = \frac{1}{b(x, \dot{x})}\left[-f(x, \dot{x}) + \ddot{x}_d - \lambda \dot{e}\right] - K \cdot \text{sgn}(s)$$

其中第一项是名义等效控制（不含扰动），第二项是切换控制。

### 步骤4：稳定性证明

构造Lyapunov函数：

$$V = \frac{1}{2}s^2$$

对时间求导：

$$\dot{V} = s\dot{s} = s\left[f + bu + d - \ddot{x}_d + \lambda \dot{e}\right]$$

代入控制律：

$$\dot{V} = s\left[f + b\left(\frac{1}{b}(-f + \ddot{x}_d - \lambda \dot{e}) - K \cdot \text{sgn}(s)\right) + d - \ddot{x}_d + \lambda \dot{e}\right]$$

化简：

$$\dot{V} = s\left[-bK \cdot \text{sgn}(s) + d\right] = -bK|s| + sd$$

由于 $|d| \leq D$，有 $sd \leq |s||d| \leq D|s|$，所以：

$$\dot{V} \leq -(bK - D)|s|$$

**到达条件**：只要选择 $K > D/b$，就有 $\dot{V} \leq -\eta|s|$（其中 $\eta = bK - D > 0$），根据Barbalat引理，s 会在有限时间内收敛到 0。

一旦 s = 0，系统进入滑动模态，此时 $\dot{e} = -\lambda e$，误差指数收敛到 0。

## 手算例子：倒立摆镇定

### 系统建模

考虑倒立摆系统，动力学方程为：

$$ml^2\ddot{\theta} = mgl\sin\theta + u$$

其中：
- $\theta$ 是摆角（垂直向上为 $\theta = 0$）
- $m$ 是质量，$l$ 是杆长
- $g$ 是重力加速度
- $u$ 是施加在摆上的力矩

目标是设计滑模控制器，使倒立摆稳定在垂直向上位置 $\theta = 0$。

### 步骤1：标准化方程

将方程改写为标准形式：

$$\ddot{\theta} = \frac{g}{l}\sin\theta + \frac{1}{ml^2}u$$

对比标准形式 $\ddot{x} = f(x, \dot{x}) + b(x, \dot{x})u$，有：
- $f(\theta, \dot{\theta}) = \frac{g}{l}\sin\theta$
- $b(\theta, \dot{\theta}) = \frac{1}{ml^2}$

### 步骤2：定义切换函数

期望角度 $\theta_d = 0$，所以跟踪误差 $e = \theta - \theta_d = \theta$。

切换函数：

$$s = \dot{e} + \lambda e = \dot{\theta} + \lambda \theta$$

### 步骤3：推导等效控制

对 s 求导：

$$\dot{s} = \ddot{\theta} + \lambda \dot{\theta} = \frac{g}{l}\sin\theta + \frac{1}{ml^2}u + \lambda \dot{\theta}$$

令 $\dot{s} = 0$，解出等效控制：

$$u_{eq} = -ml^2\left(\frac{g}{l}\sin\theta + \lambda \dot{\theta}\right) = -mgl\sin\theta - ml^2\lambda \dot{\theta}$$

### 步骤4：完整控制律

$$u = -mgl\sin\theta - ml^2\lambda \dot{\theta} - K \cdot \text{sgn}(s)$$

其中 $K > 0$ 是切换增益，需要根据扰动上界选择。

### 步骤5：物理意义解释

控制律有三项：
1. **重力补偿项** $-mgl\sin\theta$：抵消重力力矩，使倒立摆在 $\theta = 0$ 附近平衡
2. **阻尼注入项** $-ml^2\lambda \dot{\theta}$：提供虚拟阻尼，加速收敛
3. **鲁棒切换项** $-K \cdot \text{sgn}(s)$：克服模型不确定性和外部扰动

如果存在未建模摩擦或外部扰动，只要它们有界，第三项就能完全抑制它们。

## 抖振现象与抑制策略

### 抖振的成因

理想滑模控制使用符号函数 $\text{sgn}(s)$，在 s = 0 处不连续。这导致控制量在切换面两侧无限快速地切换，称为**抖振**（chattering）。

抖振的危害：
- **机械磨损**：执行机构（电机、舵机、阀门）频繁开关，加速磨损
- **能量损耗**：高频切换消耗额外能量
- **激发未建模动态**：可能激发系统的高频共振模式
- **传感器噪声放大**：切换会放大测量噪声

### 方法1：边界层近似

最常用的方法是用**饱和函数**代替符号函数：

$$\text{sat}\left(\frac{s}{\Phi}\right) = \begin{cases} 1 & s > \Phi \\ s/\Phi & |s| \leq \Phi \\ -1 & s < -\Phi \end{cases}$$

其中 $\Phi > 0$ 是**边界层厚度**。

修改后的控制律：

$$u = u_{eq} - K \cdot \text{sat}\left(\frac{s}{\Phi}\right)$$

**效果分析**：
- 在边界层外（$|s| > \Phi$），控制律与理想滑模相同
- 在边界层内（$|s| \leq \Phi$），控制量线性变化，避免了突变
- 代价：系统不再精确收敛到 s = 0，而是在边界层内振荡，稳态误差约为 $\Phi/\lambda$

**设计权衡**：
- $\Phi$ 越大，抖振越小，但稳态误差越大
- $\Phi$ 越小，精度越高，但抖振越严重
- 典型取值：根据执行机构带宽和传感器分辨率选择，通常在 $10^{-3}$ 到 $10^{-1}$ 之间

### 方法2：双曲正切光滑化

另一种光滑化方法是用双曲正切函数：

$$\tanh\left(\frac{s}{\Phi}\right)$$

性质：
- 连续可微，比饱和函数更光滑
- $\tanh(0) = 0$，$\tanh(\infty) = 1$
- 在 s = 0 附近渐变，避免突变

控制律：

$$u = u_{eq} - K \cdot \tanh\left(\frac{s}{\Phi}\right)$$

### 方法3：高阶滑模控制

**二阶滑模**（Super-Twisting Algorithm）是一种流行的高阶滑模方法，它通过对切换函数积分来消除抖振：

$$\begin{aligned} u &= -\alpha |s|^{1/2}\text{sgn}(s) + v \\ \dot{v} &= -\beta \text{sgn}(s) \end{aligned}$$

其中 $\alpha, \beta > 0$ 是设计参数。

**优点**：
- 不需要边界层近似，理论上无抖振
- 仍保持对匹配不确定性的鲁棒性
- 收敛速度快于一阶滑模

**缺点**：
- 参数整定更复杂
- 需要更高的计算能力

## 到达律方法

除了上述基于等效控制的方法，还可以直接设计 $\dot{s}$ 的动态，称为**到达律**（Reaching Law）。

### 常数速率到达律

$$\dot{s} = -\eta \cdot \text{sgn}(s)$$

其中 $\eta > 0$ 是常数。积分得 $s(t) = s(0) - \eta \int_0^t \text{sgn}(s)d\tau$，到达时间 $t_r = |s(0)|/\eta$。

对应的控制律通过令 $\dot{s} = -\eta \cdot \text{sgn}(s)$ 解出：

$$u = \frac{1}{b}\left[-f + \ddot{x}_d - \lambda \dot{e} - \eta \cdot \text{sgn}(s)\right]$$

这与之前的形式相同，只是 $K = \eta/b$。

### 指数到达律

$$\dot{s} = -\eta s - \epsilon \cdot \text{sgn}(s)$$

其中 $\eta, \epsilon > 0$。第一项提供指数收敛，第二项保证有限时间到达。

**优点**：
- 远离切换面时（$|s|$ 大），$-\eta s$ 主导，快速接近
- 靠近切换面时（$|s|$ 小），$-\epsilon \cdot \text{sgn}(s)$ 主导，保证有限时间到达
- 比常数速率更快

### 幂速率到达律

$$\dot{s} = -\eta |s|^\alpha \cdot \text{sgn}(s)$$

其中 $\eta > 0$，$0 < \alpha < 1$。

**特点**：
- $\alpha = 1/2$ 时，对应超螺旋算法的基础形式
- 收敛速度介于线性和有限时间之间
- 可以通过调整 $\alpha$ 平衡速度和抖振

## 匹配与不匹配不确定性

### 匹配不确定性

**定义**：不确定性出现在控制通道中，即与控制输入 u 乘以相同的函数 $b(x)$。

一般形式：

$$\dot{x} = f(x) + b(x)[u + d(t)]$$

其中 $d(t)$ 是匹配扰动。

**关键性质**：滑模控制对匹配不确定性有**完全鲁棒性**。只要 $|d(t)| \leq D$ 且切换增益 $K > D$，扰动就能被完全抑制。

**物理解释**：因为扰动和控制输入作用在同一个通道上，切换控制可以直接抵消它。

### 不匹配不确定性

**定义**：不确定性不出现在控制通道中，例如：

$$\dot{x} = f(x) + \Delta f(x) + b(x)u$$

其中 $\Delta f(x)$ 是不匹配扰动。

**关键性质**：滑模控制对不匹配不确定性**没有完全鲁棒性**。切换控制无法直接抵消它，只能通过增大切换增益来减小影响，但不能完全消除。

**处理方法**：
1. **增大切换增益**：$K > |\Delta f(x)/b(x)|$，但会加剧抖振
2. **自适应滑模**：在线估计不确定性上界，动态调整 K
3. **结合其他方法**：如扰动观测器、神经网络逼近等

### 例子对比

**匹配扰动例子**：电机转矩控制
$$J\ddot{\theta} + B\dot{\theta} = u + d(t)$$
其中 $d(t)$ 是负载转矩扰动。改写为：
$$\ddot{\theta} = -\frac{B}{J}\dot{\theta} + \frac{1}{J}[u + d(t)]$$
扰动 $d(t)$ 与控制输入 u 都乘以 $1/J$，是匹配扰动，滑模控制可完全抑制。

**不匹配扰动例子**：质量变化的倒立摆
$$ml^2\ddot{\theta} = mgl\sin\theta + u$$
如果质量 m 不确定，设真实质量为 $m + \Delta m$，则：
$$(m+\Delta m)l^2\ddot{\theta} = (m+\Delta m)gl\sin\theta + u$$
展开后，$\Delta m$ 出现在多个位置，不是简单的匹配形式，滑模控制不能完全消除其影响。

## 应用案例

### 案例1：直流电机位置控制

#### 系统建模

直流电机的运动方程为：

$$J\ddot{\theta} + B\dot{\theta} = K_t u - T_L$$

其中：
- $\theta$ 是转子角度
- $J$ 是转动惯量（不确定，标称值 $J_0$）
- $B$ 是粘性摩擦系数
- $K_t$ 是转矩常数
- $u$ 是电枢电压
- $T_L$ 是负载转矩（外部扰动）

目标是跟踪期望角度 $\theta_d(t)$。

#### 滑模控制器设计

**步骤1：定义误差和切换函数**

$$e = \theta - \theta_d$$
$$s = \dot{e} + \lambda e$$

**步骤2：推导控制律**

系统方程改写为：

$$\ddot{\theta} = -\frac{B}{J}\dot{\theta} + \frac{K_t}{J}u - \frac{T_L}{J}$$

令 $f = -\frac{B}{J}\dot{\theta}$，$b = \frac{K_t}{J}$，$d = -\frac{T_L}{J}$。

等效控制（名义部分）：

$$u_{eq} = \frac{J_0}{K_t}\left[\frac{B}{J_0}\dot{\theta} + \ddot{\theta}_d - \lambda \dot{e}\right]$$

完整控制律：

$$u = u_{eq} - K \cdot \text{sat}\left(\frac{s}{\Phi}\right)$$

**步骤3：参数选择**

假设：
- $J_0 = 0.01$ kg·m²，实际 $J \in [0.009, 0.011]$
- $B = 0.1$ N·m·s/rad
- $K_t = 0.5$ N·m/A
- $|T_L| \leq 0.2$ N·m
- $\lambda = 10$，$\Phi = 0.01$，$K = 5$

### 案例2：航天器姿态控制

#### 问题描述

卫星姿态动力学方程为：

$$J\dot{\omega} + \omega \times (J\omega) = \tau + d(t)$$

其中：
- $J$ 是转动惯量矩阵（3×3，有不确定性）
- $\omega$ 是角速度向量
- $\tau$ 是控制力矩（来自反作用轮或推力器）
- $d(t)$ 是外部扰动（地磁力矩、大气阻力、太阳辐射压）

目标是使姿态角 $\theta$ 跟踪期望轨迹 $\theta_d(t)$。

#### 滑模控制器设计

为简化，考虑单轴旋转（绕z轴）：

$$J_z\dot{\omega}_z = \tau_z + d_z(t)$$

其中 $J_z$ 有±10%的不确定性，$|d_z(t)| \leq 0.01$ N·m。

**切换函数**：

$$s = \omega_z - \omega_{z,d} + \lambda(\theta_z - \theta_{z,d})$$

**控制律**：

$$\tau_z = -K \cdot \text{sgn}(s)$$

选择 $K > 0.01$ 以保证鲁棒性。

**仿真结果**（略，见JupyterNotebook）：即使转动惯量误差达20%，外部扰动持续存在，滑模控制仍能保证姿态角在30秒内稳定到±0.1°以内，而传统PID在同样条件下会发散。

### 案例3：机器人关节控制

#### 背景

工业机器人关节通常采用交流伺服电机驱动，动力学方程为：

$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = \tau - \tau_f - \tau_d$$

其中：
- $q$ 是关节角度向量
- $M(q)$ 是惯性矩阵（依赖于构型）
- $C(q, \dot{q})$ 是Coriolis和离心力矩阵
- $G(q)$ 是重力项
- $\tau$ 是电机转矩
- $\tau_f$ 是摩擦转矩（不确定，包括库仑摩擦和粘性摩擦）
- $\tau_d$ 是外部扰动（如接触力）

#### 滑模控制器设计

对于单关节，简化为：

$$M\ddot{q} + C\dot{q} + G = \tau - \tau_f - \tau_d$$

**切换函数**：

$$s = \dot{e} + \lambda e, \quad e = q - q_d$$

**控制律**：

$$\tau = M(\ddot{q}_d - \lambda \dot{e}) + C\dot{q} + G - K \cdot \text{sat}\left(\frac{s}{\Phi}\right)$$

前三项是计算力矩控制（Computed Torque Control），最后一项是滑模鲁棒项，用于补偿摩擦和扰动。

**工程实践**：
- 摩擦模型通常不准确，滑模控制能有效补偿未建模摩擦
- 切换增益 K 需要根据摩擦上界选择，过大引起抖振，过小无法完全补偿
- 实际机器人控制器（如ABB、KUKA）常采用滑模或类似鲁棒控制方法

## 与其他非线性控制方法的对比

### 滑模控制 vs 反馈线性化

| 特性 | 滑模控制 | 反馈线性化 |
|------|---------|-----------|
| **线性化方式** | 不线性化，直接在非线性系统上设计 | 通过坐标变换和非线性反馈精确线性化 |
| **鲁棒性** | 对匹配不确定性完全鲁棒 | 对模型误差敏感，需要精确模型 |
| **控制连续性** | 不连续（需边界层光滑化） | 连续 |
| **抖振** | 存在，需抑制 | 无 |
| **适用场景** | 模型不确定、扰动大的系统 | 模型精确、需要高精度的系统 |
| **设计复杂度** | 中等（主要是切换面和增益选择） | 较高（需要计算Lie导数和坐标变换） |

### 滑模控制 vs Lyapunov直接法

| 特性 | 滑模控制 | Lyapunov直接法 |
|------|---------|---------------|
| **设计思路** | 先设计切换面，再设计控制律使状态到达面 | 直接构造Lyapunov函数，设计控制律使 Ṽ < 0 |
| **系统性** | 有系统化设计流程 | 依赖经验，无通用构造方法 |
| **鲁棒性** | 对匹配不确定性完全鲁棒 | 取决于Lyapunov函数选择，不一定有鲁棒性 |
| **适用范围** | 主要适用于相对阶为1的系统 | 适用于任何能构造Lyapunov函数的系统 |

### 滑模控制 vs 自适应控制

| 特性 | 滑模控制 | 自适应控制 |
|------|---------|-----------|
| **不确定性处理** | 假设有界，用高增益抑制 | 在线估计参数，动态调整控制律 |
| **收敛速度** | 有限时间到达，快速 | 通常渐近收敛，较慢 |
| **参数知识** | 只需知道不确定性上界 | 需要知道参数化形式 |
| **抖振** | 存在 | 无（控制律连续） |
| **计算复杂度** | 低 | 高（需要在线参数更新） |

## 局限性讨论

### 1. 抖振问题

尽管有边界层、高阶滑模等抑制方法，抖振仍然是滑模控制的主要缺陷。对于精密加工、光学系统等对振动敏感的应用，滑模控制可能不适用。

### 2. 匹配条件限制

滑模控制只对匹配不确定性有完全鲁棒性。对于不匹配不确定性（如参数变化出现在非控制通道），只能通过增大增益来减小影响，不能完全消除。

### 3. 需要全状态反馈

滑模控制器通常需要测量所有状态变量（如位置和速度）。如果某些状态不可测，需要设计观测器，增加了复杂度。

### 4. 切换增益整定困难

切换增益 K 需要大于不确定性上界，但这个上界往往未知。选择过大会加剧抖振，过小则失去鲁棒性。自适应滑模可以在线估计上界，但增加了算法复杂度。

### 5. 采样频率要求

数字实现时，采样频率必须足够高，否则离散化会让系统无法精确保持在切换面上。一般要求采样频率至少是系统带宽的10倍以上。

## 小结

滑模控制是一种经典的非线性鲁棒控制方法，核心思想是：

1. **两阶段机制**：到达阶段（有限时间到达切换面）+ 滑动阶段（沿面滑动到平衡点）
2. **切换面设计**：通常为状态的线性组合 $s = \dot{e} + \lambda e$，保证滑动模态稳定
3. **控制律结构**：等效控制 $u_{eq}$（维持滑动）+ 切换控制 $-K \cdot \text{sgn}(s)$（提供鲁棒性）
4. **稳定性证明**：用Lyapunov直接法，构造 $V = \frac{1}{2}s^2$，证明 $\dot{V} \leq -\eta|s|$
5. **抖振抑制**：边界层方法（饱和函数）、双曲正切光滑化、高阶滑模（超螺旋算法）
6. **到达律方法**：常数速率、指数速率、幂速率，提供不同的收敛特性
7. **匹配vs不匹配**：滑模控制对匹配不确定性完全鲁棒，对不匹配不确定性只能部分抑制

**工程应用要点**：
- 倒立摆、电机控制、航天器姿态、机器人关节等场景广泛应用
- 边界层厚度 $\Phi$ 需在抖振和精度之间权衡
- 切换增益 K 需根据扰动上界选择，过大引起抖振，过小失去鲁棒性
- 数字实现时采样频率要足够高

**与其他方法对比**：
- 比反馈线性化更鲁棒，但有抖振
- 比Lyapunov直接法更有系统性，但适用范围稍窄
- 比自适应控制收敛更快，但需要知道不确定性上界

**答案1：切换函数设计**

(a) 跟踪误差 $e = x - x_d$。要求时间常数 $\tau = 0.2$ s，即 $\lambda = 1/\tau = 5$。

切换函数：
$$s = \dot{e} + 5e$$

(b) 系统方程：$\ddot{x} = -2\dot{x} - x + u + d(t)$

对 s 求导：
$$\dot{s} = \ddot{e} + 5\dot{e} = \ddot{x} - \ddot{x}_d + 5\dot{e}$$

代入系统方程：
$$\dot{s} = -2\dot{x} - x + u + d - \ddot{x}_d + 5\dot{e}$$

令 $\dot{s} = 0$，解出等效控制：
$$u_{eq} = 2\dot{x} + x + \ddot{x}_d - 5\dot{e} - d$$

去掉未知扰动 d，名义等效控制：
$$u_{eq} = 2\dot{x} + x + \ddot{x}_d - 5\dot{e}$$

(c) 完整控制律：
$$u = u_{eq} - K \cdot \text{sgn}(s)$$

Lyapunov分析：
$$\dot{V} = s\dot{s} = s(-2\dot{x} - x + u + d - \ddot{x}_d + 5\dot{e})$$

代入控制律：
$$\dot{V} = s(-K \cdot \text{sgn}(s) + d) = -K|s| + sd$$

由于 $|d| \leq 0.5$，有 $sd \leq 0.5|s|$，所以：
$$\dot{V} \leq -(K - 0.5)|s|$$

到达条件：$K > 0.5$，取 $K = 1$ 即可。

**答案2：倒立摆滑模控制**

**答案3：稳定性证明**

(a) Lyapunov函数：
$$V = \frac{1}{2}s^2$$

显然 $V \geq 0$，且 $V = 0$ 当且仅当 $s = 0$。

(b) 对时间求导：
$$\dot{V} = s\dot{s}$$

由前面推导：
$$\dot{s} = f + bu + d - \ddot{x}_d + \lambda \dot{e}$$

代入控制律 $u = u_{eq} - K \cdot \text{sgn}(s)$，其中 $u_{eq} = \frac{1}{b}(-f + \ddot{x}_d - \lambda \dot{e})$：

$$\dot{s} = f + b\left[\frac{1}{b}(-f + \ddot{x}_d - \lambda \dot{e}) - K \cdot \text{sgn}(s)\right] + d - \ddot{x}_d + \lambda \dot{e}$$

化简：
$$\dot{s} = -bK \cdot \text{sgn}(s) + d$$

所以：
$$\dot{V} = s(-bK \cdot \text{sgn}(s) + d) = -bK|s| + sd$$

由于 $|d| \leq D$，有 $sd \leq |s||d| \leq D|s|$，所以：
$$\dot{V} \leq -bK|s| + D|s| = -(bK - D)|s|$$

当 $K > D/b$ 时，令 $\eta = bK - D > 0$，有：
$$\dot{V} \leq -\eta|s|$$

(c) 这保证了：
- **到达性**：$\dot{V} < 0$ 说明 V 单调递减，s 会收敛到 0
- **有限时间到达**：由于 $\dot{V} \leq -\eta|s| = -\eta\sqrt{2V}$，积分可得到达时间 $t_r \leq \frac{|s(0)|}{\eta}$
- **滑动模态稳定性**：一旦 s = 0，系统进入滑动模态，$\dot{e} = -\lambda e$，误差指数收敛

**答案4：边界层分析**

(a) 边界层内（$|s| \leq \Phi$），控制律为：
$$u = u_{eq} - K \cdot \frac{s}{\Phi}$$

代入 $\dot{s}$ 的表达式：
$$\dot{s} = -bK \cdot \frac{s}{\Phi} + d$$

忽略扰动 d（最坏情况），有：
$$\dot{s} = -\frac{bK}{\Phi}s$$

这是一阶线性系统，s 指数收敛到 0，时间常数 $\tau = \Phi/(bK)$。

(b) 在滑动模态下，$s = \dot{e} + \lambda e = 0$，即 $\dot{e} = -\lambda e$。

但在边界层内，s 不严格为 0，而是 $|s| \leq \Phi$。稳态时，$\dot{e} \approx 0$，所以：
$$\lambda e_{ss} \approx s \Rightarrow |e_{ss}| \approx \frac{|s|}{\lambda} \leq \frac{\Phi}{\lambda}$$

因此稳态误差约为 $\Phi/\lambda$。

(c) 要求 $|e_{ss}| < 0.01$，$\lambda = 10$，则：
$$\frac{\Phi}{10} < 0.01 \Rightarrow \Phi < 0.1$$

所以 $\Phi$ 的最大值为 0.1。但要注意，$\Phi$ 越小，抖振越严重，需要在精度和抖振之间权衡。

**答案5：匹配与不匹配不确定性**

系统方程：
$$\ddot{x} + (a + \Delta a)\dot{x} + (b + \Delta b)x = (c + \Delta c)u + d(t)$$

改写为标准形式：
$$\ddot{x} = -(a + \Delta a)\dot{x} - (b + \Delta b)x + (c + \Delta c)u + d(t)$$

(a) **匹配不确定性**：
- $\Delta c$：出现在控制通道中，与控制输入 u 乘以相同的位置
- $d(t)$：外部扰动，也出现在控制通道中

**不匹配不确定性**：
- $\Delta a$：出现在 $\dot{x}$ 的系数中，不在控制通道
- $\Delta b$：出现在 x 的系数中，不在控制通道

判断方法：如果不确定性可以写成 $b(x) \cdot \delta(t)$ 的形式（即与控制输入乘以相同的函数），则是匹配的；否则是不匹配的。

(b) 对于匹配不确定性（$\Delta c$ 和 $d(t)$），滑模控制**能完全抑制**，只要切换增益 $K > |\Delta c \cdot u + d(t)|/c$ 的上界。

具体来说，等效控制基于标称模型 $c$，实际系统有 $(c + \Delta c)$，差值由切换项补偿。只要 $K$ 足够大，就能保证 $\dot{V} < 0$。

(c) 对于不匹配不确定性（$\Delta a$ 和 $\Delta b$），滑模控制**不能完全消除**其影响。处理方法包括：

1. **增大切换增益**：
   $$K > \frac{1}{c}|\Delta a \cdot \dot{x} + \Delta b \cdot x|$$
   但这会加剧抖振，且需要知道不确定性上界。

2. **自适应滑模**：
   在线估计 $\Delta a$ 和 $\Delta b$ 的上界，动态调整 K：
   $$\dot{\hat{D}} = \gamma |s|, \quad K = \hat{D} + \epsilon$$
   其中 $\gamma > 0$ 是自适应增益，$\epsilon > 0$ 是安全裕度。

3. **扰动观测器**：
   设计观测器估计不匹配扰动 $\hat{d}_{mismatch}$，然后在控制律中补偿：
   $$u = u_{eq} - K \cdot \text{sgn}(s) - \frac{1}{c}\hat{d}_{mismatch}$$

4. **结合其他方法**：
   - 神经网络/模糊逻辑逼近不确定性
   - H∞ 控制处理不匹配扰动
   - 复合控制：滑模 + 自适应 + 观测器

**工程建议**：如果系统中存在显著的不匹配不确定性，纯滑模控制可能不够，需要结合自适应控制或扰动观测器。
