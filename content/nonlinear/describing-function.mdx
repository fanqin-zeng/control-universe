# 描述函数法

## 引言

一台伺服轴在小指令下安静听话，把指令幅值调大一倍，它就开始以固定频率持续振荡——关掉指令也不停。工程师的第一反应是"环路增益太高"，于是降增益：振荡消失了，但跟踪变慢、刚度变差。再调回去，振荡又回来。**这个"只在大幅度时出现"的振荡，就是非线性环节（放大器饱和）与线性环路共同产生的极限环**，而描述函数法是能在纸上预测它的振幅和频率的最便宜工具。

它的想法只有一句话：**给非线性环节喂一个正弦 $u = A\sin\omega t$，只取输出里的基波，把"基波输出 / 输入"当作一个增益 $N(A)$**。此后整个非线性环路就被当作一个"增益随振幅变化的线性环路"，用 Nyquist 的语言讨论 $N(A)G(j\omega) = -1$。

这个近似好不好，不取决于信仰，取决于线性部分把高次谐波滤掉了多少。本课把五个环路全部仿真出来，用**实测的谐波泄漏指标 $L$、闭环信号 THD、以及预测幅值的误差**给这个方法定价：

| 线性部分 $G(s)$（与继电器/滞环继电器串联） | 谐波泄漏 $L$ | 实测闭环 THD | 预测幅值误差 |
| --- | --- | --- | --- |
| $\dfrac{1}{s(s+1)(0.5s+1)}$，理想继电器 | $-31.2$ dB | $0.024$ | $+4.9\%$ |
| $\dfrac{1}{s(s+1)(0.05s+1)}$，理想继电器 | $-27.9$ dB | $0.033$ | $+10.6\%$ |
| $\dfrac{2}{s(s+1)}$，滞环继电器 $h=0.2$ | $-25.4$ dB | $0.041$ | $-1.2\%$ |
| $\dfrac{2}{s(s+1)(0.1s+1)}$，滞环继电器 $h=0.2$ | $-26.6$ dB | $0.038$ | $+3.0\%$ |
| $G_3(s)\times$ 三次谐波谐振峰（$\zeta=0.02$） | $-7.6$ dB | $0.113$ | $+18.1\%$ |

（$L \triangleq \sum_{n=3,5,\ldots}\lvert G(jn\omega_0)\rvert/n \big/ \lvert G(j\omega_0)\rvert$，即"高次谐波经环路漏回来的总量"；$L$ 由 Notebook 3 与 Notebook 6 打印，幅值误差分别由 Notebook 3（第 1、2 行）、Notebook 5（第 3、4 行）、Notebook 6（第 5 行）实测。）读法：**$L$ 低于 $-25$ dB 时，描述函数是一个"误差几个百分点"的工程近似；$L$ 到 $-7.6$ dB 时它已经不可用。** 而 $-20$ dB 的经验门槛只是筛查，不是保证——第二行踩在门槛上，误差就有 $10.6\%$。

本课的每个公式都配一个数值核对：描述函数的闭式对傅里叶积分核到 $10^{-9}$（光滑情形）或 $10^{-4}$（含跳变情形），极限环的预测对仿真核到百分之几。**预测与实测的差距本身就是本课的内容**，不是瑕疵。

> 📐 本文用到傅里叶级数与 Nyquist 稳定判据，详见 [频域分析](/classic/frequency-domain-analysis) 与 [复数基础](/math/complex-numbers)。

## 描述函数的定义与滤波假设

考虑**静态**非线性 $y = f(u)$（输出只依赖当前输入；含滞环/间隙的"多值"非线性见第 3 节，它们带记忆但仍用同一套定义）。输入 $u(t) = A\sin\omega t$，输出是周期函数，展开为

$$
y(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\big[a_n\cos(n\omega t) + b_n\sin(n\omega t)\big]
$$

$$
a_n = \frac{1}{\pi}\int_0^{2\pi} f(A\sin\theta)\cos(n\theta)\,\mathrm{d}\theta, \qquad
b_n = \frac{1}{\pi}\int_0^{2\pi} f(A\sin\theta)\sin(n\theta)\,\mathrm{d}\theta
$$

**描述函数**定义为基波输出与正弦输入的复数比。因为输入是 $\sin$（不是 $\cos$），把基波写成 $y_1 = A\lvert N\rvert\sin(\omega t + \varphi)$ 对比系数得 $b_1 = A\lvert N\rvert\cos\varphi$、$a_1 = A\lvert N\rvert\sin\varphi$，所以

$$
N(A) = \frac{b_1 + j a_1}{A} = \lvert N(A)\rvert e^{j\varphi}
$$

**这个 $b_1 + ja_1$ 的顺序很容易写反**（写成 $a_1 + jb_1$ 会把实虚部互换）。Notebook 1 用带滞环的继电器当场核对：数值积分给出 $(b_1+ja_1)/A = 1.214607 - 0.381927j$，与闭式 $\frac{4M}{\pi A}\big(\sqrt{1-(h/A)^2} - j\,h/A\big) = 1.214593 - 0.381972j$ 相差 $4.7\times10^{-5}$；而写反顺序得到的 $(a_1+jb_1)/A = -0.381927 + 1.214607j$，与闭式差 $2.26$——实虚部整个调了个位置，相位从滞后 $17.5^\circ$ 变成超前 $107.5^\circ$，稳定性判据会跟着全错。

三条结构性事实：

- **奇对称非线性**（$f(-u) = -f(u)$）的所有 $a_n = 0$，故 $N(A) = b_1/A$ 是**实数**——它只改增益不改相位。继电器、饱和、死区都属于这一类。
- **带记忆的非线性**（滞环、间隙）$a_1 \ne 0$，$N(A)$ 是复数，虚部为负代表相位滞后。
- $N$ **只依赖 $A$ 不依赖 $\omega$**（静态非线性的尺度性质）；而这里的 $A$ 是**非线性环节输入端**的正弦幅值，不是系统输出的幅值——手算时搞错这一点，预测的振幅就会差一个 $\lvert G(j\omega)\rvert$ 倍。

**滤波假设**：把 $y$ 的高次谐波全部丢掉，只留基波。理由是闭环里谐波要先经过 $G(s)$：若 $\lvert G(jn\omega)\rvert \ll \lvert G(j\omega)\rvert$（$n \ge 3$），漏回来的谐波不足以改变非线性环节输入"近似正弦"这件事。定量筛查常用 $\lvert G(j3\omega)\rvert < 0.1\lvert G(j\omega)\rvert$；更完整的指标是引言里的 $L$。但请注意 Notebook 1 的一个实测：**饱和在 $A = 2$ 时自己就产生 $22.6\%$ 的三次谐波**（各次谐波幅值 $1.2180,\ 0,\ 0.2757,\ 0,\ 0.0551,\ \ldots$）——谐波是非线性环节必然制造的，方法成不成立完全看 $G$ 滤不滤得掉。

## 常见非线性的描述函数

五个最常用的闭式（$A$ 为环节输入幅值；$\alpha = \arcsin(a/A)$、$\beta = \arcsin(1 - 2b/A)$）：

| 非线性 | 描述函数 $N(A)$ | 性质 |
| --- | --- | --- |
| 理想继电器 $\pm M$ | $\dfrac{4M}{\pi A}$ | 实数，随 $A$ 衰减 |
| 滞环继电器 $\pm M$，宽 $\pm h$ | $\dfrac{4M}{\pi A}\Big(\sqrt{1-(h/A)^2} - j\dfrac{h}{A}\Big)$，$A>h$ | 复数，虚部 $<0$ |
| 饱和 $k$，限 $\pm a$ | $A\le a$ 时 $k$；否则 $\dfrac{2k}{\pi}\big[\alpha + \sin\alpha\cos\alpha\big]$ | 实数，单调减 |
| 死区 $k$，宽 $\pm a$ | $A<a$ 时 $0$；否则 $\dfrac{2k}{\pi}\big[\dfrac{\pi}{2} - \alpha - \sin\alpha\cos\alpha\big]$ | 实数，单调增 |
| 间隙 $k$，宽 $\pm b$ | $\dfrac{k}{\pi}\big[\dfrac{\pi}{2} + \beta + \sin\beta\cos\beta - j\,4\dfrac{b}{A}\big(1-\dfrac{b}{A}\big)\big]$ | 复数，虚部 $<0$ |

Notebook 2 把每个闭式与 40000 点傅里叶积分在 $A\in[0.4,6]$ 的 60 个点上逐点相减：饱和与死区的最大偏差 $9.9\times10^{-10}$、$8.0\times10^{-10}$（被积函数连续，梯形法则谱精度）；理想继电器与滞环继电器 $1.3\times10^{-4}$、$2.2\times10^{-4}$（输出有跳变，收敛退化为 $O(h)$）；间隙的闭式在 $A=1,2,5$ 上与数值积分逐位相同（$0.747684-0.267380j$、$0.905940-0.162338j$、$0.975504-0.071811j$）。**这张表不是抄来的，是核过的。**

一个必须当场拆穿的省事做法：**串联非线性的描述函数不等于各环节描述函数的乘积**。理由很简单：第一个环节的输出已经不是正弦，第二个环节的 DF 公式前提失效。Notebook 2 用"死区(0.3) 串饱和(1)"实测：$A\le1$ 时饱和未起作用，乘积碰巧精确相等（相对差 $0.0\%$）；$A=1.5$ 起开始偏离，$A=1.5$ 处相对差 $15.4\%$、$A=2$ 处 $14.2\%$、$A=5$ 处 $6.9\%$。两个都是静态环节时，正确做法是把组合映射 $f_2(f_1(u))$ 当成**一个**静态非线性直接做傅里叶积分。

## 谐波平衡与极限环预测

闭环结构：非线性 $f$ 在前、线性 $G(s)$ 在后、单位负反馈、无外部输入。假设环路已进入周期状态，非线性环节输入为 $e(t) = A\sin\omega t$，则其基波输出经 $G$ 回到输入端必须**自洽**：

$$
N(A)\,G(j\omega) = -1 \qquad\Longleftrightarrow\qquad G(j\omega) = -\frac{1}{N(A)}
$$

这就是**谐波平衡条件**。几何读法：在 Nyquist 图上画两条曲线——$G(j\omega)$（$\omega$ 从 $0$ 到 $\infty$）和 $-1/N(A)$（$A$ 从 $0$ 到 $\infty$）——交点给出 $(A,\omega)$。**注意 $-1/N(A)$ 轨迹的方向**：对理想继电器 $-1/N = -\pi A/(4M)$，$A\to0^+$ 时它从原点出发，$A$ 增大时**向 $-\infty$ 走**；对饱和它从 $-1/k$ 出发同样向左走。方向搞反会把第 5 节的稳定性判据整个读反。

**手算例**：理想继电器 $M=1$ 串 $G(s) = \dfrac{1}{s(s+1)(0.5s+1)}$。$N$ 为实数，故交点必须落在 $G$ 的负实轴穿越点上：

$$
(j\omega)(j\omega+1)(0.5j\omega+1) = -1.5\omega^2 + j(\omega - 0.5\omega^3)
$$

虚部为零给出 $\omega_0 = \sqrt{2} = 1.414214$ rad/s（**不是** $\omega=1$：把 $0.5j\omega\cdot j\omega$ 漏掉系数是这一步最常见的错误），此时 $G(j\omega_0) = 1/(-1.5\omega_0^2) = -1/3$。由 $-\pi A/4 = -1/3$ 得

$$
A_0 = \frac{4}{3\pi} = 0.424413
$$

即非线性环节**输入端**的基波幅值预测为 $0.4244$。Notebook 3 用 dt = 1e-4 仿真 80 s 并对末段做整周期傅里叶：实测基波幅值 $0.445089$（比预测大 $4.87\%$），周期 $4.550400$ s（预测 $2\pi/\sqrt2 = 4.442883$ s，差 $2.42\%$），闭环信号 THD $0.0237$。**这几个百分点就是基波近似的定价**：被丢掉的三次谐波仍会把继电器的切换时刻稍微推离正弦假设的位置。

同一个 Notebook 还跑了第二个环路：把 $0.5s+1$ 换成 $0.05s+1$（第三个极点从 $2$ rad/s 推到 $20$ rad/s）。这时 $\omega_0 = \sqrt{1/0.05} = \sqrt{20} = 4.472136$，$G(j\omega_0) = -0.05/1.05 = -0.047619$，$A_0 = 0.060630$；实测基波 $0.067046$（$+10.58\%$），周期 $1.477600$ s（$+5.17\%$），THD $0.0332$。**极点推远了，误差反而从 $4.9\%$ 涨到 $10.6\%$**——因为 $\omega_0 = \sqrt{1/T_c}$ 跟着涨了 $3.16$ 倍，三倍频 $3\omega_0$ 与极点的相对距离并没有拉开（泄漏指标 $L$ 只从 $-31.2$ dB 变到 $-27.9$ dB，是变差不是变好）。这条反直觉的实测在第 7 节还会再用到：**要让描述函数准，得让 $\omega_0$ 远离所有极点零点，而不是把极点推远。**

## 极限环的稳定性判据

交点只说明"谐波平衡在该点成立"，不说明极限环稳定。判据（Loeb 判据的 Nyquist 读法）：**在交点处把 $A$ 稍微增大，看 $-1/N(A)$ 的新位置是否落在 $G$ 的 Nyquist 曲线"不包围"的一侧**——

- 若 $A\uparrow$ 使 $-1/N$ 进入**不被包围**（等效线性环稳定）的区域，振幅会被压回来 → **稳定极限环**；
- 若进入**被包围**（等效线性环不稳定）的区域，振幅继续增长 → **不稳定极限环**。

用等效增益的语言更直接：把 $N(A)$ 当作环路增益 $K$，用线性判据（本例 Routh：$0.5s^3+1.5s^2+s+K$ 稳定当且仅当 $K<3$）检查该增益下闭环是否稳定。Notebook 4 先做这个交叉核对：$K=2.9$ 时三个极点实部全负，$K=3.1$ 时出现正实部极点——与 Routh 的 $K<3$ 一致。

**双交点算例**（死区 $0.3$ 串饱和，再串 $K\cdot G_3$，$K=7.0302$）：组合 $N(A)$ 先升后降（峰值 $0.711220$ 在 $A=1.331$），水平线 $N = 3/K = 0.426732$ 与它交于两点 $A_1 = 0.6569$（升支）与 $A_2 = 2.8348$（降支）。升支上 $A\uparrow \Rightarrow N\uparrow \Rightarrow$ 等效增益更接近不稳定侧 → $A_1$ **不稳定**；降支相反 → $A_2$ **稳定**。仿真（dt = 5e-4）逐条验证：

| 初值 $e(0)$ | 结局 |
| --- | --- |

## 应用案例

描述函数有三种用法，三个案例各占一种：**正向预测**（给系统算振荡参数）、**诊断**（判断某个增益下会不会振荡）、**反推设计**（给振荡指标解出元件参数）。三个案例的预测与实测误差全部汇总在 Notebook 5 的最后一格。

### 案例 1：滞环继电器自激振荡器（温控器 / 滞环电流调制）

继电器加滞环是恒温器和滞环电流调制器（hysteresis current-mode control）的标准结构：滞环宽度决定开关频率，继电器幅值决定输出幅值。工程上需要在**不搭仿真**的情况下回答"这个滞环宽度会把开关频率定在哪里"，这正是描述函数的主场。

环路：滞环继电器（$M=1$，$h=0.2$）串 $G(s) = \dfrac{2}{s(s+1)}$，单位负反馈。这个例子的好处是谐波平衡可以**闭式求解**。记 $r = h/A$、$c = 4M/(\pi A)$，则 $N = c(\sqrt{1-r^2} - jr)$，而 $G(j\omega) = -a - jb$ 中 $a = K/(\omega^2+1)$、$b = a/\omega$。把 $NG = -1$ 分成实虚两部（推导见习题 2）：

$$
\omega = \frac{\sqrt{1-r^2}}{r}, \qquad 4MKr^3 = \pi h\sqrt{1-r^2}
$$

第二式只含 $r$，一维求根即可。Notebook 5 用 `brentq` 解出三个滞环宽度，残差都在 $10^{-16}$ 量级：

| $h$ | $A$ | $\omega$ (rad/s) | $f$ (Hz) | $L$ |
| --- | --- | --- | --- | --- |
| $0.10$ | $0.300034$ | $2.828785$ | $0.450215$ | $-25.7$ dB |
| $0.20$ | $0.481962$ | $2.192528$ | $0.348952$ | $-25.4$ dB |
| $0.40$ | $0.780020$ | $1.674126$ | $0.266445$ | $-25.0$ dB |

**滞环越宽，开关频率越低、振幅越大**——这就是滞环调制器的设计旋钮，而描述函数把它写成了一行公式。仿真仲裁：$h=0.2$ 时实测基波 $0.4763$（比预测小 $1.18\%$），周期 $2.8472$ s（$-0.65\%$），THD $0.0413$。

把植物换成三阶的 $\dfrac{2}{s(s+1)(0.1s+1)}$（多一个 $10$ rad/s 的极点），谐波平衡没有闭式解，用 `fsolve` 解二元方程组得 $A = 0.646914$、$\omega = 1.844773$（残差 $2.9\times10^{-13}$）；实测基波 $0.6665$（$+3.03\%$），周期 $3.4628$ s（$+1.67\%$），THD $0.0378$。

> 💡 一个常被忽略的事实：**二阶环路加理想继电器永远不会自激振荡**，因为 $G(j\omega) = K/(-\omega^2 + j\omega)$ 的相位在 $-90^\circ$ 到 $-180^\circ$ 之间，永远达不到 $-180^\circ$。滞环提供的相位滞后（$N$ 的负虚部）才把总相位推到 $-180^\circ$，振荡才有解。案例 3 的对照组与 Notebook 6 cell 3 都实测了 $h=0$ 的情形：不振荡，而是抖振到零。

### 案例 2：饱和放大器伺服（诊断"只在大幅度时振荡"）

这就是引言里那台伺服轴。环路：饱和（$k=1$，$a=1$）串 $G(s) = \dfrac{K}{s(s+1)(0.5s+1)}$，单位负反馈。等效线性环的特征方程是 $0.5s^3 + 1.5s^2 + s + KN(A) = 0$，Routh 判据给出稳定条件 $KN(A) < 3$；谐波平衡在 $\omega_0 = \sqrt2$ 处要求 $N(A) = 3/K$。

- **$K = 6$**（线性环不稳定）：需要 $N = 0.5$。饱和的描述函数从 $k=1$ 单调降到 $0$，所以方程有唯一解 $A = 2.475414$。实测基波 $2.551004$（$+3.05\%$），周期 $4.5026$ s（$+1.34\%$），THD $0.0190$。**饱和把增益压下来，线性不稳定的环在大信号下自限于一个稳定极限环**——这就是"降增益振荡消失、跟踪变慢"的定量版本。
- **$K = 2$**（线性环稳定，$K<3$）：需要 $N = 1.5 > k = 1$，**无解**。实测从 $e(0)=1$ 衰减，末段 $\lvert e\rvert$ 峰值 $0.036456$，没有极限环。

于是设计结论有了明确的门槛：**$K<3$ 时不可能振荡**（$N\le k=1 \Rightarrow KN \le K < 3$）。这个门槛不是描述函数的近似结论，而是可以用圆判据严格证明的（见第 8 节与习题 6）。代价是带宽：$K$ 从 $6$ 降到 $2$ 意味着低频增益降 $3$ 倍。

### 案例 3：反推设计（给指标解参数）

描述函数也能反过来用。设计任务：用滞环继电器（$M=1$）和植物 $G(s) = \dfrac{K}{s(s+1)}$ 做一个 $f = 0.5$ Hz、幅值 $A = 1$ 的振荡器，求 $h$ 与 $K$。

把案例 1 的两个闭式条件当方程组反解（$c = 4M/(\pi A) = 1.273240$）：

$$
r = \frac{1}{\sqrt{1+\omega^2}} = 0.303314 \;\Rightarrow\; h = rA = 0.303314
$$

$$
K = \frac{\sqrt{1-r^2}}{c}\,(\omega^2+1) = 8.134795
$$

代回谐波平衡，残差 $\lvert NG+1\rvert = 2.3\times10^{-16}$（机器精度）。仿真验证：基波 $0.989195$（$-1.08\%$），周期 $1.9886$ s（$-0.57\%$），THD $0.0396$，$40$ s 内继电器只切换 $40$ 次，$\lvert e\rvert$ 首次超过 $0.9$ 的时刻是 $1.74$ s（起振时间）。

**三个参数定两个、反解第三个，误差不超过 $1.1\%$**——这是描述函数作为设计工具最有说服力的用法，也是它在继电器反馈整定（relay feedback autotuning）里被广泛使用的原因：做一次继电器反馈实验，测出振荡的 $A$ 和 $\omega$，就得到 $G(j\omega)$ 上的一个点，进而整定 PID。

## 何时失效

四种失效模式，每一种都配实测数字。共同的根源只有一句话：**描述函数把"非线性环节的输入是正弦"当前提，而它自己算出来的解可能破坏这个前提。**

### 失效一：$3\omega_0$ 附近有谐振峰

构造一个"最坏情况"：把第 4 节手算例的 $G_3(s)$ 串上一个 $\zeta = 0.02$、$\omega_r = 3\sqrt2$ 的二阶谐振峰（工程上对应结构模态、电源谐振、传动轴扭振）。数值解 $\operatorname{Im}G = 0$ 得 $\omega_0 = 1.3922$，$G(j\omega_0) = -0.385361$，$A_0 = 0.490657$。此时

$$
\left\lvert \frac{G(j3\omega_0)}{G(j\omega_0)} \right\rvert = 1.249 \;(+1.9\ \mathrm{dB}), \qquad L = 0.418\;(-7.6\ \mathrm{dB})
$$

**三次谐波被放大 $25\%$ 而不是被衰减。**仿真结果：实测基波 $0.5794$（$+18.1\%$），周期 $4.9689$ s（$+10.1\%$），THD $0.113$。机理很清楚：被放大的三次谐波回到非线性输入端，$e(t)$ 自己就不是正弦了（THD $11\%$），$N(A)$ 的定义前提被解本身破坏。

**缓解手段的实测价格**：把谐振阻尼从 $\zeta = 0.02$ 提到 $0.2$，$L$ 从 $-7.6$ dB 降到 $-24.6$ dB，幅值误差从 $+18.1\%$ 降到 $+8.7\%$，周期误差 $+5.0\%$，THD 从 $0.1127$ 降到 $0.0550$。代价有两条：振荡频率从 $1.3922$ 移到 $1.2360$ rad/s（$-11.2\%$），以及现实中要真的加阻尼器或陷波滤波器。注意阻尼加大后误差仍有 $8.7\%$，因为 $\omega_r/\omega_0$ 只从 $3.05$ 变到 $3.43$，谐振峰还在三倍频附近——**要真正修好，得让 $\omega_r/\omega_0$ 远离所有奇次谐波**。

### 失效二：$G(j\omega)$ 整段落在负实轴上（周期解族）

继电器串双积分器：$G(j\omega) = -1/\omega^2$ 对一切 $\omega$ 都是负实数，而 $-1/N(A) = -\pi A/(4M)$ 也在负实轴上——**两条轨迹整段重合**。谐波平衡退化成 $\omega^2 = 4M/(\pi A)$：每个 $A$ 都配一个 $\omega$，解不是孤立的一点而是一族。

仿真三个初值 $a_0 = 0.5,\,1.0,\,2.0$（峰值就等于初值），实测：

| $a_0$ | 峰值 $A_p$ | 基波 $A_1$ | 周期实测 | $T=\pi\sqrt{\pi A_1/M}$ | $T=4\sqrt{2A_p/M}$ |
| --- | --- | --- | --- | --- | --- |
| $0.5$ | $0.500000$ | $0.516025$ | $4.000000$ | $4.000000$ | $4.000000$ |
| $1.0$ | $1.000000$ | $1.032029$ | $5.656800$ | $5.656800$ | $5.656854$ |
| $2.0$ | $2.000000$ | $2.064098$ | $8.000000$ | $8.000000$ | $8.000000$ |

两个公式都与实测吻合到 $10^{-5}$ 相对误差以内。这不是巧合：这条轨道的基波与峰值之比实测为 $A_1/A_p = 1.032029\sim1.032049$，而 $32/\pi^3 = 1.032049$（相对差 $1.9\times10^{-5}$，来自仿真步长；习题 5 要求证明这个恒等式），代入得 $\pi\sqrt{\pi\cdot 32/\pi^3} = \sqrt{32} = 4\sqrt2$，两个式子恒等。

**但周期对了不等于方法成功了**：$T \propto \sqrt{A}$ 说明振幅完全由初值决定，系统参数只决定比例系数。描述函数在这里"公式对、振幅无意义"——它无法告诉你实际会振多大，因为答案取决于扰动历史。这与线性系统里的中心是同一种病，只有相平面能一眼看穿（第 8 节）。工程上真实的位置伺服总有额外极点，所以这个失效模式通常表现为"振幅对初值极其敏感、对增益极其不敏感"这种反常现象。

### 失效三：环路阶数不足 → 滑动与抖振

继电器串纯积分器：$G(j\omega) = -j/\omega$ 永远不在实轴上，谐波平衡无解，描述函数判"没有极限环"。仿真的真相是：$e$ 在 $1$ s 内到达 $0$，此后继电器抖振——dt $=10^{-3}$ 时 $2$ s 内切换 $1000$ 次，dt $=10^{-4}$ 时切换 $9999$ 次，切换频率 $\approx 1/(2\,dt)$ 随步长发散。**这不是有限频率的周期解，是滑动模态。**

再看无滞环继电器串 $2/(s(s+1))$（$K=2$）：同样无谐波平衡解。仿真末段 $\lvert e\rvert$ 峰值 $7.2\times10^{-5}$（$30$ s 内 $1159$ 次切换，其中末 $5$ s 占 $294$ 次）；把 dt 从 $10^{-4}$ 减到 $5\times10^{-5}$，末 $5$ s 切换升到 $480$ 次、峰值降到 $2.7\times10^{-5}$——**误差随步长趋零、切换频率随步长发散**，判据与上面一致。

描述函数的结论（无极限环）是对的，但它给不出工程师最关心的两个数：稳态误差有多小、执行器每秒动作多少次（后者直接决定继电器与接触器的寿命）。这类问题要交给滑模理论，见 [滑模控制](/nonlinear/sliding-mode-control)。反过来，案例 1 的滞环正是工程上抑制抖振的手段：加 $h=0.2$ 之后切换频率被钉死在 $0.349$ Hz，代价是振幅不可能小于 $h$（$A>h$ 才有 $N\neq0$）。

### 失效四：结构性盲区（串联、平衡点、时变、多变量）

- **串联不可相乘**：Notebook 2 实测"死区($0.3$) 串饱和($1$)"在 $A=1.5$ 处乘积近似错 $15.4\%$。正确做法是把组合映射 $f_2(f_1(u))$ 当成**一个**静态非线性做傅里叶积分。
- **看不见平衡点与吸引域**：死区加积分的环路有一整段连续平衡点，Notebook 4 实测冻点非单调（$e(0)=0.40 \to 0.0791$，$e(0)=0.60 \to 0.2597$）。描述函数只假设一个正弦，既给不出平衡点也给不出吸引域；起振阈值只能靠仿真二分（实测 $0.6735$，对预测 $A_1 = 0.6569$ 差 $2.5\%$）。
- **时变参数、多频激励、混沌**：本课未测，给结构性理由。$N(A)$ 的定义要求 $f$ 静态、周期化后单值、输入恰为单一正弦。参数慢时变时可用"冻结时间"逐点近似（见 [自适应控制基础](/nonlinear/adaptive-control-basics)）；快时变、多频激励或混沌下 $N(A)$ 不再是良定义的量，只能改用多谐波平衡或直接仿真。
- **多变量**：$N$ 变成矩阵、$-1/N$ 变成轨迹族，判据也随之复杂化，超出本课范围（见 [多变量系统分析](/modern/multivariable-systems)）。

## 与其他非线性方法的接口

描述函数在非线性工具箱里的位置很特殊：**它是唯一"频域 + 代数"的方法**，所以便宜、能手算、还能反推设计；代价是它只回答"有没有周期解、多大、多快"，不回答"全局稳不稳"、"吸引域多大"、"参数摄动下还成立吗"。

| 方法 | 适用阶数 | 给出什么 | 代价 | 与本课的关系 |
| --- | --- | --- | --- | --- |
| 相平面 | 二阶自治 | 全局相图、平衡点分类、极限环孤立性 | 只能二阶（高维需降维） | 失效二（解族）与失效四（连续平衡点）在相平面上一眼可见，见 [相平面分析](/nonlinear/phase-plane) |
| Lyapunov | 任意阶 | 严格的稳定性证明、吸引域估计 | 找函数靠技巧；**不给周期解参数** | 判"没有振荡"的严格工具；DF 只能判"没有谐波平衡解"，见 [李雅普诺夫稳定性](/nonlinear/lyapunov-stability) |
| 圆判据 / 被动性 | 任意阶 | 扇区非线性下"全局无周期解"的**充分条件** | 保守；要求扇区条件 | 案例 2 的 $K<3$ 正是圆判据与 Routh 重合的实例（习题 6） |
| 滑模 | 任意阶 | 有限时间收敛、抖振的定量刻画 | 抖振伤执行器 | 失效三是 DF 的盲区、滑模的主场，见 [滑模控制](/nonlinear/sliding-mode-control) |
| 反馈线性化 / 反步 / 自适应 | 任意阶 | 控制器（不只是分析） | 需要模型结构已知 | DF 只做预测不做设计；工程上先用 DF 找出振荡边界，再决定要不要换设计方法 |

**圆判据与案例 2 的严格版本**：饱和（$k=1$，$a=1$）满足扇区条件 $0 \le f(u)/u \le 1$，即落在扇区 $[0,1]$ 内。圆判据说：若 $G$ 无右半平面极点，且其 Nyquist 曲线不包围 $-1/k = -1$，则闭环全局渐近稳定（从而不可能有周期解）。对 $G = K/(s(s+1)(0.5s+1))$，Nyquist 只在 $\omega_0=\sqrt2$ 处穿越负实轴，穿越点是 $-K/3$，所以"不包围 $-1$" $\Leftrightarrow$ $K<3$——**与 Routh 判据逐字相同**。这条定理比描述函数强得多：$K<3$ 时不只是"没有谐波平衡解"，而是"从任何初值出发都收敛到零，不存在任何周期解"。

反过来，$K=6$ 时圆判据的充分条件不成立，它只能说"不能排除周期解"——既不能证明存在也不能证明不存在。这时候才轮到描述函数：它给出 $A = 2.4754$、$\omega = \sqrt2$，实测 $2.5510$（$+3.05\%$）。**分工很清楚：严格工具证"无"，近似工具找"有"。**

## 局限性讨论

| 局限 | 机理 | 本课实测证据 | 缓解手段与价格 |
| --- | --- | --- | --- |

## 小结

描述函数把非线性环节换成一个"随振幅变化的增益" $N(A)$，于是极限环的预测变成 Nyquist 图上两条曲线的交点问题。

- **定义与惯例**：输入 $u = A\sin\omega t$ 时 $N(A) = (b_1 + ja_1)/A$；奇对称无记忆非线性的 $N$ 是**实数**，带记忆（滞环、间隙）的虚部为负。$A$ 是**非线性环节输入端**的幅值。五个闭式全部对 $40000$ 点傅里叶积分核过：光滑情形偏差 $10^{-9}$，含跳变情形 $10^{-4}$。
- **谐波平衡**：$N(A)G(j\omega) = -1$，即 $G(j\omega) = -1/N(A)$。$-1/N$ 轨迹的方向（$A$ 增大向左）必须画对，否则稳定性判据整个读反。
- **稳定性判据**：交点处 $A\uparrow$ 若使 $-1/N$ 进入"不被包围"侧则极限环稳定；等效增益语言下就是"$N(A)$ 当增益时闭环仍稳定"。双交点算例中升支交点 $A_1=0.6569$ 不稳定（吸引域边界，仿真二分得 $0.6735$，差 $2.5\%$），降支 $A_2=2.8348$ 稳定（实测 $2.9070$，差 $2.5\%$）。
- **精度定价**：$L<-25$ dB 时，四个算例的幅值误差最大 $3.05\%$、周期误差最大 $1.67\%$、THD 最大 $0.0413$；$L=-7.6$ dB 时幅值误差 $+18.1\%$、THD $0.1127$，方法不可用。
- **失效模式**：谐振峰、周期解族、滑动抖振、串联与平衡点盲区——每一种都有实测数字与缓解手段的价格。
- **三种用法**：正向预测（案例 1）、诊断（案例 2 的 $K<3$ 门槛）、反推设计（案例 3 解出 $h=0.303314$、$K=8.134795$，实测偏差 $1.08\%$）。继电器反馈自整定就是第三种用法的工业化版本。

> 🔗 描述函数只能判"有没有周期解"，判不了全局稳定与吸引域。下一课 [李雅普诺夫稳定性](/nonlinear/lyapunov-stability) 用能量函数给出严格结论；想要二阶系统的全局几何图像，回看 [相平面分析](/nonlinear/phase-plane)。

## 习题

**习题 1（复数惯例与滞环）**：滞环继电器 $M=1$、$h=0.3$，输入幅值 $A=1$。

(a) 计算 $N(A)$ 的实部、虚部、幅值与相位（保留 6 位小数）；
(b) 证明幅值 $\lvert N\rvert$ 与 $h$ 无关，恒等于同幅值理想继电器的 $4M/(\pi A)$；
(c) 说明虚部符号的物理意义，并解释为什么奇对称的**无记忆**非线性（继电器、饱和、死区）虚部为零。

**习题 2（二阶植物 + 滞环继电器的闭式解）**：环路为滞环继电器（$M$，$h$）串 $G(s) = \dfrac{K}{s(s+1)}$，单位负反馈。记 $r = h/A$、$c = 4M/(\pi A)$。

(a) 把 $N = c(\sqrt{1-r^2} - jr)$ 与 $G(j\omega) = -a - jb$（$a = K/(\omega^2+1)$、$b = a/\omega$）代入 $NG = -1$，证明等价于
$$
\omega = \frac{\sqrt{1-r^2}}{r}, \qquad 4MKr^3 = \pi h\sqrt{1-r^2}
$$
(b) 取 $M=1$、$K=2$、$h=0.2$，解出 $A$、$\omega$、$f=\omega/2\pi$；
(c) 反问题：若要求 $A=1$、$\omega=\pi$（$f=0.5$ Hz）、$M=1$、植物仍是 $K/(s(s+1))$，求 $h$ 与 $K$。

**习题 3（Routh 与极限环存在性）**：植物 $G(s) = \dfrac{1}{s(s+1)(0.5s+1)}$。

(a) 把非线性换成等效增益 $K$，用 Routh 判据求闭环稳定的 $K$ 上界；
(b) 非线性换成理想继电器（幅值 $M$）：证明对任意 $K>0$、$M>0$ 都存在谐波平衡解，并给出 $A_0(K,M)$；算 $K=1$、$M=1$ 的数值；
(c) 非线性换成饱和（$k=1$、$a=1$），植物增益为 $K$：$K$ 满足什么条件才存在极限环？算 $K=6$ 的 $A_0$，并说明 $K=2$ 时会发生什么。

**习题 4（泄漏指标）**：$G_3(s) = \dfrac{1}{s(s+1)(0.5s+1)}$，理想继电器。

(a) 手算 $\lvert G_3(j3\omega_0)\rvert/\lvert G_3(j\omega_0)\rvert$（$\omega_0=\sqrt2$），给出数值与 dB；
(b) 按 $L \triangleq \sum_{n=3,5,7,9}\lvert G_3(jn\omega_0)\rvert/n \big/ \lvert G_3(j\omega_0)\rvert$ 计算 $L$；
(c) 实测 THD 只有 $0.0237$，幅值误差却有 $4.87\%$。为什么"$-20$ dB 经验门槛"不足以保证精度？
(d) 若把 $0.5s+1$ 换成 $0.05s+1$，则 $\omega_0=\sqrt{20}$，比值变为 $0.0966$（$-20.3$ dB）、$L=0.0401$（$-27.9$ dB），实测误差涨到 $10.58\%$。解释为什么把极点推远反而让指标变差。

**习题 5（周期解族与 $32/\pi^3$）**：理想继电器（$M=1$）串双积分器 $1/s^2$，单位负反馈，$e$ 为继电器输入。

(a) 由谐波平衡导出 $\omega^2 = 4M/(\pi A_1)$，进而 $T = \pi\sqrt{\pi A_1/M}$，并说明为什么解不孤立；
(b) 精确求解：证明轨道峰值 $A_p$ 与周期满足 $T = 4\sqrt{2A_p/M}$；
(c) 对 (b) 的分段抛物线波形做傅里叶积分，证明基波幅值 $A_1 = \dfrac{32}{\pi^3}A_p$，从而说明 (a) 与 (b) 是同一个式子；
(d) 用实测数据验证：$(A_1, T) = (0.516025,\,4.000000)$、$(1.032029,\,5.656800)$、$(2.064098,\,8.000000)$。

**习题 6（圆判据交叉核对）**：案例 2 的环路——饱和（$k=1$、$a=1$）串 $\dfrac{K}{s(s+1)(0.5s+1)}$。

(a) 写出该饱和非线性的扇区；
(b) 用圆判据给出"闭环全局渐近稳定、不存在任何周期解"的充分条件，并证明它等价于 $K<3$；
(c) $K=6$ 时圆判据给不出结论，而描述函数预测 $A_0=2.475414$、实测 $2.551004$（$+3.05\%$）。说明两个方法的分工，以及为什么"$K<3$ 不振荡"这个结论可以放心用于设计。

## 答案

**答案 1**：

(a) 闭式 $N(A) = \dfrac{4M}{\pi A}\Big(\sqrt{1-(h/A)^2} - j\dfrac{h}{A}\Big)$。代入 $M=1$、$h=0.3$、$A=1$：

$$
\frac{4M}{\pi A} = \frac{4}{\pi} = 1.273240, \qquad \sqrt{1-0.3^2} = \sqrt{0.91} = 0.953939
$$

$$
\operatorname{Re}N = 1.273240 \times 0.953939 = 1.214593, \qquad \operatorname{Im}N = -1.273240 \times 0.3 = -0.381972
$$

$$
\lvert N\rvert = 1.273240, \qquad \angle N = \arctan\frac{-0.381972}{1.214593} = -17.455^\circ
$$

Notebook 1 的 $40000$ 点数值积分给出 $1.214607 - 0.381927j$，与闭式相差 $4.67\times10^{-5}$（被积函数有跳变，收敛只有 $O(1/N)$）。

(b) $\lvert N\rvert = \dfrac{4M}{\pi A}\sqrt{(1-r^2) + r^2} = \dfrac{4M}{\pi A}$，根号内恰好是 $1$，所以幅值与 $h$ 无关。**滞环只改相位，不改基波增益的模**——这条性质在习题 2 的闭式求解里被反复用到。

(c) 虚部为负意味着输出基波**滞后**输入 $17.5^\circ$：滞环是有记忆的非线性，输出要等输入越过 $\pm h$ 才跳变，跳变时刻的延迟就是相位滞后，物理上对应每周期耗散的能量（滞环回线的面积）。奇对称且**无记忆**的非线性满足 $f(-u) = -f(u)$，于是 $f(A\sin\theta)\cos\theta$ 是奇函数、在整周期上积分为零，即 $a_1 = 0$，$N = b_1/A$ 为实数。注意"奇对称"本身不够：滞环继电器也是奇对称的，但因为有记忆，一个周期内的输出波形不再关于 $\theta=\pi/2$ 对称，$a_1\neq0$。

**答案 2**：

(a) $NG = (p - jq)(-a - jb)$，其中 $p = c\sqrt{1-r^2}$、$q = cr$。展开：

$$
NG = (-pa - qb) + j(qa - pb) = -1
$$

虚部为零：$qa = pb$。代入 $b = a/\omega$ 得 $q = p/\omega$，即

$$
\omega = \frac{p}{q} = \frac{\sqrt{1-r^2}}{r}
$$

实部：$pa + qb = 1$。把 $q = p/\omega$ 代入得 $a(p + q/\omega) = a(p + q^2/p) = a\,\dfrac{p^2+q^2}{p} = 1$。由 (b) 的结论 $p^2+q^2 = c^2$、$p = c\sqrt{1-r^2}$，所以

$$
a\,\frac{c}{\sqrt{1-r^2}} = 1 \;\Rightarrow\; a = \frac{\sqrt{1-r^2}}{c}
$$

再用 $\omega^2 + 1 = \dfrac{1-r^2}{r^2} + 1 = \dfrac{1}{r^2}$，即 $a = Kr^2$，并代入 $c = \dfrac{4M}{\pi A} = \dfrac{4Mr}{\pi h}$：

$$
Kr^2 = \frac{\sqrt{1-r^2}\,\pi h}{4Mr} \;\Rightarrow\; 4MKr^3 = \pi h\sqrt{1-r^2}
$$

(b) 取 $M=1$、$K=2$、$h=0.2$：解 $8r^3 = 0.2\pi\sqrt{1-r^2}$ 得 $r = 0.414971$，于是

$$
A = \frac{h}{r} = 0.481962, \qquad \omega = \frac{\sqrt{1-r^2}}{r} = 2.192528\ \mathrm{rad/s}, \qquad f = 0.348952\ \mathrm{Hz}
$$

代回 $\lvert NG+1\rvert = 0$（机器精度）。仿真实测基波 $0.4763$（$-1.18\%$）、周期 $2.8472$ s（预测 $2.8657$ s，$-0.65\%$）、THD $0.0413$。

(c) 反问题：$\omega = \pi$ 代入 $\omega = \sqrt{1-r^2}/r$ 得 $r = \dfrac{1}{\sqrt{1+\omega^2}} = \dfrac{1}{\sqrt{1+\pi^2}} = 0.303314$，故 $h = rA = 0.303314$。再由 $a = Kr^2 = \sqrt{1-r^2}/c$，$c = 4M/(\pi A) = 1.273240$：

$$
K = \frac{\sqrt{1-r^2}}{c\,r^2} = \frac{0.952891}{1.273240 \times 0.092000} = 8.134795
$$

（等价写法：$K = \dfrac{\sqrt{1-r^2}}{c}(\omega^2+1)$。）谐波平衡残差 $2.3\times10^{-16}$；仿真实测基波 $0.989195$（$-1.08\%$）、周期 $1.9886$ s（$-0.57\%$）、THD $0.0396$、起振 $1.74$ s。

**答案 3**：

(a) 特征方程 $0.5s^3 + 1.5s^2 + s + K = 0$。Routh 表：

| $s^3$ | $0.5$ | $1$ |
| --- | --- | --- |
| $s^2$ | $1.5$ | $K$ |
| $s^1$ | $\dfrac{1.5\cdot1 - 0.5K}{1.5}$ | $0$ |
| $s^0$ | $K$ | |

要求第一列全正：$K>0$ 且 $1.5 - 0.5K > 0$，即 $\boxed{0<K<3}$。Notebook 4 用极点直接核对：$K=2.9$ 时极点实部 $[-2.9816,-0.0092,-0.0092]$ 全负；$K=3.0$ 时出现 $0$；$K=3.1$ 时出现 $+0.009$。

(b) 理想继电器 $N(A) = 4M/(\pi A)$ 是实数，故交点必在 $G$ 的负实轴穿越点：$\operatorname{Im}G_3(j\omega)=0 \Rightarrow \omega_0=\sqrt2$，$G_3(j\omega_0) = -1/3$。谐波平衡 $N\cdot K\cdot(-1/3) = -1$ 给出

$$
A_0 = \frac{4MK}{3\pi}
$$

对任意 $K>0$、$M>0$ 都有正解——**继电器环路必然振荡**，因为 $N(A)$ 从 $\infty$（$A\to0$）单调降到 $0$（$A\to\infty$），一定穿过任何正的 $3/K$。$K=1$、$M=1$ 时 $A_0 = 4/(3\pi) = 0.424413$，实测 $0.445089$（$+4.87\%$）。

(c) 饱和的 $N_{\text{sat}}(A)$ 从 $k=1$ 单调降到 $0$，最大值就是 $1$。存在解要求 $\dfrac{3}{K} \le 1$，即 $\boxed{K \ge 3}$（$K=3$ 时解在边界 $A=a=1$ 上）。

- $K=6$：需 $N = 0.5$，解 $\dfrac{2}{\pi}\big[\alpha + \sin\alpha\cos\alpha\big] = 0.5$（$\alpha = \arcsin(1/A)$）得 $A_0 = 2.475414$，实测 $2.551004$（$+3.05\%$），周期 $4.5026$ s（$+1.34\%$），THD $0.0190$。
- $K=2$：需 $N = 1.5 > 1$，**无解**。实测从 $e(0)=1$ 衰减，末段 $\lvert e\rvert$ 峰值 $0.036456$，没有极限环；这与 (a) 的 $K<3$ 一致，而且由习题 6 的圆判据可知是**全局**结论。

**答案 4**：

(a) $\lvert G_3(j\omega)\rvert = \dfrac{1}{\omega\sqrt{\omega^2+1}\sqrt{0.25\omega^2+1}}$。

- $\omega_0=\sqrt2$：$\sqrt2\cdot\sqrt3\cdot\sqrt{1.5} = 3.0000$，故 $\lvert G_3(j\omega_0)\rvert = 1/3 = 0.333333$；
- $3\omega_0 = 3\sqrt2$：$4.2426\times\sqrt{19}\times\sqrt{5.5} = 4.2426\times4.3589\times2.3452 = 43.376$，故 $\lvert G_3(j3\omega_0)\rvert = 0.023054$。

比值 $= 0.023054/0.333333 = 0.0692$，即 $20\log_{10}0.0692 = -23.2$ dB。

(b) 逐次计算 $\lvert G_3(jn\omega_0)\rvert/n$：$n=3$ 给 $0.007685$，$n=5$ 给 $0.001078$，$n=7$ 给 $0.000287$，$n=9$ 给 $0.000106$；求和 $0.009156$，除以 $\lvert G_3(j\omega_0)\rvert=0.333333$ 得 $L = 0.0275$，即 $-31.2$ dB。Notebook 3 打印同一结果。

(c) $-20$ dB 门槛只约束**谐波的幅值**，而幅值误差的主要来源不是"$e(t)$ 里有多少谐波"，而是**谐波把继电器的切换时刻推离了正弦假设的位置**。切换时刻一偏，继电器输出的基波分量跟着变，整个自洽点就移动了。本例 THD 只有 $0.0237$（$e$ 确实接近正弦），幅值误差仍有 $4.87\%$，正是这个机理。所以门槛只能当筛查用：$L=-27.9$ dB 的那个环路 THD $0.0332$，误差却达 $10.58\%$。

(d) 交点频率由 $\omega_0 = \sqrt{1/T_c}$ 决定：$T_c$ 从 $0.5$ 减到 $0.05$，$\omega_0$ 从 $1.414$ 升到 $4.472$（涨 $3.16$ 倍），而极点位置 $1/T_c$ 从 $2$ 升到 $20$（涨 $10$ 倍）。关键量是三倍频与极点之比 $3\omega_0 T_c = 3\sqrt{T_c}$：$T_c=0.5$ 时为 $2.12$（三倍频在极点**之上**，已被衰减），$T_c=0.05$ 时为 $0.67$（三倍频跑到极点**之下**，几乎没被衰减）。所以比值从 $0.0692$ 恶化到 $0.0966$，$L$ 从 $-31.2$ dB 恶化到 $-27.9$ dB，误差从 $4.87\%$ 涨到 $10.58\%$。**结论：要让描述函数准，应降低 $\omega_0$（加大时间常数、降增益），而不是把极点推远。**

**答案 5**：

(a) $G(j\omega) = 1/(j\omega)^2 = -1/\omega^2$，$N(A_1) = 4M/(\pi A_1)$。谐波平衡：

$$
\frac{4M}{\pi A_1}\cdot\left(-\frac{1}{\omega^2}\right) = -1 \;\Rightarrow\; \omega^2 = \frac{4M}{\pi A_1} \;\Rightarrow\; T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{\pi A_1}{4M}} = \pi\sqrt{\frac{\pi A_1}{M}}
$$

$A_1$ 是自由的：任何 $A_1>0$ 都配一个 $\omega$。几何上，$G$ 的轨迹是整条负实轴，$-1/N$ 的轨迹也是整条负实轴，两者**重合**而不是相交，所以解是一族曲线而非孤立点——描述函数无法预测振幅。

(b) 设峰值为 $A_p$。$e>0$ 时 $\ddot e = -M$，从 $(A_p, 0)$ 出发：$e(t) = A_p - \tfrac{M}{2}t^2$，在 $t_a = \sqrt{2A_p/M}$ 处过零，此时 $\dot e = -Mt_a = -\sqrt{2MA_p}$。随后 $\ddot e = +M$，再经 $t_a$ 到达 $-A_p$ 且 $\dot e = 0$。由对称性，半个周期为 $2t_a$，故

$$
T = 4t_a = 4\sqrt{\frac{2A_p}{M}}
$$

(c) 取时间原点在峰值处，则 $e$ 是偶函数且满足半波对称 $e(t+T/2) = -e(t)$，故只有奇次余弦项，$A_1 = \dfrac{4}{T}\int_0^{T/2} e(t)\cos(\omega t)\,\mathrm{d}t$，$\omega t_a = \pi/2$。用 $A_p = \tfrac{M}{2}t_a^2$ 把两段写成

$$
[0,t_a]:\ e = \tfrac{M}{2}(t_a^2 - t^2), \qquad [t_a,2t_a]:\ e = -Mt_a s + \tfrac{M}{2}s^2,\ s = t-t_a
$$

第二段的 $\cos(\omega(s+t_a)) = \cos(\omega s + \pi/2) = -\sin(\omega s)$。换元 $x = t/t_a$ 后两段分别给出

$$
\int_0^1 (1-x^2)\cos\tfrac{\pi x}{2}\,\mathrm{d}x = \frac{16}{\pi^3}, \qquad \int_0^1 (2x-x^2)\sin\tfrac{\pi x}{2}\,\mathrm{d}x = \frac{16}{\pi^3}
$$

（两式都由两次分部积分得到，中间量 $\int_0^1 x\sin\tfrac{\pi x}{2}\mathrm{d}x = \tfrac{4}{\pi^2}$、$\int_0^1 x\cos\tfrac{\pi x}{2}\mathrm{d}x = \tfrac{2}{\pi}-\tfrac{4}{\pi^2}$。）于是

$$
\int_0^{T/2} e\cos(\omega t)\,\mathrm{d}t = \frac{M}{2}t_a^3\cdot\frac{16}{\pi^3}\times 2 = \frac{16Mt_a^3}{\pi^3}
$$

$$
A_1 = \frac{4}{4t_a}\cdot\frac{16Mt_a^3}{\pi^3} = \frac{16Mt_a^2}{\pi^3} = \frac{16M}{\pi^3}\cdot\frac{2A_p}{M} = \frac{32}{\pi^3}A_p
$$

代入 (a)：$T = \pi\sqrt{\dfrac{\pi}{M}\cdot\dfrac{32}{\pi^3}A_p} = \pi\sqrt{\dfrac{32A_p}{\pi^2 M}} = \sqrt{\dfrac{32A_p}{M}} = 4\sqrt{\dfrac{2A_p}{M}}$，与 (b) 恒等。**所以描述函数在这里的周期公式是精确的**（当 $A$ 解释为基波幅值时），失效的只是"振幅可预测"这一点。

(d) 实测三条轨道的 $A_1/A_p = 1.032029\sim1.032049$，与 $32/\pi^3 = 1.0320491$ 的相对差 $1.9\times10^{-5}$；周期实测 $4.000000$、$5.656800$、$8.000000$，与 $T=\pi\sqrt{\pi A_1}$ 逐位相同，与 $4\sqrt{2A_p}$ 的相对差也在 $10^{-5}$ 量级。

**答案 6**：

(a) 饱和 $f(u) = \operatorname{clip}(u,-1,1)$ 满足 $0 \le \dfrac{f(u)}{u} \le 1$（$u\neq0$），即落在扇区 $[0, k]$，$k = 1$。

(b) 圆判据（扇区 $[0,k]$ 版本）：若 $G$ 无右半平面极点，且 $G(j\omega)$ 的 Nyquist 曲线不包围 $-1/k$，则闭环全局渐近稳定，从而不存在任何周期解。本题 $G$ 的极点是 $0,-1,-2$，无右半平面极点（原点极点在 Nyquist 围线中按标准小半圆处理，等效增益判据与 Routh 一致）；Nyquist 只在 $\omega_0 = \sqrt2$ 处穿越负实轴，穿越点为 $-K/3$。于是

$$
\text{不包围 } -1 \;\Longleftrightarrow\; -\frac{K}{3} > -1 \;\Longleftrightarrow\; K < 3
$$

与 (习题 3a) 的 Routh 结果逐字相同。区别在于结论强度：Routh 说的是**线性化环**稳定，圆判据说的是**含饱和的非线性环**从任何初值都收敛到零，因此"$K<3$ 不振荡"是全局严格的。

(c) $K=6$ 时 $-K/3 = -2 < -1$，Nyquist 包围 $-1/k$，圆判据的**充分条件不成立**，它只能回答"不能排除周期解"——既不能证明存在，也不能证明不存在。这时描述函数接手：给出 $A_0 = 2.475414$、$\omega_0=\sqrt2$，并用第 5 节的 Loeb 判据判定该极限环稳定（降支交点），仿真验证 $2.551004$（$+3.05\%$）。

**分工**：圆判据/Lyapunov 证"无"（严格、保守），描述函数找"有"（近似、给出幅值与频率）。设计上可以放心用 $K<3$：它是由定理保证的全局结论，不依赖基波近似；而 $K=6$ 时的振幅数字只是估计，落地前必须仿真复核。
