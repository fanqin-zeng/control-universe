# 反步法设计

## 引言

想象你在指挥一支接力赛跑队伍。每个队员（状态变量）都需要把接力棒准确地交给下一个队员。如果最后一个队员跑偏了，你会责怪倒数第二个队员没有把棒交好；而倒数第二个队员的问题，又源于倒数第三个队员……这样一直追溯回第一个队员。

反步法（Backstepping）的设计思路与此类似，但方向相反：**从第一个状态开始，逐步向后设计，确保每个状态都能"完美交接"给下一个状态**。具体来说：

1. 首先设计第二个状态 $x_2$ 应该如何行动，才能使第一个状态 $x_1$ 稳定
2. 然后设计第三个状态 $x_3$ 应该如何行动，才能使 $x_2$ 跟踪上一步设计的期望值
3. 依此类推，直到最后一步设计出实际控制输入 $u$

这种**递归设计**（recursive design）方法的最大优势是**系统性**：只要系统具有**严格反馈结构**（strict-feedback form），就可以按部就班地设计控制器，每一步都用Lyapunov理论保证稳定性，最终全局稳定。

与反馈线性化相比，反步法不需要精确抵消非线性项，对模型不确定性更鲁棒；与滑模控制相比，反步法产生连续控制律，没有抖振问题；与经典PID相比，反步法有严格的稳定性证明，适用于强非线性系统。

> 📐 本文用到了Lyapunov稳定性理论和链式法则，详见 [李雅普诺夫稳定性](/nonlinear/lyapunov-stability)。

## 严格反馈系统

### 定义

**严格反馈系统**（Strict-Feedback System）是指具有以下结构的非线性系统：

$$\begin{aligned} \dot{x}_1 &= f_1(x_1) + g_1(x_1)x_2 \\ \dot{x}_2 &= f_2(x_1, x_2) + g_2(x_1, x_2)x_3 \\ &\vdots \\ \dot{x}_{n-1} &= f_{n-1}(x_1, \ldots, x_{n-1}) + g_{n-1}(x_1, \ldots, x_{n-1})x_n \\ \dot{x}_n &= f_n(x_1, \ldots, x_n) + g_n(x_1, \ldots, x_n)u \end{aligned}$$

其中：
- $x = [x_1, x_2, \ldots, x_n]^T$ 是状态向量
- $u$ 是标量控制输入
- $f_i(\cdot)$ 和 $g_i(\cdot)$ 是已知的光滑函数，且 $g_i(x) \neq 0$

**关键特征**：
1. **下三角结构**：第 i 个方程只依赖于 $x_1, \ldots, x_i$ 和 $x_{i+1}$
2. **线性虚拟控制**：$x_{i+1}$ 以线性方式出现在第 i 个方程中
3. **控制输入出现在最后一个方程**

这种结构在物理系统中很常见，比如：
- 机械系统：位置 → 速度 → 加速度（控制力）
- 电气系统：电荷 → 电流 → 电压
- 机电系统：角度 → 角速度 → 转矩

### 为什么叫"严格"反馈？

对比**纯反馈系统**（pure-feedback system）：

$$\dot{x} = f(x) + g(x)u$$

纯反馈系统中，控制输入 $u$ 可以直接影响所有状态。而严格反馈系统中，$u$ 只能直接影响 $x_n$，然后通过 $x_n$ 影响 $x_{n-1}$，依此类推，形成**级联结构**（cascade structure）。

"严格"的含义是：每个方程中，虚拟控制 $x_{i+1}$ 必须以线性方式出现，不能有 $x_{i+1}^2$ 或 $\sin(x_{i+1})$ 这样的非线性项。如果不是线性的，称为**半严格反馈**（semi-strict feedback），设计会更复杂。

## 二阶系统的反步法设计

### 问题描述

考虑二阶严格反馈系统：

$$\begin{aligned} \dot{x}_1 &= f_1(x_1) + g_1(x_1)x_2 \\ \dot{x}_2 &= f_2(x_1, x_2) + g_2(x_1, x_2)u \end{aligned}$$

目标是设计控制律 $u$，使 $x_1$ 跟踪期望轨迹 $x_{1d}(t)$，且所有信号有界。

### 步骤1：设计第一个虚拟控制

**定义跟踪误差**：

$$z_1 = x_1 - x_{1d}$$

**对 $z_1$ 求导**：

$$\dot{z}_1 = \dot{x}_1 - \dot{x}_{1d} = f_1(x_1) + g_1(x_1)x_2 - \dot{x}_{1d}$$

**设计虚拟控制** $\alpha_1$：

我们把 $x_2$ 看作 $z_1$ 子系统的"虚拟控制"，设计其期望值 $\alpha_1$（称为 **stabilizing function**），使 $z_1$ 稳定。

选择：

$$\alpha_1(x_1, x_{1d}, \dot{x}_{1d}) = \frac{1}{g_1(x_1)}\left[-f_1(x_1) + \dot{x}_{1d} - k_1 z_1\right]$$

其中 $k_1 > 0$ 是设计参数。

**物理解释**：如果 $x_2 = \alpha_1$，则：

$$\dot{z}_1 = f_1 + g_1 \alpha_1 - \dot{x}_{1d} = f_1 + g_1 \cdot \frac{1}{g_1}(-f_1 + \dot{x}_{1d} - k_1 z_1) - \dot{x}_{1d} = -k_1 z_1$$

即 $z_1$ 按指数 $e^{-k_1 t}$ 收敛到 0。

**定义第二个误差**：

$$z_2 = x_2 - \alpha_1$$

$z_2$ 衡量 $x_2$ 偏离其期望值的程度。

**构造第一个Lyapunov函数**：

$$V_1 = \frac{1}{2}z_1^2$$

**求导**：

$$\dot{V}_1 = z_1\dot{z}_1 = z_1[f_1(x_1) + g_1(x_1)x_2 - \dot{x}_{1d}]$$

代入 $x_2 = \alpha_1 + z_2$：

$$\dot{V}_1 = z_1[f_1 + g_1(\alpha_1 + z_2) - \dot{x}_{1d}]$$

由 $\alpha_1$ 的定义，$f_1 + g_1 \alpha_1 - \dot{x}_{1d} = -k_1 z_1$，所以：

$$\dot{V}_1 = z_1[-k_1 z_1 + g_1 z_2] = -k_1 z_1^2 + g_1 z_1 z_2$$

**关键点**：交叉项 $g_1 z_1 z_2$ 会在下一步被消去。

### 步骤2：设计实际控制律

**对 $z_2$ 求导**：

$$\dot{z}_2 = \dot{x}_2 - \dot{\alpha}_1 = f_2(x_1, x_2) + g_2(x_1, x_2)u - \dot{\alpha}_1$$

这里 $\dot{\alpha}_1$ 需要用**链式法则**计算：

$$\dot{\alpha}_1 = \frac{\partial \alpha_1}{\partial x_1}\dot{x}_1 + \frac{\partial \alpha_1}{\partial x_{1d}}\dot{x}_{1d} + \frac{\partial \alpha_1}{\partial \dot{x}_{1d}}\ddot{x}_{1d}$$

注意：$\alpha_1$ 是 $x_1, x_{1d}, \dot{x}_{1d}$ 的函数，而这些又依赖于时间 $t$。

**构造第二个Lyapunov函数**：

$$V_2 = V_1 + \frac{1}{2}z_2^2 = \frac{1}{2}z_1^2 + \frac{1}{2}z_2^2$$

**求导**：

$$\dot{V}_2 = \dot{V}_1 + z_2\dot{z}_2 = -k_1 z_1^2 + g_1 z_1 z_2 + z_2[f_2 + g_2 u - \dot{\alpha}_1]$$

整理：

$$\dot{V}_2 = -k_1 z_1^2 + z_2[g_1 z_1 + f_2 + g_2 u - \dot{\alpha}_1]$$

**设计控制律** $u$：

为了使 $\dot{V}_2$ 负定，我们选择 $u$ 使括号内等于 $-k_2 z_2$（$k_2 > 0$）：

$$g_1 z_1 + f_2 + g_2 u - \dot{\alpha}_1 = -k_2 z_2$$

解出：

$$u = \frac{1}{g_2(x_1, x_2)}\left[-g_1(x_1)z_1 - f_2(x_1, x_2) + \dot{\alpha}_1 - k_2 z_2\right]$$

**代入验证**：

$$\dot{V}_2 = -k_1 z_1^2 + z_2[-k_2 z_2] = -k_1 z_1^2 - k_2 z_2^2$$

显然 $\dot{V}_2 < 0$（当 $(z_1, z_2) \neq (0, 0)$ 时），根据Lyapunov稳定性定理：
- $z_1 \to 0$，即 $x_1 \to x_{1d}$
- $z_2 \to 0$，即 $x_2 \to \alpha_1$
- 所有信号有界

### 设计总结

二阶反步法的设计流程可以总结为：

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 定义 $z_1 = x_1 - x_{1d}$ | 跟踪误差 |
| 2 | 设计 $\alpha_1 = \frac{1}{g_1}(-f_1 + \dot{x}_{1d} - k_1 z_1)$ | 虚拟控制 |
| 3 | 定义 $z_2 = x_2 - \alpha_1$ | 第二个误差 |
| 4 | 构造 $V_1 = \frac{1}{2}z_1^2$，计算 $\dot{V}_1$ | 出现交叉项 $g_1 z_1 z_2$ |
| 5 | 构造 $V_2 = V_1 + \frac{1}{2}z_2^2$，计算 $\dot{V}_2$ | 需要消去交叉项 |
| 6 | 设计 $u = \frac{1}{g_2}(-g_1 z_1 - f_2 + \dot{\alpha}_1 - k_2 z_2)$ | $\dot{V}_2 = -k_1 z_1^2 - k_2 z_2^2 < 0$ |

**关键技巧**：
- 每一步的Lyapunov函数都包含前面所有项：$V_i = V_{i-1} + \frac{1}{2}z_i^2$
- 交叉项 $g_{i-1} z_{i-1} z_i$ 在下一步被消去
- 最终 $\dot{V}_n = -\sum_{i=1}^n k_i z_i^2$，负定

## 手算例子：二阶严格反馈系统

### 系统描述

考虑如下二阶非线性系统：

$$\begin{aligned} \dot{x}_1 &= x_1^2 + x_2 \\ \dot{x}_2 &= x_1 x_2 + u \end{aligned}$$

目标是设计控制律 $u$，使 $x_1$ 跟踪期望轨迹 $x_{1d}(t) = \sin(t)$。

对比标准形式：
- $f_1(x_1) = x_1^2$，$g_1(x_1) = 1$
- $f_2(x_1, x_2) = x_1 x_2$，$g_2(x_1, x_2) = 1$

### 步骤1：设计第一个虚拟控制

**跟踪误差**：

$$z_1 = x_1 - x_{1d} = x_1 - \sin(t)$$

**对 $z_1$ 求导**：

$$\dot{z}_1 = \dot{x}_1 - \dot{x}_{1d} = x_1^2 + x_2 - \cos(t)$$

**设计虚拟控制** $\alpha_1$：

选择 $k_1 = 2$（设计参数），则：

$$\alpha_1 = \frac{1}{g_1}(-f_1 + \dot{x}_{1d} - k_1 z_1) = -x_1^2 + \cos(t) - 2z_1$$

展开 $z_1 = x_1 - \sin(t)$：

$$\alpha_1 = -x_1^2 + \cos(t) - 2(x_1 - \sin(t)) = -x_1^2 - 2x_1 + \cos(t) + 2\sin(t)$$

**第二个误差**：

$$z_2 = x_2 - \alpha_1 = x_2 + x_1^2 + 2x_1 - \cos(t) - 2\sin(t)$$

**第一个Lyapunov函数**：

$$V_1 = \frac{1}{2}z_1^2$$

**求导**：

$$\dot{V}_1 = z_1\dot{z}_1 = z_1(x_1^2 + x_2 - \cos(t))$$

代入 $x_2 = \alpha_1 + z_2$：

$$\dot{V}_1 = z_1[x_1^2 + (\alpha_1 + z_2) - \cos(t)]$$

由 $\alpha_1$ 的定义，$x_1^2 + \alpha_1 - \cos(t) = -2z_1$，所以：

$$\dot{V}_1 = z_1[-2z_1 + z_2] = -2z_1^2 + z_1 z_2$$

### 步骤2：设计实际控制律

**对 $z_2$ 求导**：

$$\dot{z}_2 = \dot{x}_2 - \dot{\alpha}_1 = x_1 x_2 + u - \dot{\alpha}_1$$

需要计算 $\dot{\alpha}_1$。由 $\alpha_1 = -x_1^2 - 2x_1 + \cos(t) + 2\sin(t)$：

$$\dot{\alpha}_1 = \frac{\partial \alpha_1}{\partial x_1}\dot{x}_1 + \frac{\partial \alpha_1}{\partial t} = (-2x_1 - 2)\dot{x}_1 - \sin(t) + 2\cos(t)$$

代入 $\dot{x}_1 = x_1^2 + x_2$：

$$\dot{\alpha}_1 = (-2x_1 - 2)(x_1^2 + x_2) - \sin(t) + 2\cos(t)$$

展开：

$$\dot{\alpha}_1 = -2x_1^3 - 2x_1 x_2 - 2x_1^2 - 2x_2 - \sin(t) + 2\cos(t)$$

**第二个Lyapunov函数**：

$$V_2 = V_1 + \frac{1}{2}z_2^2 = \frac{1}{2}z_1^2 + \frac{1}{2}z_2^2$$

**求导**：

$$\dot{V}_2 = \dot{V}_1 + z_2\dot{z}_2 = -2z_1^2 + z_1 z_2 + z_2(x_1 x_2 + u - \dot{\alpha}_1)$$

整理：

$$\dot{V}_2 = -2z_1^2 + z_2[z_1 + x_1 x_2 + u - \dot{\alpha}_1]$$

**设计控制律** $u$：

选择 $k_2 = 3$（设计参数），令括号内等于 $-k_2 z_2 = -3z_2$：

$$z_1 + x_1 x_2 + u - \dot{\alpha}_1 = -3z_2$$

解出：

$$u = -z_1 - x_1 x_2 + \dot{\alpha}_1 - 3z_2$$

代入 $\dot{\alpha}_1$ 的表达式：

$$u = -z_1 - x_1 x_2 + [-2x_1^3 - 2x_1 x_2 - 2x_1^2 - 2x_2 - \sin(t) + 2\cos(t)] - 3z_2$$

合并同类项：

$$u = -z_1 - 3z_2 - 2x_1^3 - 3x_1 x_2 - 2x_1^2 - 2x_2 - \sin(t) + 2\cos(t)$$

其中 $z_1 = x_1 - \sin(t)$，$z_2 = x_2 + x_1^2 + 2x_1 - \cos(t) - 2\sin(t)$。

**验证稳定性**：

代入控制律后：

$$\dot{V}_2 = -2z_1^2 - 3z_2^2$$

显然 $\dot{V}_2 < 0$（当 $(z_1, z_2) \neq (0, 0)$ 时），系统渐近稳定。

## n 阶系统的反步法设计

### 一般流程

对于 n 阶严格反馈系统，反步法的设计流程可以归纳为：

**初始化**：
- 定义 $z_1 = x_1 - x_{1d}$
- 构造 $V_1 = \frac{1}{2}z_1^2$

**递归步骤**（i = 1, 2, ..., n-1）：
1. 设计虚拟控制 $\alpha_i = \frac{1}{g_i}(-f_i + \dot{\alpha}_{i-1} - g_{i-1}z_{i-1} - k_i z_i)$
2. 定义误差 $z_{i+1} = x_{i+1} - \alpha_i$
3. 更新Lyapunov函数 $V_{i+1} = V_i + \frac{1}{2}z_{i+1}^2$

**最后一步**（i = n）：
- 设计实际控制 $u = \alpha_n$

**最终Lyapunov函数**：

$$V_n = \frac{1}{2}\sum_{i=1}^n z_i^2$$

**导数**：

$$\dot{V}_n = -\sum_{i=1}^n k_i z_i^2$$

### 递归公式

第 i 步的详细推导：

**误差定义**：

$$z_i = x_i - \alpha_{i-1}$$

其中 $\alpha_0 = x_{1d}$。

**误差动态**：

$$\dot{z}_i = \dot{x}_i - \dot{\alpha}_{i-1} = f_i(x_1, \ldots, x_i) + g_i(x_1, \ldots, x_i)x_{i+1} - \dot{\alpha}_{i-1}$$

**虚拟控制设计**：

$$\alpha_i = \frac{1}{g_i(x_1, \ldots, x_i)}\left[-f_i(x_1, \ldots, x_i) + \dot{\alpha}_{i-1} - g_{i-1}(x_1, \ldots, x_{i-1})z_{i-1} - k_i z_i\right]$$

其中：
- $-g_{i-1}z_{i-1}$ 用于消去上一步的交叉项
- $-k_i z_i$ 提供阻尼，$k_i > 0$
- $\dot{\alpha}_{i-1}$ 用链式法则计算

**Lyapunov函数更新**：

$$V_i = V_{i-1} + \frac{1}{2}z_i^2$$

**导数**：

$$\dot{V}_i = \dot{V}_{i-1} + z_i\dot{z}_i = -\sum_{j=1}^{i-1} k_j z_j^2 + g_{i-1}z_{i-1}z_i + z_i[f_i + g_i x_{i+1} - \dot{\alpha}_{i-1}]$$

代入 $x_{i+1} = \alpha_i + z_{i+1}$ 和 $\alpha_i$ 的表达式，交叉项消去，得到：

$$\dot{V}_i = -\sum_{j=1}^i k_j z_j^2 + g_i z_i z_{i+1}$$

最后一步（i = n）没有 $z_{n+1}$，所以：

$$\dot{V}_n = -\sum_{j=1}^n k_j z_j^2$$

## 处理参数不确定性：自适应反步法

### 问题描述

实际系统中，$f_i(\cdot)$ 或 $g_i(\cdot)$ 可能包含未知参数。例如：

$$\dot{x}_1 = \theta x_1^2 + x_2$$

其中 $\theta$ 是未知常数。

### 传统方法：过参数化

如果直接用反步法，需要在每一步估计 $\theta$，导致**过参数化**（overparameterization）：同一个参数被估计多次，增加计算负担。

### Tuning Function 方法

**核心思想**：延迟参数更新，直到最后一步才进行，避免重复估计。

**设计流程**：
1. 前 n-1 步按正常反步法设计，但不更新参数估计
2. 构造 **tuning function** $\tau_i$，累积每一步的参数相关信息
3. 最后一步设计参数更新律 $\dot{\hat{\theta}} = \gamma \tau_n$

**例子**：考虑一阶系统 $\dot{x}_1 = \theta x_1^2 + x_2$。

**步骤1**：定义 $z_1 = x_1 - x_{1d}$，则：

$$\dot{z}_1 = \theta x_1^2 + x_2 - \dot{x}_{1d}$$

设计虚拟控制：

$$\alpha_1 = -\hat{\theta} x_1^2 + \dot{x}_{1d} - k_1 z_1$$

其中 $\hat{\theta}$ 是 $\theta$ 的估计值。

定义参数估计误差 $\tilde{\theta} = \theta - \hat{\theta}$。

Lyapunov函数：

$$V_1 = \frac{1}{2}z_1^2 + \frac{1}{2\gamma}\tilde{\theta}^2$$

其中 $\gamma > 0$ 是自适应增益。

求导：

$$\dot{V}_1 = z_1(\theta x_1^2 + x_2 - \dot{x}_{1d}) - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$

代入 $x_2 = \alpha_1 + z_2$：

$$\dot{V}_1 = z_1[\theta x_1^2 + (-\hat{\theta} x_1^2 + \dot{x}_{1d} - k_1 z_1 + z_2) - \dot{x}_{1d}] - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$

$$= z_1[(\theta - \hat{\theta})x_1^2 - k_1 z_1 + z_2] - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$

$$= z_1[\tilde{\theta} x_1^2 - k_1 z_1 + z_2] - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$

$$= -k_1 z_1^2 + z_1 z_2 + \tilde{\theta}\left(z_1 x_1^2 - \frac{1}{\gamma}\dot{\hat{\theta}}\right)$$

为了消去 $\tilde{\theta}$ 项，选择参数更新律：

$$\dot{\hat{\theta}} = \gamma z_1 x_1^2$$

但这只是第一步，后续步骤还会产生新的 $\tilde{\theta}$ 项。**Tuning function 方法**的做法是：

- 第一步不更新 $\hat{\theta}$，而是记录 tuning function $\tau_1 = z_1 x_1^2$
- 第二步产生 $\tau_2 = \tau_1 + \cdots$
- 最后一步才更新：$\dot{\hat{\theta}} = \gamma \tau_n$

这样可以避免过参数化。

## 应用案例

### 案例1：柔性关节机器人

#### 系统建模

柔性关节机器人的动力学方程为：

$$\begin{aligned} J_l\ddot{q} + B_l\dot{q} + K(q - \theta) &= 0 \\ J_m\ddot{\theta} + B_m\dot{\theta} + K(\theta - q) &= u \end{aligned}$$

其中：
- $q$ 是连杆角度
- $\theta$ 是电机转子角度
- $J_l, J_m$ 分别是连杆和电机的转动惯量
- $B_l, B_m$ 是粘性摩擦系数
- $K$ 是弹簧刚度
- $u$ 是电机转矩

目标是使连杆角度 $q$ 跟踪期望轨迹 $q_d(t)$。

#### 状态空间表示

定义状态变量：

$$x_1 = q, \quad x_2 = \dot{q}, \quad x_3 = \theta, \quad x_4 = \dot{\theta}$$

则系统方程为：

$$\begin{aligned} \dot{x}_1 &= x_2 \\ \dot{x}_2 &= -\frac{B_l}{J_l}x_2 - \frac{K}{J_l}(x_1 - x_3) \\ \dot{x}_3 &= x_4 \\ \dot{x}_4 &= -\frac{B_m}{J_m}x_4 - \frac{K}{J_m}(x_3 - x_1) + \frac{1}{J_m}u \end{aligned}$$

这不是标准的严格反馈形式，因为 $x_3$ 出现在 $\dot{x}_2$ 中，但不是线性的。我们可以通过坐标变换将其转化为严格反馈形式，或者使用**块反步法**（block backstepping）。

为简化，假设 $B_l = B_m = 0$（无摩擦），则：

$$\begin{aligned} \dot{x}_1 &= x_2 \\ \dot{x}_2 &= -\frac{K}{J_l}(x_1 - x_3) \\ \dot{x}_3 &= x_4 \\ \dot{x}_4 &= -\frac{K}{J_m}(x_3 - x_1) + \frac{1}{J_m}u \end{aligned}$$

定义新坐标 $z_1 = x_1$, $z_2 = x_2$, $z_3 = x_1 - x_3$, $z_4 = x_2 - x_4$，可以转化为严格反馈形式。

#### 反步法设计

由于篇幅限制，这里只给出设计思路：

**步骤1**：设计 $x_2$ 使 $x_1$ 稳定
- $z_1 = x_1 - q_d$
- $\alpha_1 = -k_1 z_1 + \dot{q}_d$

**步骤2**：设计 $x_3$ 使 $x_2$ 跟踪 $\alpha_1$
- $z_2 = x_2 - \alpha_1$
- 由 $\dot{x}_2 = -\frac{K}{J_l}(x_1 - x_3)$，设计 $\alpha_2$

**步骤3**：设计 $x_4$ 使 $x_3$ 跟踪 $\alpha_2$
- $z_3 = x_3 - \alpha_2$
- $\alpha_3 = -k_3 z_3 + \dot{\alpha}_2$

**步骤4**：设计 $u$ 使 $x_4$ 跟踪 $\alpha_3$
- $z_4 = x_4 - \alpha_3$
- $u = J_m[-\frac{K}{J_m}(x_3 - x_1) + \dot{\alpha}_3 - k_4 z_4]$

最终控制律保证 $q \to q_d$。

### 案例2：DC-DC变换器电压调节

#### 背景

Boost变换器是一种DC-DC升压变换器，广泛应用于电源管理。其平均模型为：

$$\begin{aligned} L\frac{di_L}{dt} &= -(1-d)V_C + V_{in} \\ C\frac{dV_C}{dt} &= (1-d)i_L - \frac{V_C}{R} \end{aligned}$$

其中：
- $i_L$ 是电感电流
- $V_C$ 是电容电压（输出电压）
- $d \in [0, 1)$ 是占空比（控制输入）
- $V_{in}$ 是输入电压
- $L, C, R$ 分别是电感、电容、负载电阻

目标是调节 $V_C$ 到期望值 $V_{ref}$。

#### 反步法设计

定义状态变量 $x_1 = V_C$, $x_2 = i_L$，控制输入 $u = d$。

系统方程：

$$\begin{aligned} \dot{x}_1 &= \frac{1}{C}(1-u)x_2 - \frac{x_1}{RC} \\ \dot{x}_2 &= -\frac{1}{L}(1-u)x_1 + \frac{V_{in}}{L} \end{aligned}$$

这不是严格反馈形式，因为 $u$ 同时出现在两个方程中。需要使用**占空比作为虚拟控制**的技巧，或者采用其他方法。

## 与其他非线性控制方法的对比

### 反步法 vs 反馈线性化

| 特性 | 反步法 | 反馈线性化 |
|------|-------|-----------|
| **适用系统** | 严格反馈系统 | 仿射非线性系统，需满足相对阶条件 |
| **线性化方式** | 不线性化，直接非线性设计 | 通过坐标变换和非线性反馈精确线性化 |
| **鲁棒性** | 可结合自适应处理参数不确定性 | 对模型误差敏感 |
| **控制连续性** | 连续 | 连续 |
| **抖振** | 无 | 无 |
| **设计复杂度** | 递归设计，但可能有复杂度爆炸 | 需计算Lie导数和坐标变换 |
| **稳定性保证** | 每步Lyapunov保证，全局稳定 | 依赖精确抵消，内部稳定性需单独分析 |

### 反步法 vs 滑模控制

| 特性 | 反步法 | 滑模控制 |
|------|-------|---------|
| **适用系统** | 严格反馈系统 | 相对阶为1的系统 |
| **不确定性处理** | 可结合自适应处理参数不确定性 | 对匹配不确定性完全鲁棒 |
| **控制连续性** | 连续 | 不连续（需边界层光滑化） |
| **抖振** | 无 | 存在，需抑制 |
| **不匹配不确定性** | 可以处理 | 不能完全处理 |
| **设计复杂度** | 递归设计，表达式复杂 | 相对简单，主要是切换面和增益选择 |
| **收敛速度** | 渐近收敛 | 有限时间到达 |

### 反步法 vs Lyapunov直接法

| 特性 | 反步法 | Lyapunov直接法 |
|------|-------|---------------|
| **设计思路** | 系统化递归设计 | 直接构造Lyapunov函数，依赖经验 |
| **系统性** | 有固定流程，适合级联系统 | 无通用构造方法 |
| **适用范围** | 严格反馈系统 | 任何能构造Lyapunov函数的系统 |
| **复杂度** | 随阶数增加而增加 | 取决于Lyapunov函数选择 |

## 局限性讨论

### 1. 复杂度爆炸

随着系统阶数 n 增加，虚拟控制 $\alpha_i$ 的表达式越来越复杂，因为每一步都要对前面的 $\alpha_{i-1}$ 求偏导。对于高阶系统，控制律可能变得无法实用。

**缓解方法**：
- **动态面控制**（DSC）：用一阶滤波器近似 $\alpha_i$，避免求导
- **命令滤波反步**：用二阶滤波器生成平滑参考信号
- **神经网络逼近**：用神经网络近似复杂的非线性项

### 2. 仅适用于严格反馈系统

反步法要求系统具有严格的下三角结构。如果不是这种结构（如非下三角、非最小相位），需要先用坐标变换转化，或者采用其他方法。

### 3. 需要全状态反馈

反步控制器通常需要测量所有状态变量。如果某些状态不可测，需要设计观测器，增加了复杂度。

### 4. 对未建模动态敏感

虽然反步法可以处理参数不确定性，但对未建模动态（如高频共振模式）比较敏感。可能需要结合鲁棒控制方法。

### 5. 参数收敛问题

自适应反步法中，参数估计 $\hat{\theta}$ 不一定收敛到真实值 $\theta$，除非满足持续激励（persistent excitation）条件。

## 小结

反步法是一种系统化的非线性控制设计方法，核心思想是：

1. **递归设计**：从第一个状态开始，逐步向后设计虚拟控制律，直到最后一步得到实际控制律
2. **严格反馈系统**：适用于具有下三角结构的级联系统，每个方程中虚拟控制以线性方式出现
3. **Lyapunov函数构造**：每一步都构造Lyapunov函数 $V_i = V_{i-1} + \frac{1}{2}z_i^2$，保证稳定性
4. **交叉项消去**：第 i 步产生的交叉项 $g_{i-1}z_{i-1}z_i$ 在第 i+1 步被消去
5. **虚拟控制与镇定函数**：$\alpha_i$ 是 $x_{i+1}$ 的期望值，设计为使 $z_i$ 稳定
6. **自适应反步法**：用tuning function方法避免过参数化，延迟参数更新到最后一步
7. **复杂度爆炸**：高阶系统控制律表达式复杂，可用动态面控制缓解

**工程应用要点**：
- 柔性关节机器人、DC-DC变换器、无人机姿态控制等场景广泛应用
- 控制律连续平滑，无抖振问题
- 可处理参数不确定性，但不能完全处理未建模动态
- 实际实现时常用简化版本（如DSC）降低计算复杂度

**与其他方法对比**：
- 比反馈线性化更鲁棒，但适用范围稍窄
- 比滑模控制更平滑，但收敛速度慢（渐近 vs 有限时间）
- 比Lyapunov直接法更有系统性，但仅适用于严格反馈系统

## 答案

**答案1：二阶反步法设计**

(a) **设计虚拟控制 $\alpha_1$**

跟踪误差：
$$z_1 = x_1 - x_{1d} = x_1 - 1$$

对 $z_1$ 求导：
$$\dot{z}_1 = \dot{x}_1 - \dot{x}_{1d} = x_1 + x_2 - 0 = x_1 + x_2$$

设计虚拟控制（选择 $k_1 = 2$）：
$$\alpha_1 = \frac{1}{g_1}(-f_1 + \dot{x}_{1d} - k_1 z_1) = -(x_1 + 2z_1) = -x_1 - 2(x_1 - 1) = -3x_1 + 2$$

第二个误差：
$$z_2 = x_2 - \alpha_1 = x_2 + 3x_1 - 2$$

第一个Lyapunov函数：
$$V_1 = \frac{1}{2}z_1^2$$

求导：
$$\dot{V}_1 = z_1\dot{z}_1 = z_1(x_1 + x_2) = z_1(x_1 + \alpha_1 + z_2)$$

代入 $\alpha_1 = -x_1 - 2z_1$：
$$\dot{V}_1 = z_1(x_1 - x_1 - 2z_1 + z_2) = z_1(-2z_1 + z_2) = -2z_1^2 + z_1 z_2$$

(b) **设计实际控制律 $u$**

对 $z_2$ 求导：
$$\dot{z}_2 = \dot{x}_2 - \dot{\alpha}_1 = x_1 x_2 + u - \dot{\alpha}_1$$

计算 $\dot{\alpha}_1$：
$$\alpha_1 = -3x_1 + 2 \Rightarrow \dot{\alpha}_1 = -3\dot{x}_1 = -3(x_1 + x_2)$$

第二个Lyapunov函数：
$$V_2 = V_1 + \frac{1}{2}z_2^2 = \frac{1}{2}z_1^2 + \frac{1}{2}z_2^2$$

求导：
$$\dot{V}_2 = \dot{V}_1 + z_2\dot{z}_2 = -2z_1^2 + z_1 z_2 + z_2(x_1 x_2 + u - \dot{\alpha}_1)$$

整理：
$$\dot{V}_2 = -2z_1^2 + z_2[z_1 + x_1 x_2 + u - \dot{\alpha}_1]$$

设计控制律（选择 $k_2 = 3$）：
$$z_1 + x_1 x_2 + u - \dot{\alpha}_1 = -k_2 z_2 = -3z_2$$

解出：
$$u = -z_1 - x_1 x_2 + \dot{\alpha}_1 - 3z_2$$

代入 $\dot{\alpha}_1 = -3(x_1 + x_2)$：
$$u = -z_1 - x_1 x_2 - 3(x_1 + x_2) - 3z_2$$

其中 $z_1 = x_1 - 1$，$z_2 = x_2 + 3x_1 - 2$。

(c) **稳定性证明**

代入控制律后：
$$\dot{V}_2 = -2z_1^2 - 3z_2^2$$

显然 $\dot{V}_2 < 0$（当 $(z_1, z_2) \neq (0, 0)$ 时），根据Lyapunov稳定性定理，系统渐近稳定，即 $z_1 \to 0$ 且 $z_2 \to 0$，从而 $x_1 \to 1$。

**答案2：三阶系统反步法**

(a) **误差定义**

期望轨迹 $x_{1d} = 0$。

$$z_1 = x_1 - 0 = x_1$$
$$z_2 = x_2 - \alpha_1$$
$$z_3 = x_3 - \alpha_2$$

(b) **设计控制律**

**步骤1**：设计 $\alpha_1$

$$\dot{z}_1 = \dot{x}_1 = x_1^2 + x_2$$

选择 $k_1 = 1$：
$$\alpha_1 = \frac{1}{g_1}(-f_1 + \dot{x}_{1d} - k_1 z_1) = -(x_1^2 + z_1) = -x_1^2 - x_1$$

$$\dot{V}_1 = z_1(x_1^2 + x_2) = z_1(x_1^2 + \alpha_1 + z_2) = z_1(x_1^2 - x_1^2 - x_1 + z_2) = z_1(-x_1 + z_2) = -z_1^2 + z_1 z_2$$

**步骤2**：设计 $\alpha_2$

$$\dot{z}_2 = \dot{x}_2 - \dot{\alpha}_1 = x_2^2 + x_3 - \dot{\alpha}_1$$

计算 $\dot{\alpha}_1$：
$$\alpha_1 = -x_1^2 - x_1 \Rightarrow \dot{\alpha}_1 = (-2x_1 - 1)\dot{x}_1 = (-2x_1 - 1)(x_1^2 + x_2)$$

选择 $k_2 = 1$：
$$V_2 = V_1 + \frac{1}{2}z_2^2$$
$$\dot{V}_2 = -z_1^2 + z_1 z_2 + z_2(x_2^2 + x_3 - \dot{\alpha}_1) = -z_1^2 + z_2[z_1 + x_2^2 + x_3 - \dot{\alpha}_1]$$

设计 $\alpha_2$：
$$z_1 + x_2^2 + \alpha_2 - \dot{\alpha}_1 = -z_2$$
$$\alpha_2 = -z_1 - x_2^2 + \dot{\alpha}_1 - z_2$$

$$\dot{V}_2 = -z_1^2 - z_2^2 + z_2 z_3$$

**步骤3**：设计 $u$

$$\dot{z}_3 = \dot{x}_3 - \dot{\alpha}_2 = x_1 x_3 + u - \dot{\alpha}_2$$

$$V_3 = V_2 + \frac{1}{2}z_3^2$$
$$\dot{V}_3 = -z_1^2 - z_2^2 + z_2 z_3 + z_3(x_1 x_3 + u - \dot{\alpha}_2) = -z_1^2 - z_2^2 + z_3[z_2 + x_1 x_3 + u - \dot{\alpha}_2]$$

选择 $k_3 = 1$，设计 $u$：
$$z_2 + x_1 x_3 + u - \dot{\alpha}_2 = -z_3$$
$$u = -z_2 - x_1 x_3 + \dot{\alpha}_2 - z_3$$

$$\dot{V}_3 = -z_1^2 - z_2^2 - z_3^2 < 0$$

(c) **稳定性证明**

$$\dot{V}_3 = -\sum_{i=1}^3 z_i^2 < 0$$

系统渐近稳定，$z_i \to 0$，即 $x_1 \to 0$。

**答案3：参数自适应**

(a) **设计虚拟控制 $\alpha_1$**

跟踪误差：
$$z_1 = x_1 - x_{1d}$$

$$\dot{z}_1 = \theta x_1^2 + x_2 - \dot{x}_{1d}$$

设计虚拟控制（含参数估计）：
$$\alpha_1 = -\hat{\theta} x_1^2 + \dot{x}_{1d} - k_1 z_1$$

其中 $\hat{\theta}$ 是 $\theta$ 的估计值，$\tilde{\theta} = \theta - \hat{\theta}$ 是估计误差。

(b) **构造Lyapunov函数**

$$V_1 = \frac{1}{2}z_1^2 + \frac{1}{2\gamma}\tilde{\theta}^2$$

其中 $\gamma > 0$ 是自适应增益。

求导：
$$\dot{V}_1 = z_1\dot{z}_1 - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$
$$= z_1(\theta x_1^2 + x_2 - \dot{x}_{1d}) - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$

代入 $x_2 = \alpha_1 + z_2$：
$$= z_1[\theta x_1^2 + (-\hat{\theta} x_1^2 + \dot{x}_{1d} - k_1 z_1 + z_2) - \dot{x}_{1d}] - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$
$$= z_1[(\theta - \hat{\theta})x_1^2 - k_1 z_1 + z_2] - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$
$$= z_1[\tilde{\theta} x_1^2 - k_1 z_1 + z_2] - \frac{1}{\gamma}\tilde{\theta}\dot{\hat{\theta}}$$
$$= -k_1 z_1^2 + z_1 z_2 + \tilde{\theta}\left(z_1 x_1^2 - \frac{1}{\gamma}\dot{\hat{\theta}}\right)$$

(c) **设计参数更新律**

为了消去 $\tilde{\theta}$ 项，选择：
$$\dot{\hat{\theta}} = \gamma z_1 x_1^2$$

则：
$$\dot{V}_1 = -k_1 z_1^2 + z_1 z_2$$

如果有第二步，继续设计 $u$ 消去 $z_1 z_2$ 项。

**答案4：复杂度分析**

(a) **$\alpha_i$ 的依赖关系**

$\alpha_i$ 依赖于：
- $x_1, \ldots, x_i$（当前及之前的状态）
- $x_{1d}, \dot{x}_{1d}, \ldots, x_{1d}^{(i)}$（期望轨迹及其导数）
- $\alpha_{i-1}$ 及其偏导数

具体来说：
$$\alpha_i = \alpha_i(x_1, \ldots, x_i, x_{1d}, \ldots, x_{1d}^{(i)}, \hat{\theta})$$

(b) **偏导次数**

计算 $\dot{\alpha}_i$ 需要对 $\alpha_i$ 求时间导数：
$$\dot{\alpha}_i = \sum_{j=1}^i \frac{\partial \alpha_i}{\partial x_j}\dot{x}_j + \sum_{k=0}^i \frac{\partial \alpha_i}{\partial x_{1d}^{(k)}}x_{1d}^{(k+1)} + \frac{\partial \alpha_i}{\partial \hat{\theta}}\dot{\hat{\theta}}$$

每一项 $\frac{\partial \alpha_i}{\partial x_j}$ 又依赖于 $\alpha_{i-1}$ 的偏导，形成递归。

对于 n 阶系统，$\dot{\alpha}_i$ 的项数大致以 $O(2^i)$ 增长，导致**指数复杂度**。

(c) **复杂度爆炸原因**

1. **链式法则递归**：每一步都要对前面的 $\alpha_{i-1}$ 求偏导，而 $\alpha_{i-1}$ 本身已经包含了 $\alpha_{i-2}$ 的偏导
2. **交叉项累积**：虽然交叉项被消去，但计算过程中仍需处理
3. **参数估计**：如果有自适应，还需处理参数更新律的导数

**缓解方法**：动态面控制用滤波器近似 $\alpha_i$，避免求导，将复杂度从 $O(2^n)$ 降到 $O(n)$。

**答案5：与反馈线性化对比**

系统：$\ddot{x} = f(x, \dot{x}) + u$

(a) **反馈线性化**

定义状态 $x_1 = x$, $x_2 = \dot{x}$，则：
$$\begin{aligned} \dot{x}_1 &= x_2 \\ \dot{x}_2 &= f(x_1, x_2) + u \end{aligned}$$

这是相对阶 r=2 的系统。设计控制律：
$$u = -f(x_1, x_2) + v$$

其中 $v$ 是新输入。代入后：
$$\ddot{x} = v$$

选择 $v = -k_1 x - k_2 \dot{x}$，则 $\ddot{x} + k_2 \dot{x} + k_1 x = 0$，系统线性稳定。

(b) **反步法**

**步骤1**：$z_1 = x_1 - x_{1d}$（假设 $x_{1d} = 0$）

$$\dot{z}_1 = x_2$$

设计 $\alpha_1 = -k_1 z_1$。

$$z_2 = x_2 - \alpha_1 = x_2 + k_1 x_1$$

$$V_1 = \frac{1}{2}z_1^2, \quad \dot{V}_1 = z_1 x_2 = z_1(\alpha_1 + z_2) = -k_1 z_1^2 + z_1 z_2$$

**步骤2**：
$$\dot{z}_2 = \dot{x}_2 - \dot{\alpha}_1 = f(x_1, x_2) + u - (-k_1 \dot{x}_1) = f + u + k_1 x_2$$

$$V_2 = V_1 + \frac{1}{2}z_2^2$$
$$\dot{V}_2 = -k_1 z_1^2 + z_1 z_2 + z_2(f + u + k_1 x_2)$$

设计 $u$（选择 $k_2$）：
$$z_1 + f + u + k_1 x_2 = -k_2 z_2$$
$$u = -z_1 - f - k_1 x_2 - k_2 z_2$$

代入 $z_2 = x_2 + k_1 x_1$：
$$u = -x_1 - f - k_1 x_2 - k_2(x_2 + k_1 x_1) = -f - (1 + k_1 k_2)x_1 - (k_1 + k_2)x_2$$

(c) **对比**

反馈线性化：$u = -f - k_1 x - k_2 \dot{x}$

反步法：$u = -f - (1 + k_1 k_2)x - (k_1 + k_2)\dot{x}$

**不完全相同**，但形式相似。差异在于：
- 反馈线性化直接抵消非线性项 $f$，然后设计线性反馈
- 反步法通过递归Lyapunov设计，自然产生非线性反馈

两者都能使系统稳定，但反步法的增益选择更有系统性（每步一个 $k_i$），且可以扩展到参数自适应。
