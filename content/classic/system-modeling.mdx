# 系统建模基础

控制系统设计的第一步是建立被控对象的数学模型。本节介绍如何从物理定律出发，推导系统的微分方程。

## 机械系统建模

对平移机械系统，依据牛顿第二定律：

$$
m\ddot{x}(t) + c\dot{x}(t) + kx(t) = F(t)
$$

其中 $m$ 为质量，$c$ 为阻尼系数，$k$ 为弹簧刚度，$F(t)$ 为外力。

对旋转系统，依据转动定律：

$$
J\ddot{\theta}(t) + B\dot{\theta}(t) + K\theta(t) = T(t)
$$

其中 $J$ 为转动惯量，$B$ 为粘性摩擦系数，$K$ 为扭转刚度。

## 电气系统建模

对 RLC 串联电路，依据基尔霍夫电压定律：

$$
L\frac{di(t)}{dt} + Ri(t) + \frac{1}{C}\int i(t)\,dt = v(t)
$$

对电容电压 $v_C(t)$ 为输出时，传递函数为：

$$
G(s) = \frac{V_C(s)}{V(s)} = \frac{1}{LCs^2 + RCs + 1}
$$

## 机电类比

机械系统与电气系统存在类比关系：

| 机械量 | 电气量（力-电压类比） |
|--------|----------------------|
| 力 $F$ | 电压 $v$ |
| 速度 $\dot{x}$ | 电流 $i$ |
| 质量 $m$ | 电感 $L$ |
| 阻尼 $c$ | 电阻 $R$ |
| 刚度倒数 $1/k$ | 电容 $C$ |

利用类比关系，可以用电路仿真工具分析机械系统。

## 代码示例

用 Python 建立弹簧-质量-阻尼系统模型：

```python
import numpy as np
from scipy.signal import lti, step

m, c, k = 1.0, 0.5, 2.0  # 质量、阻尼、刚度
sys = lti([k], [m, c, k])
t, y = step(sys, T=np.linspace(0, 20, 500))
```

## 小结

- 系统建模是从物理定律推导微分方程的过程。
- 机械系统用牛顿定律，电气系统用基尔霍夫定律。
- 机电类比可以跨领域复用分析方法。

<Callout variant="tip">
  建模时先画自由体图（free-body diagram），标注所有力和力矩，再列方程，不易遗漏。
</Callout>
