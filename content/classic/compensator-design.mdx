# 校正网络设计

## 为什么需要校正网络

上一章（[频率响应设计法](/classic/frequency-response-design)）的实例中，我们遇到了一个典型困境：

> 被控对象 $G(s) = \frac{K}{s(s+1)(s+10)}$，要求 $K_v \geq 10$ 且 $PM \geq 45°$。
>
> 增大 $K$ 满足稳态精度 → 相位裕度变负，系统不稳定。
>
> 减小 $K$ 满足稳定裕度 → 稳态精度不够。

**纯增益调节无法同时满足稳态精度和动态性能。**

回顾我们已经掌握的工具，看看它们各自能做什么：

| 工具 | 能做什么 | 不能做什么 |
|------|---------|-----------|
| 增益调节（[频率响应设计法](/classic/frequency-response-design)） | 改变穿越频率 | 无法独立调整低频增益和中频相位 |
| Z-N 整定（[频率响应设计法](/classic/frequency-response-design)） | 给出 PID 初始参数 | 精度有限，PM 通常只有 ~30° |
| PID（[PID 控制器](/classic/pid-controller)） | 三个参数覆盖基本需求 | 参数耦合，调参靠经验 |

这就是校正网络登场的时刻。校正网络（compensator）是串联在控制器中的额外环节，通过改变开环频率响应的**形状**（而不仅仅是增益），使系统同时满足多方面的设计指标。

校正网络的设计思路：**在 Bode 图上" sculpt"（雕刻）开环频率特性。**

- 低频段增益不够？→ 增大低频增益（滞后校正）
- 中频段相位裕度不够？→ 增加相位超前（超前校正）
- 两者都需要？→ 超前-滞后校正

> 📖 本章需要 Bode 图、增益裕度和相位裕度的基础，详见 [频率响应设计法](/classic/frequency-response-design)。PID 控制器的基础详见 [PID 控制器设计](/classic/pid-controller)。

### 从"试"到"设计"

PID 调参（[Z-N 法](/classic/frequency-response-design#工程应用ziegler-nichols-整定法)）本质上是"试"——用经验公式给出初始值，再手动微调。校正网络设计则是**系统化方法**：

1. 从设计指标出发，用数学推导出校正器参数
2. 每一步都有明确的物理意义
3. 设计结果可预测、可复现

这是从"工匠"到"工程师"的跨越。

## 校正的基本思路

### 设计指标：从时域到频域的翻译

实际控制系统的指标通常以**时域**形式给出（超调量、上升时间、稳态误差），但校正设计在**频域**进行。因此第一步是"翻译"：

| 时域指标 | 频域对应 | 近似关系 |
|---------|---------|---------|
| 超调量 $M_p \leq 5\%$ | 相位裕度 $PM \geq ?$ | $\zeta \approx PM/100$，$M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}}$ |
| 上升时间 $t_r \leq 0.5$ s | 穿越频率 $\omega_c \geq ?$ | $t_r \approx 1.8/\omega_c$ |
| 稳态误差 $e_{ss} \leq 0.01$ | 误差系数 $K_v \geq ?$ | $e_{ss} = 1/K_v$（斜坡输入） |
|  settling time $t_s \leq 2$ s | 带宽 $\omega_b$ | $t_s \approx 4/(\zeta\omega_n)$，$\omega_b \approx \omega_c$ |

**示例**：指标要求 $M_p \leq 10\%$，$t_r \leq 0.3$ s，$K_v \geq 50$。

翻译过程：
- $M_p \leq 10\%$ → $\zeta \geq 0.59$ → $PM \geq 59°$（取 $PM \geq 60°$）
- $t_r \leq 0.3$ s → $\omega_c \geq 1.8/0.3 = 6$ rad/s
- $K_v \geq 50$

这样，时域指标就转化为了频域设计目标。

> 💡 关于 $PM$ 与 $\zeta$ 的完整推导，详见 [频域分析——频域指标与时域指标的对应](/classic/frequency-domain-analysis#频域指标与时域指标的对应)。

### 校正方式

| 方式 | 描述 | 优缺点 |
|------|------|--------|
| **串联校正** | 校正网络串联在前向通道中 | 最常用，设计直观 |
| **反馈校正** | 校正网络在局部反馈回路中 | 对参数变化更鲁棒 |
| **前馈校正** | 根据参考输入或扰动直接补偿 | 不改变稳定性，改善跟踪 |

本章主要讨论**串联校正**，这是最基础也最常用的方法。

### 设计流程

1. **根据稳态精度要求**确定开环增益 $K$
2. **画出未校正系统**的 Bode 图，检查 $PM$ 和 $\omega_c$
3. **判断需要哪种校正**：
   - 需要增加相位裕度 → 超前校正
   - 需要增大低频增益 → 滞后校正
   - 两者都需要 → 超前-滞后校正
4. **设计校正网络**参数
5. **验证**校正后系统是否满足所有指标

## 超前校正

### 传递函数

超前校正网络的传递函数：

$$
G_c(s) = \frac{1 + \alpha Ts}{1 + Ts}, \quad \alpha > 1
$$

或者写成零极点形式：

$$
G_c(s) = \alpha \cdot \frac{s + 1/(\alpha T)}{s + 1/T}
$$

零点在 $s = -1/(\alpha T)$，极点在 $s = -1/T$。因为 $\alpha > 1$，零点比极点更靠近虚轴（更"慢"）。

### 频率特性

$G_c(j\omega) = \frac{1 + j\alpha T\omega}{1 + jT\omega}$

**幅频特性**：

- 低频（$\omega \ll 1/(\alpha T)$）：增益 $\approx 1$（0 dB）
- 高频（$\omega \gg 1/T$）：增益 $\approx \alpha$（$20\log_{10}\alpha$ dB）
- 中频段：增益从 0 dB 上升到 $20\log_{10}\alpha$

**相频特性**：

- 提供**正的相位**（相位超前）
- 最大超前相位 $\phi_m$ 出现在 $\omega_m = \frac{1}{T\sqrt{\alpha}}$

$$
\phi_m = \arcsin\frac{\alpha - 1}{\alpha + 1}
$$

> **$\phi_m$ 公式推导**：相位 $\phi(\omega) = \arctan(\alpha T\omega) - \arctan(T\omega)$。令 $u = T\omega$，则 $\phi = \arctan(\alpha u) - \arctan(u)$。对 $u$ 求导并令为零：
>
> $$\frac{d\phi}{du} = \frac{\alpha}{1+\alpha^2 u^2} - \frac{1}{1+u^2} = 0$$
>
> 解得 $u_m = 1/\sqrt{\alpha}$，即 $\omega_m = 1/(T\sqrt{\alpha})$。代入：
>
> $$\phi_m = \arctan(\sqrt{\alpha}) - \arctan(1/\sqrt{\alpha})$$
>
> 利用 $\arctan(x) + \arctan(1/x) = \pi/2$（$x > 0$），得 $\phi_m = 2\arctan(\sqrt{\alpha}) - \pi/2$。
>
> 令 $\theta = \arctan(\sqrt{\alpha})$，则 $\tan\theta = \sqrt{\alpha}$，$\sin(2\theta - \pi/2) = -\cos(2\theta) = -\frac{1-\alpha}{1+\alpha} = \frac{\alpha-1}{\alpha+1}$。
>
> 因此 $\phi_m = \arcsin\frac{\alpha-1}{\alpha+1}$。$\blacksquare$

### 关键关系

$\alpha$ 与 $\phi_m$ 的对应关系：

| $\phi_m$ | $\alpha$ |
|:---:|:---:|
| 20° | 2.0 |
| 30° | 3.0 |
| 40° | 4.8 |
| 50° | 7.6 |
| 60° | 13.9 |

注意：$\phi_m$ 一般不超过 65°~70°。更大的超前角需要 $\alpha$ 极大，导致高频增益过大，噪声问题严重。

### 设计步骤

**目标**：增加相位裕度到指定值，同时保持稳态精度。

1. **确定开环增益 $K$**：根据稳态误差要求（这一步不加校正就要完成）

2. **评估未校正系统**：画出 $KG(s)$ 的 Bode 图，读取当前相位裕度 $PM_0$ 和穿越频率 $\omega_{c0}$

3. **计算需要的超前相位**：

$$
\phi_m = PM_{\text{req}} - PM_0 + \epsilon
$$

其中 $\epsilon = 5° \sim 15°$ 是安全余量（因为校正后穿越频率会右移，原系统相位更负）

4. **计算 $\alpha$**：

$$
\alpha = \frac{1 + \sin\phi_m}{1 - \sin\phi_m}
$$

5. **确定新的穿越频率 $\omega_c'$**：在未校正 Bode 图上，找到幅值为 $-10\log_{10}\alpha$ dB 的频率。这个频率将成为校正后的穿越频率（因为超前校正在 $\omega_m$ 处的增益恰好是 $10\log_{10}\alpha$ dB，把幅值抬到 0 dB）

6. **计算 $T$**：令 $\omega_m = \omega_c'$：

$$
T = \frac{1}{\omega_m \sqrt{\alpha}}
$$

7. **验证**：画出校正后系统的 Bode 图，检查 $PM$ 和其他指标

### 完整设计示例

**问题**：$G(s) = \frac{K}{s(s+2)}$，要求 $K_v = 20$，$PM \geq 50°$。

**第一步**：$K_v = \lim_{s\to 0} sG(s) = K/2 = 20$，所以 $K = 40$。

$G(s) = \frac{40}{s(s+2)}$

**第二步**：未校正系统。

$|G(j\omega)| = \frac{40}{\omega\sqrt{\omega^2+4}}$

令 $|G| = 1$：$\omega_{c0}\sqrt{\omega_{c0}^2+4} = 40$

近似：$\omega_{c0}^2 \approx 40$，$\omega_{c0} \approx 6.1$ rad/s。

$\angle G(j6.1) = -90° - \arctan(6.1/2) = -90° - 71.9° = -161.9°$

$PM_0 = 180° - 161.9° = 18.1°$

需要 $PM \geq 50°$，差距很大。

**第三步**：$\phi_m = 50° - 18.1° + 10° = 41.9°$（取 $\epsilon = 10°$）

**第四步**：$\alpha = \frac{1+\sin 41.9°}{1-\sin 41.9°} = \frac{1+0.668}{1-0.668} = \frac{1.668}{0.332} = 5.02$

取 $\alpha = 5$。

**第五步**：$10\log_{10}5 = 7.0$ dB。在未校正 Bode 图上找幅值为 $-7$ dB 的频率。

$|G(j\omega)| = 10^{-7/20} = 0.447$

$\frac{40}{\omega\sqrt{\omega^2+4}} = 0.447$

$\omega\sqrt{\omega^2+4} = 89.5$

$\omega^2(\omega^2+4) = 8010$

$\omega^4 + 4\omega^2 - 8010 = 0$

$\omega^2 = \frac{-4+\sqrt{16+32040}}{2} = \frac{-4+179.1}{2} = 87.6$

$\omega_c' = \sqrt{87.6} = 9.36$ rad/s

**第六步**：$T = \frac{1}{9.36\sqrt{5}} = \frac{1}{20.9} = 0.0478$

**校正网络**：

$$
G_c(s) = \frac{1 + 5 \times 0.0478 s}{1 + 0.0478 s} = \frac{1 + 0.239s}{1 + 0.0478s}
$$

零点：$s = -1/0.239 = -4.18$

极点：$s = -1/0.0478 = -20.9$

**第七步**：验证。

$\omega_m = 1/(0.0478\sqrt{5}) = 9.36$ rad/s ✓

在 $\omega = 9.36$ 处：

$\angle G_c(j9.36) = \arctan(0.239 \times 9.36) - \arctan(0.0478 \times 9.36) = \arctan(2.24) - \arctan(0.447) = 65.9° - 24.1° = 41.8°$

$\angle G(j9.36) = -90° - \arctan(9.36/2) = -90° - 77.9° = -167.9°$

总相位：$-167.9° + 41.8° = -126.1°$

$PM = 180° - 126.1° = 53.9° > 50°$ ✓

### 超前校正的物理直觉

**为什么超前校正有效？** 从三个角度理解：

**1. 频域角度——"相位注入"**

超前校正在中频段注入正相位，直接补偿原系统在该频段的相位亏损。就像一个"相位电池"，在关键频率处充电。

**2. 时域角度——"近似微分"**

超前校正 $G_c(s) = \frac{1+\alpha Ts}{1+Ts}$ 可以改写为：

$$G_c(s) = \alpha - \frac{\alpha - 1}{1 + Ts/\alpha} \cdot \frac{1}{\alpha}$$

当频率在 $1/(\alpha T) \ll \omega \ll 1/T$ 范围内时，$G_c(s) \approx \alpha Ts$——这正是一个**微分器**！微分器的相位恰好是 $+90°$。

所以超前校正本质上是**带限幅的微分器**——在低频和高频段受限，在中频段近似微分。

**3. 根轨迹角度——"零点吸引"**

超前校正在 $s = -1/(\alpha T)$ 处添加的零点，将根轨迹向左拉，使闭环极点更远离虚轴 → 更稳定、更快。

> 💡 这就是为什么 PID 中的微分项 $K_d s$ 能改善动态性能——它就是一个纯超前校正器（$\alpha \to \infty$ 的极限情况）。实际 PID 用的是 $K_d s / (1 + s/N)$，$N$ 为滤波系数，这正是一个有限 $\alpha$ 的超前校正器。详见 [PID 控制器](/classic/pid-controller#微分项的噪声问题)。

## 滞后校正

### 传递函数

滞后校正网络的传递函数：

$$
G_c(s) = \frac{1 + \beta Ts}{1 + Ts}, \quad \beta < 1
$$

零点在 $s = -1/(\beta T)$，极点在 $s = -1/T$。因为 $\beta < 1$，零点比极点更远离虚轴（更"快"）。

注意：这和超前校正的形式相同，只是 $\beta < 1$（而超前校正 $\alpha > 1$）。

### 频率特性

**幅频特性**：

- 低频（$\omega \ll 1/T$）：增益 $\approx 1$（0 dB）
- 中频（$1/T \ll \omega \ll 1/(\beta T)$）：增益 $\approx \beta$（$20\log_{10}\beta$ dB，负值）
- 高频（$\omega \gg 1/(\beta T)$）：增益 $\approx 1$（0 dB）

关键：滞后校正在中频段**降低**增益。

**相频特性**：

- 提供**负的相位**（相位滞后）
- 但设计时让转折频率远低于穿越频率，使相位滞后在穿越频率处可忽略

### 工作原理

滞后校正的核心思想：**降低穿越频率**。

1. 在低频段，增益几乎不变 → 稳态精度不受影响
2. 在中频段，增益下降 → 穿越频率左移（$\omega_c' < \omega_{c0}$）
3. 新的穿越频率处，原系统的相位更接近 $0°$（因为频率更低了）→ 相位裕度增大

**代价**：带宽减小，响应变慢。

### 滞后校正的物理直觉

**为什么降低增益能提高相位裕度？**

关键在于：原系统的相位滞后是**频率的增函数**——频率越低，相位滞后越小。

$$\angle G(j\omega) = -90° - \arctan(\omega/\omega_1) - \arctan(\omega/\omega_2) - \cdots$$

每个惯性环节 $1/(1+s/\omega_i)$ 贡献的相位滞后 $\arctan(\omega/\omega_i)$ 随 $\omega$ 单调递增。

所以，把穿越频率往左移（降低），自然就来到了相位滞后更小的地方 → 相位裕度增大。

**与积分作用的联系**：

滞后校正 $G_c(s) = \frac{1+\beta Ts}{1+Ts}$（$\beta < 1$）在低频段的增益为 1，在中频段增益为 $\beta < 1$。

这相当于在低频段"额外"放大了 $1/\beta$ 倍——效果类似于积分器提高低频增益，但没有积分器带来的 $-90°$ 相位滞后。

> 💡 这就是 PID 中积分项 $K_i/s$ 的作用——提高低频增益以减小稳态误差。但纯积分器带来 $-90°$ 相位滞后，而滞后校正用"衰减中频"的方式间接达到了类似效果，相位代价更小。

**为什么 $T$ 经常很大？**

滞后校正的设计要求转折频率 $1/T$ 远低于穿越频率 $\omega_c'$（通常 $1/T < \omega_c'/10$）。如果 $\omega_c'$ 本身就很低（比如 0.5 rad/s），那么 $1/T < 0.05$，$T > 20$。再加上 $\beta$ 很小（比如 0.02），$T$ 就更大。

这是滞后校正在模拟电路中的主要困难。解决方案：
- **数字实现**：不受物理限制
- **减小衰减量**：增大 $\beta$，但需要更低的穿越频率
- **改用超前-滞后校正**：分散负担

### 设计步骤

1. **确定开环增益 $K$**：根据稳态误差要求

2. **评估未校正系统**：读取 $PM_0$

3. **确定目标穿越频率 $\omega_c'$**：在未校正相频曲线上，找到相位为 $-180° + PM_{\text{req}} + \epsilon$ 的频率（$\epsilon = 5° \sim 10°$ 补偿滞后网络的相位贡献）

4. **计算需要的增益衰减**：在未校正 Bode 图上，读取 $\omega_c'$ 处的幅值 $|G(j\omega_c')|$（dB）。滞后网络需要把这个幅值衰减到 0 dB：

$$
20\log_{10}\beta = -|G(j\omega_c')|_{\text{dB}}
$$

5. **选择 $T$**：使滞后网络的高转折频率 $1/(\beta T)$ 远低于 $\omega_c'$：

$$
\frac{1}{\beta T} = \frac{\omega_c'}{10} \sim \frac{\omega_c'}{5}
$$

6. **计算 $\beta T$** 和 **$T$**

7. **验证**

### 完整设计示例

**问题**：$G(s) = \frac{K}{s(s+1)(s+2)}$，要求 $K_v = 30$，$PM \geq 40°$。

**第一步**：$K_v = K/(1 \times 2) = K/2 = 30$，$K = 60$。

**第二步**：$G(s) = \frac{60}{s(s+1)(s+2)}$

未校正穿越频率：$\omega_{c0} \approx 5.2$ rad/s

$\angle G(j5.2) = -90° - \arctan(5.2) - \arctan(2.6) = -90° - 79.1° - 69.0° = -238.1°$

$PM_0 = 180° - 238.1° = -58.1°$ → 不稳定！

**第三步**：目标 $PM = 40°$，需要相位为 $-180° + 40° + 5° = -135°$。

$-90° - \arctan(\omega_c') - \arctan(\omega_c'/2) = -135°$

$\arctan(\omega_c') + \arctan(\omega_c'/2) = 45°$

试 $\omega_c' = 0.7$：$\arctan(0.7) + \arctan(0.35) = 35.0° + 19.3° = 54.3°$（偏大）

试 $\omega_c' = 0.5$：$\arctan(0.5) + \arctan(0.25) = 26.6° + 14.0° = 40.6°$（接近）

取 $\omega_c' \approx 0.55$ rad/s。

**第四步**：$|G(j0.55)| = \frac{60}{0.55 \times \sqrt{0.55^2+1} \times \sqrt{0.55^2+4}} = \frac{60}{0.55 \times 1.14 \times 2.07} = \frac{60}{1.296} = 46.3$

$20\log_{10}(46.3) = 33.3$ dB

$20\log_{10}\beta = -33.3$ dB → $\beta = 10^{-33.3/20} = 0.0215$

**第五步**：$\frac{1}{\beta T} = \frac{0.55}{10} = 0.055$

$\beta T = 1/0.055 = 18.2$

$T = 18.2 / 0.0215 = 846$

**校正网络**：

$$
G_c(s) = \frac{1 + 0.0215 \times 846 s}{1 + 846 s} = \frac{1 + 18.2s}{1 + 846s}
$$

零点：$s = -1/18.2 = -0.055$

极点：$s = -1/846 = -0.00118$

**注意**：$T = 846$ 非常大！这意味着滞后校正器的极点非常靠近原点，时间常数极大。在实际电路中可能需要很大的电容。这是滞后校正的一个实际限制。

## 超前-滞后校正

当系统同时需要：

- 增大相位裕度（超前）
- 提高稳态精度（滞后）

单独用超前或滞后可能不够，需要**超前-滞后校正**。

### 传递函数

$$
G_c(s) = \frac{(1 + \alpha T_1 s)(1 + \beta T_2 s)}{(1 + T_1 s)(1 + T_2 s)}, \quad \alpha > 1, \; \beta < 1
$$

可以分解为：

$$
G_c(s) = \underbrace{\frac{1 + \alpha T_1 s}{1 + T_1 s}}_{\text{超前部分}} \times \underbrace{\frac{1 + \beta T_2 s}{1 + T_2 s}}_{\text{滞后部分}}
$$

### 设计思路

1. **先用滞后部分**提高低频增益，满足稳态精度
2. **再用超前部分**增加相位裕度，满足动态性能
3. 两部分的设计可以相对独立，但有交互影响，需要迭代

### 设计步骤

1. 根据稳态精度要求确定 $K$
2. 用滞后部分提供低频增益提升（$\beta$ 的选择）
3. 画出滞后校正后的 Bode 图
4. 用超前部分增加相位裕度（$\alpha$ 的选择）
5. 验证所有指标

### 完整设计示例

**问题**：$G(s) = \frac{K}{s(s+1)(s+10)}$，要求 $K_v = 100$，$PM \geq 45°$。

**第一步**：$K_v = \lim_{s\to 0} sG(s) = K/(1 \times 10) = K/10 = 100$，$K = 1000$。

$G(s) = \frac{1000}{s(s+1)(s+10)}$

**第二步**：未校正系统。

穿越频率：$\frac{1000}{\omega_c\sqrt{\omega_c^2+1}\sqrt{\omega_c^2+100}} = 1$

近似（$\omega_c \gg 10$）：$\frac{1000}{\omega_c^3} \approx 1$，$\omega_{c0} \approx 10$ rad/s。

精确计算：$\omega_{c0} \approx 9.6$ rad/s。

$\angle G(j9.6) = -90° - \arctan(9.6) - \arctan(0.96) = -90° - 84.0° - 43.8° = -217.8°$

$PM_0 = 180° - 217.8° = -37.8°$ → 不稳定！

**分析**：需要 $PM \geq 45°$，差距约 $83°$。超前校正最多提供 ~60° 超前，加上安全余量，不够。而且穿越频率很高（~10 rad/s），超前校正会把它推得更高，高频噪声问题严重。

**策略**：用超前-滞后校正。

**第三步：设计滞后部分**。

滞后部分的目标：降低穿越频率到合理范围，使超前部分有足够的工作空间。

选择滞后部分的转折频率 $1/T_2$ 远低于目标穿越频率。设目标穿越频率 $\omega_c' \approx 3$ rad/s。

在 $\omega = 3$ 处，未校正系统的相位：
$\angle G(j3) = -90° - \arctan(3) - \arctan(0.3) = -90° - 71.6° - 16.7° = -178.3°$

在 $\omega = 3$ 处，未校正系统的幅值：
$|G(j3)| = \frac{1000}{3 \times \sqrt{10} \times \sqrt{109}} = \frac{1000}{3 \times 3.16 \times 10.44} = \frac{1000}{99.0} = 10.1$

$20\log_{10}(10.1) = 20.1$ dB

滞后部分需要在 $\omega = 3$ 处衰减 20.1 dB：
$20\log_{10}\beta = -20.1$ dB → $\beta = 10^{-20.1/20} = 0.099$

取 $\beta = 0.1$。

选择 $T_2$：使滞后部分的高转折频率 $1/(\beta T_2)$ 低于 $\omega_c'$：
$\frac{1}{\beta T_2} = \frac{\omega_c'}{5} = \frac{3}{5} = 0.6$

$\beta T_2 = 1/0.6 = 1.67$

$T_2 = 1.67/0.1 = 16.7$

**滞后部分**：$G_{c,\text{lag}}(s) = \frac{1 + 0.1 \times 16.7 s}{1 + 16.7 s} = \frac{1 + 1.67s}{1 + 16.7s}$

零点：$s = -1/1.67 = -0.6$，极点：$s = -1/16.7 = -0.06$

**第四步**：画出滞后校正后的 Bode 图，确定超前部分需求。

滞后校正在 $\omega = 3$ 处的相位贡献：
$\angle G_{c,\text{lag}}(j3) = \arctan(1.67 \times 3) - \arctan(16.7 \times 3) = \arctan(5.01) - \arctan(50.1) = 78.7° - 88.9° = -10.2°$

滞后校正后，在 $\omega = 3$ 处的总相位：
$-178.3° + (-10.2°) = -188.5°$

需要超前部分提供的相位：
$\phi_m = 45° - (180° - 188.5°) + 5° = 45° - (-8.5°) + 5° = 58.5°$

**第五步：设计超前部分**。

$\alpha = \frac{1 + \sin 58.5°}{1 - \sin 58.5°} = \frac{1 + 0.853}{1 - 0.853} = \frac{1.853}{0.147} = 12.6$

取 $\alpha = 12$。

$10\log_{10}(12) = 10.8$ dB

在滞后校正后的 Bode 图上，找幅值为 $-10.8$ dB 的频率。

滞后校正在 $\omega$ 处的幅值（$\omega \gg 1/(\beta T_2) = 0.6$）约为 $\beta = 0.1$（即 $-20$ dB）。

未校正幅值 + 滞后校正衰减 = 未校正幅值 - 20 dB。

需要：未校正幅值 - 20 dB = -10.8 dB → 未校正幅值 = 9.2 dB。

$|G(j\omega)| = 10^{9.2/20} = 2.88$

$\frac{1000}{\omega\sqrt{\omega^2+1}\sqrt{\omega^2+100}} = 2.88$

数值求解：$\omega_c' \approx 3.2$ rad/s。

令 $\omega_m = 3.2$：

$T_1 = \frac{1}{3.2\sqrt{12}} = \frac{1}{11.09} = 0.0902$

**超前部分**：$G_{c,\text{lead}}(s) = \frac{1 + 12 \times 0.0902 s}{1 + 0.0902 s} = \frac{1 + 1.08s}{1 + 0.0902s}$

零点：$s = -1/1.08 = -0.926$，极点：$s = -1/0.0902 = -11.1$

**完整校正网络**：

$$
G_c(s) = \frac{(1 + 1.08s)(1 + 1.67s)}{(1 + 0.0902s)(1 + 16.7s)}
$$

**第六步：验证**。

在 $\omega = 3.2$ 处：

超前部分相位：$\arctan(1.08 \times 3.2) - \arctan(0.0902 \times 3.2) = \arctan(3.46) - \arctan(0.289) = 73.9° - 16.1° = 57.8°$

滞后部分相位：$-10.2°$（前面已算）

原系统相位：$\angle G(j3.2) = -90° - \arctan(3.2) - \arctan(0.32) = -90° - 72.6° - 17.7° = -180.3°$

总相位：$-180.3° + 57.8° + (-10.2°) = -132.7°$

$PM = 180° - 132.7° = 47.3° > 45°$ ✓

$K_v = 100$ ✓（校正网络低频增益为 1，不影响 $K_v$）

> 💡 注意超前-滞后校正的设计有一定**试探性**——$\beta$ 和 $\omega_c'$ 的选择需要经验。如果验证不满足指标，调整参数重新迭代即可。

## 校正方法的比较

| 特性 | 超前校正 | 滞后校正 | 超前-滞后校正 |
|------|---------|---------|-------------|
| 主要作用 | 增大 $PM$，加快响应 | 增大低频增益，减慢响应 | 兼顾两者 |
| 对稳态精度的影响 | 不变（增益不变） | 间接改善（$K$ 可增大） | 改善 |
| 对带宽的影响 | 增大（响应更快） | 减小（响应更慢） | 可调 |
| 对噪声的影响 | 高频增益增大（不利） | 高频增益减小（有利） | 折中 |
| 实现难度 | 中等 | 时间常数可能很大 | 最复杂 |
| 适用场景 | 动态性能不足 | 稳态精度不足 | 两者都不足 |

### 选择策略

1. 先试**超前校正**：如果稳态精度已满足，只需改善动态性能
2. 再试**滞后校正**：如果动态性能尚可，只需改善稳态精度
3. 最后用**超前-滞后校正**：两者都不满足

## 从根轨迹看校正

校正网络也可以用根轨迹来理解和设计。根轨迹视角提供了频域方法之外的**几何直觉**。

### 超前校正的根轨迹解释

超前校正在 $s = -1/(\alpha T)$ 处加了一个**零点**，在 $s = -1/T$ 处加了一个**极点**。

零点将根轨迹**向左拉**，使闭环极点更靠左（更稳定、更快）。

极点的存在限制了零点的影响范围，使根轨迹在高频段回归原样。

**几何直觉**：根轨迹上的点 $s$ 满足角度条件 $\sum \angle(s - z_i) - \sum \angle(s - p_i) = 180°$。添加零点 $z_c$ 后，在根轨迹的某段上，零点贡献的正角度使更多点满足角度条件 → 根轨迹向左扩展。

### 滞后校正的根轨迹解释

滞后校正在 $s = -1/(\beta T)$ 处加了一个**零点**，在 $s = -1/T$ 处加了一个**极点**，都非常靠近原点。

这对根轨迹的影响很小（零极点几乎抵消），但**增加了开环增益**（因为低频增益为 $\beta < 1$，但配合增大的 $K$，总体效果是低频增益增大）。

**根轨迹的"几乎不变"**意味着闭环极点位置基本不变 → 动态性能变化不大。但增益增大 → 稳态误差减小。

### 超前校正的根轨迹设计法

除了 Bode 图法，还可以直接在根轨迹上设计超前校正器：

1. 根据时域指标（如阻尼比 $\zeta$、自然频率 $\omega_n$）确定**期望闭环极点**位置 $s_d$
2. 计算未校正系统在 $s_d$ 处的角度亏损 $\theta = 180° - \sum \angle(s_d - z_i) + \sum \angle(s_d - p_i)$
3. 超前校正的零点-极点需要提供角度 $\theta$
4. 选择零点位置（通常放在期望极点下方），然后计算极点位置
5. 用幅值条件确定增益 $K$

> 💡 根轨迹设计法的优势是**直接控制闭环极点位置**，但需要精确模型。Bode 图法的优势是基于频率响应，可以从实验数据设计。两种方法互为补充。

### 根轨迹视角下的超前-滞后校正

超前-滞后校正在根轨迹上的效果：

- **零点** $-1/(\alpha T_1)$ 和 $-1/(\beta T_2)$：将根轨迹向左拉
- **极点** $-1/T_1$ 和 $-1/T_2$：限制零点的影响范围

四个零极点的位置决定了根轨迹的"变形"方式。超前部分的零极点离原点较远（影响中高频段），滞后部分的零极点靠近原点（影响低频段）。

### PID与校正网络的关系

回忆 PID 控制器：

$$
C(s) = K_p + \frac{K_i}{s} + K_d s = K_p\left(1 + \frac{1}{T_i s} + T_d s\right)
$$

从校正网络的角度看：

- **微分项 $K_d s$**：等效于超前校正（提供相位超前）
- **积分项 $K_i/s$**：等效于滞后校正（提高低频增益）
- **PID** ≈ 超前-滞后校正 + 积分

这就是为什么 PID 在工业中如此强大——它本质上就是一个自动的超前-滞后校正器。

## 工程实例：电机速度控制设计

### 问题描述

直流电机速度控制，被控对象 $G(s) = \frac{10}{s(s+5)}$。

设计指标：

- 速度误差系数 $K_v \geq 100$
- 相位裕度 $PM \geq 50°$

### 第一步：确定增益

$K_v = \lim_{s\to 0} s \cdot \frac{10K}{s(s+5)} = \frac{10K}{5} = 2K$

要求 $K_v \geq 100$，$K \geq 50$。取 $K = 50$。

$G(s) = \frac{500}{s(s+5)}$

### 第二步：未校正系统

穿越频率：$\frac{500}{\omega_c \sqrt{\omega_c^2+25}} = 1$

$\omega_c^2(\omega_c^2+25) = 250000$

$\omega_c^4 + 25\omega_c^2 - 250000 = 0$

$\omega_c^2 = \frac{-25+\sqrt{625+1000000}}{2} = \frac{-25+1000.3}{2} = 487.7$

$\omega_{c0} = 22.1$ rad/s

$\angle G(j22.1) = -90° - \arctan(22.1/5) = -90° - 77.3° = -167.3°$

$PM_0 = 180° - 167.3° = 12.7°$

需要 $PM \geq 50°$，差距很大。用超前校正。

### 第三步：超前校正设计

$\phi_m = 50° - 12.7° + 10° = 47.3°$

$\alpha = \frac{1+\sin 47.3°}{1-\sin 47.3°} = \frac{1+0.735}{1-0.735} = \frac{1.735}{0.265} = 6.55$

取 $\alpha = 6.5$。

$10\log_{10}(6.5) = 8.13$ dB

找未校正幅值为 $-8.13$ dB 的频率：

$|G| = 10^{-8.13/20} = 0.391$

$\frac{500}{\omega\sqrt{\omega^2+25}} = 0.391$

$\omega\sqrt{\omega^2+25} = 1279$

数值求解：$\omega_c' \approx 34.5$ rad/s

$T = \frac{1}{34.5\sqrt{6.5}} = \frac{1}{88.0} = 0.0114$

**超前校正网络**：

$$
G_c(s) = \frac{1 + 6.5 \times 0.0114 s}{1 + 0.0114 s} = \frac{1 + 0.0741s}{1 + 0.0114s}
$$

### 第四步：验证

$\omega_m = \frac{1}{0.0114\sqrt{6.5}} = 34.5$ rad/s

在 $\omega = 34.5$ 处：

$\angle G_c = \arctan(0.0741 \times 34.5) - \arctan(0.0114 \times 34.5) = \arctan(2.56) - \arctan(0.393) = 68.6° - 21.5° = 47.1°$

$\angle G = -90° - \arctan(34.5/5) = -90° - 81.8° = -171.8°$

$PM = 180° - 171.8° + 47.1° = 55.3° > 50°$ ✓

$K_v = 100$ ✓（超前校正不改变低频增益）

### 工程实现细节

设计完校正网络后，实际实现还需要考虑以下问题：

#### 执行器饱和与抗饱和

实际执行器（电机、阀门、加热器）都有**输出限幅**。当控制器输出超过限幅时，执行器饱和，实际输入不再等于控制器输出。

**饱和的后果**：

- 闭环系统暂时变成**开环**（控制量不再受反馈影响）
- 如果饱和持续，积分器（或滞后校正器的慢极点）会**累积误差**（windup）
- 当误差反向时，积分器需要很长时间"退饱和" → 产生大幅超调

**抗积分饱和（Anti-windup）**：

最常用的方法是**回溯法（back-calculation）**：

$$
u = \text{sat}(v), \quad e_s = u - v, \quad \dot{x}_c = f(x_c) + K_b \cdot e_s
$$

其中 $v$ 是未限幅的控制器输出，$u$ 是限幅后的实际输出，$e_s$ 是饱和误差，$K_b$ 是回溯增益。当 $u = v$（未饱和）时，$e_s = 0$，不影响正常控制；当 $u \neq v$（饱和）时，$e_s \neq 0$，通过 $K_b$ 将积分器"拉回"。

> 💡 抗饱和是工业 PID 控制器的**标配功能**。没有抗饱和的 PID 在设定值大幅变化时会产生严重的"积分饱和超调"。

#### 数字实现

现代控制器几乎都用数字计算机（PLC、DSP、MCU）实现。连续校正器 $G_c(s)$ 需要**离散化**：

| 方法 | 公式 | 特点 |
|------|------|------|
| 前向差分 | $s \approx (z-1)/T_s$ | 简单，但可能不稳定 |
| 后向差分 | $s \approx (z-1)/(zT_s)$ | 稳定，但频率响应有畸变 |
| Tustin（双线性） | $s \approx \frac{2}{T_s}\frac{z-1}{z+1}$ | 最常用，频率响应保真 |

**采样频率的选择**：经验法则 $\omega_s \geq 10 \omega_c$（采样频率至少是穿越频率的 10 倍）。如果 $\omega_c = 34.5$ rad/s（~5.5 Hz），则 $f_s \geq 55$ Hz，$T_s \leq 18$ ms。

**量化效应**：ADC/DAC 的位数有限（通常 12~16 位），参数的量化可能导致校正器性能轻微退化。对于高增益校正器（$\alpha$ 很大），量化影响更显著。

#### 参数灵敏度

实际元件有容差（电阻 ±1%，电容 ±5%），校正器参数不可能精确实现。**灵敏度分析**是设计验证的重要一步：

$$
S_\alpha^{\phi_m} = \frac{\partial \phi_m}{\partial \alpha} \cdot \frac{\alpha}{\phi_m}
$$

如果灵敏度很高（参数变化 1% 导致性能变化 10%），说明设计对参数过于敏感，需要重新设计或选择更高精度的元件。

## 深入讨论

### 超前校正的局限

超前校正有一个固有的矛盾：

- 要获得更大的 $\phi_m$，需要更大的 $\alpha$
- 更大的 $\alpha$ 意味着更高的高频增益 → 更多的高频噪声

工程实践中的限制：

- $\phi_m$ 一般不超过 **55°~60°**
- 如果需要更大的相位超前，考虑用两级超前校正，或者改用超前-滞后校正

### 滞后校正的局限

滞后校正的主要问题是**时间常数可能非常大**。

在前面的例子中，$T = 846$ 秒——这意味着用模拟电路实现需要一个 846 秒时间常数的环节，物理上几乎不可能（需要极大的电容或电感）。

解决方案：

- 用数字控制器实现（不受物理限制）
- 减小 $\beta$ 的衰减量，增大 $T$（折中方案）
- 改用超前-滞后校正，减小单个环节的负担

### 校正与鲁棒性

好的校正设计不仅满足标称指标，还要保证**鲁棒性**：

- 超前校正增大了穿越频率，但也增大了带宽 → 对高频未建模动态更敏感
- 滞后校正减小了带宽 → 对高频动态不敏感，但响应变慢
- 超前-滞后校正可以灵活调整，但设计更复杂

回忆 [频率响应设计法](/classic/frequency-response-design) 中的灵敏度函数 $S = 1/(1+G)$ 和补灵敏度函数 $T = G/(1+G)$。校正设计的目标可以重新表述为：

| 频段 | 目标 | 对应灵敏度 |
|------|------|-----------|
| 低频 | $|L| \gg 1$ → $|S| \approx 1/|L|$ 小 | 好的干扰抑制和跟踪精度 |
| 中频 | $|L| \approx 1$，$PM$ 足够 | 好的动态性能和鲁棒性 |
| 高频 | $|L| \ll 1$ → $|T| \approx |L|$ 小 | 好的噪声抑制 |

**超前校正**抬高中频 → 增大带宽 → $|T|$ 的峰值可能增大 → 对高频未建模动态更敏感。

**滞后校正**降低中频 → 减小带宽 → $|T|$ 的峰值减小 → 鲁棒性更好，但低频段 $|S|$ 的改善有限。

> 💡 这就是为什么工业中常用"PID + 低通滤波器"的组合——PID 提供中频整形，低通滤波器限制高频增益，保证鲁棒性。

### 环路整形（Loop Shaping）

校正网络设计的本质是**环路整形**——通过改变开环传递函数 $L(s) = G_c(s)G(s)$ 的 Bode 图形状，使系统满足性能指标。

环路整形的核心思想（由 Bode 在 1945 年提出）：

1. **低频段**：增益足够高 → 稳态精度
2. **中频段**：以 $-20$ dB/dec 的斜率穿越 0 dB 线 → 足够的相位裕度
3. **高频段**：增益足够低 → 噪声抑制

"中频段 $-20$ dB/dec 穿越"是一条经验法则：如果开环幅频曲线在穿越频率附近以 $-20$ dB/dec 的斜率下降，那么该处的相位约为 $-90°$（对应一个积分器），$PM \approx 90°$。斜率越陡（$-40$ dB/dec），相位越接近 $-180°$，$PM$ 越小。

### 现代方法 vs 经典校正

经典校正方法（超前/滞后/PID）在工业中仍然广泛使用，但现代控制理论提供了更强大的工具：

| 方法 | 优势 | 局限 |
|------|------|------|
| 经典校正 | 直观、简单、工程验证 | 单输入单输出为主 |
| 状态反馈+观测器 | 系统化、多变量 | 需要精确模型 |
| LQR/LQG | 最优性、多变量 | 需要权重选择 |
| H∞ | 鲁棒性保证 | 计算复杂 |
| MPC | 约束处理、多变量 | 计算量大 |

经典校正方法的思想（环路整形）在现代方法中仍然适用——只是"整形"的工具更丰富了。

### 执行器饱和与抗积分饱和

实际系统中，执行器（电机、阀门等）都有输出限幅。当控制器输出超出限幅时，积分项会继续累积（积分饱和），导致严重的超调和振荡。

## 小结

校正网络设计的核心是在 Bode 图上"雕刻"开环频率特性：

| 校正类型 | 改变什么 | 效果 | 代价 |
|---------|---------|------|------|
| 超前 | 中频段相位 | 增大 $PM$，加快响应 | 高频噪声增大 |
| 滞后 | 中频段增益 | 增大低频增益，减慢响应 | 时间常数大，响应慢 |
| 超前-滞后 | 两者 | 兼顾稳态精度和动态性能 | 设计复杂 |

**设计口诀**：

- 稳态不够加**滞后**，动态不够加**超前**
- 两个都不够，**超前-滞后**来帮忙
- 先满足稳态精度（定 $K$），再改善动态性能（定校正参数）

<Callout variant="warning">
  超前校正会放大高频噪声。实际应用中，超前校正器的高频增益 $\alpha$ 不宜过大（通常 $\alpha < 10$），必要时在超前校正器后加低通滤波器。
</Callout>

## 答案

**答案1**：

(a) $\phi_m = \arcsin\frac{\alpha-1}{\alpha+1} = \arcsin\frac{9}{11} = \arcsin(0.818) = 54.9°$

(b) $\omega_m = \frac{1}{T\sqrt{\alpha}} = \frac{1}{T\sqrt{10}} = \frac{1}{3.16T}$

(c) $|G_c(j\omega_m)| = \left|\frac{1+j\alpha T \cdot \frac{1}{T\sqrt{\alpha}}}{1+jT \cdot \frac{1}{T\sqrt{\alpha}}}\right| = \left|\frac{1+j\sqrt{\alpha}}{1+j/\sqrt{\alpha}}\right|$

$= \frac{\sqrt{1+\alpha}}{\sqrt{1+1/\alpha}} = \frac{\sqrt{1+\alpha}}{\sqrt{(\alpha+1)/\alpha}} = \sqrt{\alpha}$

增益 $= 20\log_{10}\sqrt{10} = 10\log_{10}(10) = 10$ dB。

**答案2**：

(a) $K_v = \lim_{s\to 0} s \cdot \frac{K}{s(s+4)} = \frac{K}{4} = 100$，$K = 400$。

(b) $G(s) = \frac{400}{s(s+4)}$

穿越频率：$\frac{400}{\omega_c\sqrt{\omega_c^2+16}} = 1$

$\omega_c^4 + 16\omega_c^2 - 160000 = 0$

$\omega_c^2 = \frac{-16+\sqrt{256+640000}}{2} = \frac{-16+800.2}{2} = 392.1$

$\omega_{c0} = 19.8$ rad/s

$\angle G(j19.8) = -90° - \arctan(19.8/4) = -90° - 78.6° = -168.6°$

$PM_0 = 180° - 168.6° = 11.4°$

(c) 超前校正设计：

$\phi_m = 50° - 11.4° + 10° = 48.6°$

$\alpha = \frac{1+\sin 48.6°}{1-\sin 48.6°} = \frac{1+0.750}{1-0.750} = \frac{1.750}{0.250} = 7.0$

$10\log_{10}(7) = 8.45$ dB

找 $|G| = 10^{-8.45/20} = 0.377$ 的频率：

$\frac{400}{\omega\sqrt{\omega^2+16}} = 0.377$

$\omega\sqrt{\omega^2+16} = 1061$

数值求解：$\omega_c' \approx 32.0$ rad/s

$T = \frac{1}{32.0\sqrt{7}} = \frac{1}{84.7} = 0.0118$

**超前校正网络**：

$$
G_c(s) = \frac{1 + 7 \times 0.0118 s}{1 + 0.0118 s} = \frac{1 + 0.0826s}{1 + 0.0118s}
$$

验证：$\omega_m = 1/(0.0118\sqrt{7}) = 32.0$ rad/s ✓

**答案3**：

**为什么滞后校正能提高 $PM$**：

滞后校正在中频段降低增益（$20\log_{10}\beta < 0$），使开环幅频曲线下移。穿越频率 $\omega_c$ 左移到更低的频率。

在更低的频率处，原系统的相位滞后更小（因为惯性环节的相位滞后 $\arctan(\omega/\omega_0)$ 随频率降低而减小）。所以在新穿越频率处，总相位更接近 $0°$，相位裕度增大。

**为什么响应速度降低**：

穿越频率 $\omega_c$ 直接决定闭环带宽（$\omega_b \approx \omega_c$）。带宽越小，上升时间越长（$t_r \approx 1.8/\omega_c$）。

滞后校正使 $\omega_c$ 减小 → 带宽减小 → 响应变慢。

**物理直觉**：滞后校正通过"减慢系统"来"稳定系统"——用速度换取稳定性。

**答案4**：

$K_v = K/(1 \times 5) = K/5 = 50$，$K = 250$。

$G(s) = \frac{250}{s(s+1)(s+5)}$

未校正穿越频率：$\omega_{c0} \approx 6.7$ rad/s

$\angle G(j6.7) = -90° - \arctan(6.7) - \arctan(1.34) = -90° - 81.5° - 53.3° = -224.8°$

$PM_0 = 180° - 224.8° = -44.8°$ → 不稳定！

需要 $PM \geq 45°$，差距约 $90°$。

**判断**：

- 超前校正：需要 $\phi_m \approx 90° + 10° = 100°$，远超超前校正的能力极限（$\phi_m$ 最大约 65°）。**超前校正不可行**。
- 滞后校正：可以，但穿越频率需要降到很低（约 1 rad/s 以下），响应会非常慢。
- **超前-滞后校正**：最佳选择。滞后部分先降低穿越频率到合理范围，超前部分再提供额外的相位补偿。

**答案5**：

**物理实现角度**：

$\alpha$ 越大，零极点间距越大。零点 $-1/(\alpha T)$ 非常靠近原点，极点 $-1/T$ 远离原点。

模拟电路实现时，需要非常大的时间常数比（$T_{\max}/T_{\min} = \alpha$）。$\alpha = 100$ 意味着电容比 100:1，电阻比 100:1，在实际电路中难以精确实现。

**噪声角度**：

超前校正在高频段的增益为 $\alpha$。$\alpha$ 越大，高频噪声被放大得越多。

如果传感器噪声的频谱在超前校正器的高频段有显著分量，输出信噪比会严重恶化。

工程实践中，$\alpha$ 通常限制在 **5~15** 之间。如果需要更大的相位超前，用两级超前校正（每级 $\alpha \approx 5$，总超前角更大但噪声分散在两级）。

**答案6**：

在 $\omega_m = \frac{1}{T\sqrt{\alpha}}$ 处：

$$
G_c(j\omega_m) = \frac{1 + j\alpha T \cdot \frac{1}{T\sqrt{\alpha}}}{1 + jT \cdot \frac{1}{T\sqrt{\alpha}}} = \frac{1 + j\sqrt{\alpha}}{1 + j/\sqrt{\alpha}}
$$

幅值：

$$
|G_c(j\omega_m)| = \frac{|1 + j\sqrt{\alpha}|}{|1 + j/\sqrt{\alpha}|} = \frac{\sqrt{1 + \alpha}}{\sqrt{1 + 1/\alpha}} = \frac{\sqrt{1+\alpha}}{\sqrt{\frac{\alpha+1}{\alpha}}} = \frac{\sqrt{1+\alpha} \cdot \sqrt{\alpha}}{\sqrt{\alpha+1}} = \sqrt{\alpha}
$$

增益（dB）$= 20\log_{10}\sqrt{\alpha} = 10\log_{10}\alpha$ dB。$\blacksquare$

这就是超前校正设计第五步的依据：超前网络在 $\omega_m$ 处把幅值抬高了 $10\log_{10}\alpha$ dB，所以我们要在未校正 Bode 图上找到幅值为 $-10\log_{10}\alpha$ 的频率作为新的穿越频率。

**答案7**：

**相同点**：

| 方面 | PID | 超前-滞后校正 |
|------|-----|-------------|
| 结构 | 两个零点 + 一个原点极点 | 两个零点 + 两个极点 |
| 功能 | 积分消稳态误差，微分增阻尼 | 滞后部分增低频增益，超前部分增PM |
| 频域效果 | 低频增益↑，中频相位↑ | 低频增益↑，中频相位↑ |

**不同点**：

| 方面 | PID | 超前-滞后校正 |
|------|-----|-------------|
| 原点极点 | 有（积分项 $1/s$） | 无（除非额外加） |
| 高频增益 | 无限增大（$K_d s$） | 有限（$\alpha/\beta$ 倍） |
| 参数物理意义 | $K_p, T_i, T_d$ 直接可调 | $\alpha, \beta, T_1, T_2$ 间接设计 |
| 稳态误差 | 对阶跃输入零稳态误差（积分作用） | 不能保证零稳态误差（无积分） |
| 噪声 | 微分项放大高频噪声 | 高频增益有限，噪声问题较轻 |
| 设计方法 | 经验公式（Z-N法等） | Bode图/根轨迹系统化设计 |

**本质联系**：PID 可以看作"带积分的超前-滞后校正"。积分项提供无穷大的低频增益（消除稳态误差），微分项提供相位超前（改善动态性能）。超前-滞后校正没有积分项，所以不能消除阶跃输入的稳态误差，但高频特性更好（噪声抑制更强）。

**答案9**：

滞后校正网络 $G_c(s) = \frac{1+\beta Ts}{1+Ts}$，$\beta < 1$。

相位：$\phi(\omega) = \arctan(\beta T\omega) - \arctan(T\omega)$

因为 $\beta < 1$，$\beta T\omega < T\omega$，而 $\arctan$ 是单调递增函数，所以 $\arctan(\beta T\omega) < \arctan(T\omega)$，即 $\phi(\omega) < 0$。$\blacksquare$

**最大滞后相位**：对 $\phi(\omega)$ 求导并令为零，类似超前校正的推导，得 $\omega_{m,\text{lag}} = \frac{1}{T\sqrt{\beta}}$。

最大滞后相位：

$$|\phi_{m,\text{lag}}| = \arctan(T\omega_m) - \arctan(\beta T\omega_m) = \arctan(1/\sqrt{\beta}) - \arctan(\sqrt{\beta})$$

利用 $\arctan(x) + \arctan(1/x) = \pi/2$：

$$|\phi_{m,\text{lag}}| = \frac{\pi}{2} - 2\arctan(\sqrt{\beta}) = \arcsin\frac{1-\beta}{1+\beta}$$

注意：这与超前校正的公式 $\phi_m = \arcsin\frac{\alpha-1}{\alpha+1}$ 形式完全相同，只是将 $\alpha$ 替换为 $1/\beta$。这体现了超前/滞后校正的**对偶性**。
