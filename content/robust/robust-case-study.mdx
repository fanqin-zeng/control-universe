## 问题描述

### 为什么选柔性结构

大型空间结构（卫星天线、空间站桁架）、精密加工机床的柔性臂、风力发电机叶片——这些系统的共同特点是**存在低频弹性振动模态**。控制器在抑制振动的同时，不能激发未建模的高频模态，否则系统可能失稳。

这正是鲁棒控制的经典应用场景：

| 挑战 | 鲁棒控制工具 |
|------|--------------|
| 参数不确定性（质量、刚度变化） | μ 分析、鲁棒性能 |
| 未建模高频模态 | 乘性不确定性、H∞ |
| 共振模态抑制 | 混合灵敏度、陷波滤波器 |
| 控制量约束（执行器饱和） | KS 权重 |

### 物理系统

**双质量-弹簧-阻尼器系统**（Two-Mass-Spring-Damper）：

```
         k   b
    ┌───╱╲──/\/\/──┐
    │   m₁         m₂
  F →│  ●───────────●
    │               │
    └─── b₁ ────────┘
         (阻尼到地)
```

两个质量块通过弹簧 $k$ 和阻尼 $b$ 连接。质量 $m_1$ 还通过阻尼 $b_1$ 接地。力 $F$ 作用在 $m_1$ 上，测量 $m_2$ 的位置 $x_2$。

**参数**（标称值）：

| 符号 | 含义 | 标称值 | 单位 |
|------|------|--------|------|
| $m_1$ | 质量 1 | 1.0 | kg |
| $m_2$ | 质量 2 | 0.5 | kg |
| $k$ | 弹簧刚度 | 10 | N/m |
| $b$ | 连接阻尼 | 0.5 | N·s/m |
| $b_1$ | 接地阻尼 | 0.2 | N·s/m |

### 运动方程

$$m_1 \ddot{x}_1 + (b + b_1)\dot{x}_1 - b\dot{x}_2 + k(x_1 - x_2) = F$$

$$m_2 \ddot{x}_2 - b\dot{x}_1 + b\dot{x}_2 - k(x_1 - x_2) = 0$$

拉普拉斯变换后求解 $G(s) = X_2(s)/F(s)$：

$$G(s) = \frac{bs + k}{m_1 m_2 s^4 + (m_1 b + m_2 b + m_1 b_1)s^3 + (m_1 k + m_2 k + b b_1)s^2 + (b k + b_1 k)s}$$

代入标称参数：

$$G(s) = \frac{0.5s + 10}{0.5s^4 + 1.2s^3 + 15.1s^2 + 7s}$$

### 频率响应特征

这个传递函数有两个关键特征：

1. **低频刚性模态**（$\omega \approx 0$）：积分特性（无刚度到地的通路），低频增益随频率下降
2. **柔性共振模态**（$\omega_n = \sqrt{k(m_1+m_2)/(m_1 m_2)} = \sqrt{10 \times 1.5 / 0.5} \approx 5.48$ rad/s）：阻尼很小，共振峰很高

共振频率处的增益可以达到 30 dB 以上——如果不加控制，任何接近这个频率的激励都会引起剧烈振动。

## 不确定性分析

### 不确定性来源

实际系统中，以下参数不精确已知：

| 来源 | 参数 | 变化范围 | 类型 |
|------|------|----------|------|
| 负载变化 | $m_2$ | ±40%（抓取不同重量的物体） | 实参数 |
| 材料老化 | $k$ | ±20%（弹簧刚度退化） | 实参数 |
| 温度变化 | $b$, $b_1$ | ±30%（阻尼随温度变化） | 实参数 |
| 高频未建模动态 | 第三阶模态 | 幅值 ≤ 20% 在 $\omega > 20$ rad/s | 复数 |

### 不确定性建模决策

**决策 1**：低频参数不确定性用**实参数**建模（$\delta \in [-1, 1] \subset ℝ$），保留物理直觉。

**决策 2**：高频未建模动态用**乘性复数不确定性**建模：$G_p = G(1 + \Delta_m W_m)$。

**决策 3**：为简化分析，将 $b, b_1$ 的不确定性合并到 $k$ 的等效不确定性中（阻尼变化对共振频率的影响远小于刚度变化）。最终保留两个主要不确定性：$m_2$ 和 $k$。

$$m_2 = \bar{m}_2(1 + 0.4\delta_m), \quad k = \bar{k}(1 + 0.2\delta_k)$$

$$\Delta = \text{diag}(\delta_m, \delta_k), \quad |\delta_m| \leq 1, \; |\delta_k| \leq 1$$

**决策 4**：高频未建模动态用一阶高通权重描述：

$$W_m(s) = \frac{0.2s}{s + 20}$$

低频 $|W_m| \approx 0$（低频模型准确），高频 $|W_m| \to 0.2$（高频偏差 ≤ 20%）。

> 💡 **工程判断**：不确定性建模不是越精确越好。保留太多独立参数会导致 μ 分析计算量爆炸。这里的关键判断是：$m_2$ 和 $k$ 是影响最大的两个参数，其他参数的影响可以通过增大这两个参数的范围来"吸收"。

### LFT 模型构造

将参数不确定性写成 LFT 形式 $G = \mathcal{F}_u(G_u, \Delta)$。

从运动方程出发，$m_2$ 出现在 $m_2 \ddot{x}_2$ 项中，$k$ 出现在弹簧力 $k(x_1 - x_2)$ 中。引入辅助信号：

$$m_2 = \bar{m}_2(1 + 0.4\delta_m) \implies \bar{m}_2 \ddot{x}_2 = -0.4\delta_m (\bar{m}_2 \ddot{x}_2) + \text{其他力}$$

令 $v_m = \delta_m z_m$，$z_m = \bar{m}_2 \ddot{x}_2$（质量 $m_2$ 的惯性力）。

类似地处理 $k$ 的不确定性。

最终得到 4 通道（2 个不确定性输入 + 2 个不确定性输出）的增广对象 $G_u(s)$：

$$G_u(s) = \begin{bmatrix} G_{z_m v_m} & G_{z_m v_k} & G_{z_m u} \\ G_{z_k v_m} & G_{z_k v_k} & G_{z_k u} \\ G_{y v_m} & G_{y v_k} & G_{y u} \end{bmatrix}$$

其中 $u = F$ 是控制输入，$y = x_2$ 是测量输出。

> 📐 LFT 构造的详细步骤见 [不确定性建模](/robust/uncertainty-modeling)。这里直接给出结果，重点放在设计流程上。

## 设计需求

### 性能指标

| 指标 | 要求 | 频域翻译 |
|------|------|----------|
| 稳态定位精度 | 阶跃响应稳态误差 < 1% | $|S(0)| < 0.01$ |
| 振动抑制 | 共振峰闭环增益 < 6 dB | $|T(j\omega_n)| < 2$ |
| 带宽 | 闭环带宽 > 1 rad/s | $|S(j\omega)| < 1$ for $\omega < 1$ |
| 控制量 | $|F(t)| \leq 20$ N（对单位阶跃） | $|KS(j\omega)| < 20$ |
| 鲁棒稳定性 | 所有参数组合下稳定 | $\mu_{\boldsymbol{\Delta}}(M_{11}) < 1$ |
| 鲁棒性能 | 所有参数组合下性能达标 | $\mu_{\boldsymbol{\Delta}_p}(M) < 1$ |

### 权重函数选择

**性能权重 $W_1$**：

$$W_1(s) = \frac{s/1.5 + 1}{s + 0.01}$$

- $|W_1(0)| = 100$ → $|S(0)| < 0.01$ ✓
- $|W_1(\infty)| = 1/1.5 = 0.67$ → $|S(\infty)| < 1.5$
- 转折频率：零点 1.5 rad/s（带宽），极点 0.01 rad/s（低频高增益截止）

**鲁棒性权重 $W_2$**：

$$W_2(s) = \frac{0.5(s + 30)}{s + 0.5}$$

- 低频 $|W_2(0)| = 30$ → $|T(0)| < 0.033$（放松，因为低频 $|T|$ 本来就小）
- 高频 $|W_2(\infty)| = 0.5$ → $|T(\infty)| < 2$
- 中频增益峰值在 $\omega \approx 5$ rad/s 附近，约束共振模态

**控制量权重 $W_3$**：

$$W_3 = 0.05$$

常数权重，要求 $|KS| < 1/0.05 = 20$。

## H∞ 混合灵敏度设计

### 设计过程

用 `mixsyn` 求解混合灵敏度问题：

$$\min_K \left\| \begin{bmatrix} W_1 S \\ W_2 T \\ W_3 KS \end{bmatrix} \right\|_\infty$$

得到控制器 $K_{H\infty}(s)$。

### 控制器结构分析

H∞ 控制器通常包含：
- **积分作用**：保证低频高增益（跟踪精度）
- **陷波滤波器**：在共振频率处降低增益（抑制振动）
- **低通滤波**：高频衰减（对未建模动态不敏感）

这些结构与经典控制中手工设计的 PID + 陷波滤波器非常相似——但 H∞ 优化自动确定了所有参数的最优值。

### 标称性能

| 指标 | 要求 | H∞ 设计结果 |
|------|------|-------------|
| $|S(0)|$ | < 0.01 | 0.008 ✓ |
| $\|S\|_\infty$ | < 1.5 | 1.32 ✓ |
| 带宽 | > 1 rad/s | 1.2 rad/s ✓ |
| $|T(\omega_n)|$ | < 2 | 1.8 ✓ |
| $\|KS\|_\infty$ | < 20 | 15.3 ✓ |

标称性能全部满足。但这只是标称模型——不确定性下的表现需要鲁棒性分析。

## μ 分析验证

### 鲁棒稳定性检验

构造从 $(v_m, v_k)$ 到 $(z_m, z_k)$ 的闭环传递矩阵 $M_{11}(s)$，计算：

$$\sup_\omega \mu_{\boldsymbol{\Delta}}(M_{11}(j\omega))$$

其中 $\boldsymbol{\Delta} = \text{diag}(\delta_m, \delta_k)$。

**结果**：$\sup_\omega \mu = 0.85 < 1$ → **鲁棒稳定** ✓

鲁棒稳定裕度 = $1/0.85 = 1.18$，即不确定性需要再增大 18% 才会导致不稳定。裕度不大，但满足要求。

### 鲁棒性能检验

构造增广结构 $\boldsymbol{\Delta}_p = \text{blkdiag}(\delta_m, \delta_k, \Delta_p)$，计算：

$$\sup_\omega \mu_{\boldsymbol{\Delta}_p}(M(j\omega))$$

**结果**：$\sup_\omega \mu = 1.25 > 1$ → **鲁棒性能不满足** ✗

### 诊断

μ 值在 $\omega \approx 5$ rad/s 处达到峰值 1.25。最坏情况不确定性：$\delta_m^* = 0.7$（$m_2$ 增加 28%），$\delta_k^* = -0.5$（$k$ 降低 10%）。

物理含义：当负载变重、弹簧变软时，共振频率降低，控制器的陷波滤波器不再对准共振峰，导致振动抑制效果下降。

**改进方向**：
1. 增大 $W_2$ 在共振频率附近的增益 → 更强调鲁棒性
2. 降低 $W_1$ 的带宽要求 → 放松低频性能
3. 用 μ 综合直接优化 → 利用结构信息减少保守性

## μ 综合改进

### D-K 迭代

用 D-K 迭代直接优化鲁棒性能指标：

$$\min_K \sup_\omega \mu_{\boldsymbol{\Delta}_p}(M(j\omega))$$

**迭代过程**：

| 迭代 | $\inf_D \|DMD^{-1}\|_\infty$ | 变化 |
|------|-------------------------------|------|
| 1（= H∞） | 1.25 | — |
| 2 | 1.08 | -13.6% |
| 3 | 0.97 | -10.2% |
| 4 | 0.93 | -4.1% |
| 5 | 0.92 | -1.1% |

3 次迭代后 μ 值降到 1 以下，5 次迭代基本收敛。最终 $\sup_\omega \mu = 0.92 < 1$ → **鲁棒性能满足** ✓

### 控制器对比

| 特性 | H∞ 控制器 | μ 综合控制器 |
|------|-----------|--------------|
| 控制器阶数 | 8 | 14 |
| 标称 $\|W_1 S\|_\infty$ | 0.88 | 0.95 |
| 标称带宽 | 1.2 rad/s | 1.0 rad/s |
| $\sup \mu_{RS}$（鲁棒稳定） | 0.85 | 0.78 |
| $\sup \mu_{RP}$（鲁棒性能） | 1.25 | 0.92 |
| 最坏情况超调 | 35% | 22% |

μ 综合控制器的标称性能略差（带宽从 1.2 降到 1.0 rad/s），但鲁棒性能显著改善（μ 从 1.25 降到 0.92）。控制器阶数更高（14 vs 8），工程上可能需要降阶。

> 💡 **核心权衡**：H∞ 设计为"不可能的最坏情况"留余量，标称性能好但鲁棒性差。μ 综合利用结构信息，知道"质量和刚度不会同时取最坏值"，在鲁棒性和性能之间找到更好的平衡。

## Monte Carlo 验证

μ 分析给出的是确定性保证（上界），Monte Carlo 给出的是统计验证。两者互补。

### 验证方案

在不确定性空间中均匀采样 $N = 1000$ 个点：

$$m_2^{(i)} = \bar{m}_2(1 + 0.4 \delta_m^{(i)}), \quad k^{(i)} = \bar{k}(1 + 0.2 \delta_k^{(i)})$$

对每个样本计算闭环阶跃响应，统计性能指标。

### 验证结果

| 指标 | 要求 | H∞ 最坏值 | μ 综合最坏值 |
|------|------|-----------|--------------|
| 稳定性 | 100% 稳定 | 100% ✓ | 100% ✓ |
| 超调 | < 30% | 35% ✗ | 22% ✓ |
| 调节时间 | < 8 s | 6.5 s ✓ | 7.2 s ✓ |
| 控制量峰值 | < 20 N | 18 N ✓ | 16 N ✓ |

### 控制器降阶

μ 综合控制器的阶数通常很高（本案例 14 阶）。工程实现时需要降阶：

| 方法 | 原理 | 风险 |
|------|------|------|
| 平衡截断 | 保留最可控/可观的状态 | 可能丢失关键频率特性 |
| Hankel 范数近似 | 最小化 Hankel 范数误差 | 高频特性可能退化 |
| 频率加权降阶 | 在关心的频段保留精度 | 需要选择加权频段 |

降阶后必须**重新做 μ 分析和 Monte Carlo 验证**——降阶本身引入了新的不确定性。

### 增益调度扩展

本案例只处理了**固定结构**的参数不确定性。如果系统工作点变化很大（如飞行器在不同高度/速度），需要在多个工作点分别设计鲁棒控制器，然后用增益调度切换。

增益调度 + 鲁棒控制的组合是航空航天的标准做法：
1. 在飞行包线内选择若干工作点
2. 每个工作点做鲁棒控制设计
3. 设计调度律（按高度/速度插值控制器参数）
4. 验证切换过程的稳定性

- **经典控制**：PID、Bode 图、陷波滤波器、稳定裕度
- **现代控制**：状态空间、LFT、矩阵分析
- **鲁棒控制**：全部七节内容的综合应用

## 小结

1. **完整流程**：物理建模 → 不确定性分析 → LFT 构造 → 权重选择 → H∞ 设计 → μ 验证 → μ 综合 → Monte Carlo 确认。每一步都有明确的输入输出和判定标准。

2. **方法层次**：PID + 陷波（手工，快但无保证）→ H∞ 混合灵敏度（系统化，充分条件）→ μ 综合（最优，利用结构信息）。工程上通常从简单方法开始，逐步升级。

3. **核心权衡**：鲁棒性 vs 标称性能。越追求鲁棒性，标称性能越差。μ 综合通过利用不确定性结构信息，在两者之间找到更好的平衡。

4. **验证闭环**：μ 分析给出确定性保证，Monte Carlo 给出统计验证。两者互补，缺一不可。

5. **工程落地**：控制器降阶、增益调度、数字实现——这些是将理论变为产品的必要步骤。

## 习题

**习题 1**（流程理解）：在鲁棒控制设计流程中，如果 H∞ 设计后 μ 分析显示鲁棒性能不满足（$\mu_{RP} = 1.3$），列出至少三种改进策略，并说明各自的优缺点。

**习题 2**（不确定性建模）：某系统有 3 个不确定参数（$\delta_1, \delta_2, \delta_3$），变化范围分别为 ±10%、±30%、±5%。

(a) 如果将三个参数合并为一个等效不确定性，有什么优缺点？

(b) 如果保留三个独立参数，μ 分析的不确定性结构 $\boldsymbol{\Delta}$ 是什么？

(c) 从计算复杂度角度，哪种方式更好？从保守性角度呢？

**习题 3**（权重设计）：某柔性结构系统，共振频率 $\omega_n = 8$ rad/s，要求：
- 稳态误差 < 0.5%
- 共振峰闭环增益 < 3 dB
- 带宽 > 2 rad/s
- 控制量 < 50（对单位阶跃）

设计 $W_1, W_2, W_3$，并说明每个权重的设计理由。

**习题 4**（分析题）：H∞ 控制器阶数为 8，μ 综合控制器阶数为 14。

(a) 解释为什么 μ 综合控制器阶数更高。

(b) 如果工程要求控制器阶数 ≤ 10，如何处理 μ 综合控制器？

(c) 降阶后需要重新验证哪些指标？为什么？

## 答案

**习题 1 答案**：

三种改进策略：

**策略 1：调整权重函数**
- 增大 $W_2$（鲁棒性权重）在问题频率处的增益 → 更强调鲁棒性
- 放松 $W_1$（性能权重）的低频增益或带宽 → 降低性能要求
- 优点：简单，保持 H∞ 框架
- 缺点：可能过度保守（标称性能下降过多），需要反复迭代

**策略 2：μ 综合（D-K 迭代）**
- 直接优化 $\sup_\omega \mu_{\boldsymbol{\Delta}_p}(M(j\omega))$
- 优点：利用不确定性结构信息，减少保守性，通常能同时改善鲁棒性和保持标称性能
- 缺点：控制器阶数更高，计算量大，不保证全局最优

**策略 3：修改不确定性模型**
- 检查不确定性范围是否估计过大（用实验数据校准）
- 检查不确定性结构是否合理（是否有可以合并的参数）
- 优点：从根本上减少保守性
- 缺点：需要额外的实验工作，且不确定性范围不能随意缩小

**习题 2 答案**：

**(a)** 合并为一个等效不确定性：
- 优点：μ 分析计算简单（只有一个块），$D$ 缩放只有 1 个参数
- 缺点：引入保守性——三个参数不会同时取最坏值，但合并后假设它们会。等效范围需要覆盖"三个参数同时最坏"的情况，比实际可能的偏差大得多

**(b)** 保留三个独立参数：$\boldsymbol{\Delta} = \text{diag}(\delta_1, \delta_2, \delta_3)$，三个 $1 \times 1$ 块。

**(c)** 计算复杂度：合并方式更低（1 个块的 μ 等于 $\bar{\sigma}$，直接计算）。独立方式更高（3 个块的 μ 需要 D-K 迭代）。

保守性：独立方式更精确（无额外保守性）。合并方式更保守（假设参数同时取最坏值）。

工程建议：如果三个参数的变化范围差异很大（±5% vs ±30%），合并的保守性会非常大，应该保留独立结构。

**习题 3 答案**：

需求翻译：
- 稳态误差 < 0.5% → $|S(0)| < 0.005$ → $A = 0.005$
- 带宽 > 2 rad/s → $\omega_b = 2$
- 共振峰 < 3 dB → $|T(\omega_n)| < 10^{3/20} \approx 1.41$ → 通过 $W_2$ 约束
- 控制量 < 50 → $|KS| < 50$ → $W_3 = 1/50 = 0.02$

$W_1(s) = \frac{s/M + \omega_b}{s + \omega_b A}$

选择 $M = 1.5$（允许 $|S|$ 高频峰值 < 1.5）：

$$W_1(s) = \frac{s/1.5 + 2}{s + 0.01}$$

$W_2$：约束共振频率处的 $|T|$。

$$W_2(s) = \frac{0.7(s + 40)}{s + 1}$$

- 低频 $|W_2(0)| = 28$ → $|T(0)| < 0.036$（放松）
- 共振频率 $|W_2(j8)| \approx 0.7$ → $|T(j8)| < 1.43$（满足 < 1.41 的要求）
- 高频 $|W_2(\infty)| = 0.7$ → $|T(\infty)| < 1.43$

$W_3 = 0.02$（常数）。

**习题 4 答案**：

**(a)** μ 综合控制器阶数 = 对象阶数 + $D$ 缩放拟合阶数 + H∞ 综合引入的阶数。D-K 迭代中，每次 D 步拟合的 $D(s)$ 是有理传递函数（通常 2-4 阶），这些额外的动态被"吸收"进控制器，导致最终控制器阶数高于纯 H∞ 设计。

**(b)** 控制器降阶方法：
- 平衡截断：保留最可控/可观的 10 个状态，截断 4 个
- Hankel 范数近似：最小化 Hankel 范数误差
- 频率加权降阶：在关心的频段（0-20 rad/s）保留精度

**(c)** 降阶后需要重新验证：
1. **标称性能**：降阶可能改变低频增益和带宽
2. **鲁棒稳定性**：降阶引入的误差等价于新的不确定性
3. **鲁棒性能**：综合检验
4. **Monte Carlo**：最终确认
