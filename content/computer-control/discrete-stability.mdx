# 离散系统稳定性

前两节课给了我们离散系统的数学工具（Z 变换）和设计方法（离散化）。但一个根本性问题还没回答：**离散系统什么时候稳定？**

连续系统的稳定性由极点位置决定——所有极点在左半 s 平面。离散系统类似，但稳定区域变了：

> 📖 本课需要 [Z变换基础](/computer-control/z-transform-basics) 和 [数字控制器设计](/computer-control/digital-controller-design) 的前置知识。

| 连续系统 | 离散系统 |
|---------|---------|
| 稳定域：s 左半平面 | 稳定域：z 单位圆内 |
| 临界稳定：虚轴 $s = j\omega$ | 临界稳定：单位圆 $|z| = 1$ |
| 判据：Routh、Nyquist、根轨迹 | 判据：Jury、w-Routh、离散根轨迹 |

为什么不能直接用 Routh 判据？因为 Routh 判据判断的是"根是否在左半平面"，而离散系统的稳定域是单位圆——形状不同，规则不匹配。

本节的目标：掌握三种离散稳定性分析方法，理解采样周期对稳定性的影响，学会计算离散系统的稳定裕度。

## z 域稳定性条件

### 基本定理

离散 LTI 系统 $G(z) = \frac{Y(z)}{U(z)}$ 的稳定性由**特征方程的根**（即 $G(z)$ 的极点）决定：

$$D(z) = 0$$

**稳定性条件**：

| 类型 | 条件 | 时域表现 |
|------|------|---------|
| 渐近稳定 | 所有极点 $|z_i| < 1$ | 响应衰减到零 |
| 临界稳定 | 有极点在 $|z| = 1$，其余在单位圆内 | 等幅振荡或常值 |
| 不稳定 | 有极点 $|z| > 1$ | 响应发散 |

**物理直觉**：$z = e^{sT_s}$，所以 $|z| = e^{\text{Re}(s)T_s}$。
- $\text{Re}(s) < 0$（左半平面）→ $|z| < 1$（单位圆内）→ 稳定
- $\text{Re}(s) = 0$（虚轴）→ $|z| = 1$（单位圆上）→ 临界稳定
- $\text{Re}(s) > 0$（右半平面）→ $|z| > 1$（单位圆外）→ 不稳定

### 特殊极点位置的时域含义

| 极点位置 | $z$ 值 | 时域响应 |
|---------|--------|---------|
| 正实轴，靠近 1 | $z = 0.9$ | 缓慢衰减（类似大时间常数） |
| 正实轴，靠近 0 | $z = 0.1$ | 快速衰减（一拍就消失） |
| 负实轴 | $z = -0.5$ | 交替衰减（振荡，周期 $2T_s$） |
| 单位圆上，$z = 1$ | $z = 1$ | 常值（积分器） |
| 单位圆上，$z = -1$ | $z = -1$ | 等幅交替振荡（Nyquist 频率） |
| 共轭复数 | $z = re^{\pm j\theta}$ | 振荡衰减（$\theta$ 决定振荡频率） |

> 💡 **关键观察**：$z = -1$ 对应频率 $\omega = \pi/T_s = \omega_s/2$（Nyquist 频率）。这是离散系统特有的——连续系统没有"最高频率"的概念。

### 闭环特征方程

对于单位反馈系统，控制器 $K(z)$，对象 $G(z)$：

$$T(z) = \frac{K(z)G(z)}{1 + K(z)G(z)}$$

特征方程：

$$1 + K(z)G(z) = 0$$

或写成多项式形式：

$$D(z) = 1 + \frac{N(z)}{D(z)} = 0 \implies D(z) + N(z) = 0$$

稳定性分析就是判断这个多项式的所有根是否都在单位圆内。

## Jury 稳定性判据

### 原理

Jury 判据是离散系统的"Routh 判据"——直接从多项式系数判断根是否都在单位圆内，**不需要求根**。

给定 $n$ 阶特征多项式：

$$P(z) = a_0 z^n + a_1 z^{n-1} + \cdots + a_{n-1} z + a_n, \quad a_0 > 0$$

### Jury 表

构造类似 Routh 表的阵列：

**第 1 行**：$a_0, a_1, a_2, \ldots, a_n$（多项式系数正序）

**第 2 行**：$a_n, a_{n-1}, \ldots, a_0$（反序）

**第 3 行**：由前两行计算

$$b_k = \begin{vmatrix} a_0 & a_{n-k} \\ a_n & a_k \end{vmatrix} = a_0 a_k - a_n a_{n-k}, \quad k = 0, 1, \ldots, n-1$$

**第 4 行**：第 3 行反序

**第 5 行**：由第 3、4 行计算

$$c_k = \begin{vmatrix} b_0 & b_{n-1-k} \\ b_{n-1} & b_k \end{vmatrix}, \quad k = 0, 1, \ldots, n-2$$

依此类推，每两行产生新一行，行数逐次减 1，直到只剩一行。

### 稳定性条件

**必要条件**（先检查，不满足直接判不稳定）：

$$P(1) > 0 \quad \text{且} \quad (-1)^n P(-1) > 0$$

**充要条件**：Jury 表中所有"奇数行的第一个元素"都为正：

$$a_0 > 0, \quad b_0 > 0, \quad c_0 > 0, \quad \ldots$$

### 低阶情况的简化

**一阶** $P(z) = a_0 z + a_1$：

$$|a_1| < a_0$$

**二阶** $P(z) = a_0 z^2 + a_1 z + a_2$：

$$P(1) > 0: \quad a_0 + a_1 + a_2 > 0$$
$$P(-1) > 0: \quad a_0 - a_1 + a_2 > 0$$
$$|a_2| < a_0$$

**三阶** $P(z) = a_0 z^3 + a_1 z^2 + a_2 z + a_3$：

$$P(1) > 0, \quad P(-1) < 0$$
$$|a_3| < a_0$$
$$|b_0| > |b_2|, \quad \text{其中 } b_k = a_0 a_k - a_3 a_{3-k}$$

> 💡 **工程建议**：二阶和三阶系统用 Jury 判据的简化公式。四阶及以上，直接用计算机求根更简单——Jury 判据的理论价值大于实用价值。

### 示例

**二阶系统**：$P(z) = z^2 - 1.5z + 0.7$

必要条件：
- $P(1) = 1 - 1.5 + 0.7 = 0.2 > 0$ ✓
- $P(-1) = 1 + 1.5 + 0.7 = 3.2 > 0$ ✓（$(-1)^2 \times 3.2 > 0$）
- $|a_2| = 0.7 < 1 = a_0$ ✓

所有条件满足 → **稳定**。

验证：根为 $z = \frac{1.5 \pm \sqrt{2.25 - 2.8}}{2} = 0.75 \pm j0.233$，$|z| = \sqrt{0.75^2 + 0.233^2} = \sqrt{0.618} = 0.786 < 1$ ✓

## w 变换与 Routh 判据

### 原理

双线性变换（w 变换）：

$$z = \frac{w + 1}{w - 1} \quad \Longleftrightarrow \quad w = \frac{z + 1}{z - 1}$$

这个变换把 **z 平面单位圆内** 映射到 **w 平面左半平面**：

| z 平面 | w 平面 |
|--------|--------|
| $|z| < 1$（稳定域） | $\text{Re}(w) < 0$（左半平面） |
| $|z| = 1$（临界稳定） | $\text{Re}(w) = 0$（虚轴） |
| $|z| > 1$（不稳定） | $\text{Re}(w) > 0$（右半平面） |

这样就把离散稳定性问题转化为连续稳定性问题，可以直接用 **Routh 判据**。

### 操作步骤

1. 把特征方程 $D(z) = 0$ 中的 $z$ 替换为 $\frac{w+1}{w-1}$
2. 通分化简，得到 $D'(w) = 0$
3. 对 $D'(w)$ 用 Routh 判据
4. Routh 表第一列全正 → 稳定

### 示例

**二阶系统**：$D(z) = z^2 - 1.5z + 0.7 = 0$

代入 $z = \frac{w+1}{w-1}$：

$$\left(\frac{w+1}{w-1}\right)^2 - 1.5\frac{w+1}{w-1} + 0.7 = 0$$

乘以 $(w-1)^2$：

$$(w+1)^2 - 1.5(w+1)(w-1) + 0.7(w-1)^2 = 0$$

展开：

$$(w^2 + 2w + 1) - 1.5(w^2 - 1) + 0.7(w^2 - 2w + 1) = 0$$

$$w^2 + 2w + 1 - 1.5w^2 + 1.5 + 0.7w^2 - 1.4w + 0.7 = 0$$

$$0.2w^2 + 0.6w + 3.2 = 0$$

Routh 表：

| $w^2$ | 0.2 | 3.2 |
|-------|-----|-----|
| $w^1$ | 0.6 | 0 |
| $w^0$ | 3.2 | |

第一列：$0.2, 0.6, 3.2$，全正 → **稳定** ✓（与 Jury 判据结论一致）

### w 变换 vs Jury 判据

| 方法 | 优点 | 缺点 |
|------|------|------|
| Jury 判据 | 纯代数运算，可编程 | 高阶时计算量大，公式复杂 |
| w 变换 + Routh | 利用熟悉的 Routh 判据 | 需要代数替换和化简 |
| 直接求根 | 最直观，计算机轻松 | 无法给出参数范围的解析表达式 |

> 💡 **工程实践**：现代控制软件（MATLAB、Python）直接求特征根。Jury 判据和 w 变换主要用于理论分析（比如求使系统稳定的参数范围）。

## 采样周期对稳定性的影响

### 核心问题

连续系统稳定的控制器，离散化后**不一定稳定**。采样周期 $T_s$ 是关键参数。

**直觉**：采样越慢，信息丢失越多，相位延迟越大，系统越接近不稳定。

### 定量分析

考虑开环传递函数 $L(s) = K \cdot G(s)$，离散化后 $L(z) = K \cdot G(z)$。

ZOH 等效离散化引入的相位延迟：

$$\angle G_{ZOH}(j\omega) = \angle G(j\omega) - \frac{\omega T_s}{2}$$

在增益穿越频率 $\omega_{gc}$ 处，相位裕度：

$$PM_d = PM_c - \frac{\omega_{gc} T_s}{2} \times \frac{180°}{\pi}$$

其中 $PM_c$ 是连续系统的相位裕度，$PM_d$ 是离散系统的相位裕度。

**稳定性条件**：$PM_d > 0$，即

$$T_s < \frac{2 \cdot PM_c}{\omega_{gc}} \times \frac{\pi}{180°}$$

### 示例：采样周期导致不稳定

**连续系统**：$G(s) = \frac{1}{s(s+1)}$，PI 控制器 $K(s) = 2 + \frac{1}{s}$

开环：$L(s) = \frac{2s + 1}{s} \cdot \frac{1}{s(s+1)} = \frac{2s+1}{s^2(s+1)}$

连续系统相位裕度 $PM_c \approx 50°$，$\omega_{gc} \approx 1.5$ rad/s。

**最大允许采样周期**：

$$T_s < \frac{2 \times 50}{1.5} \times \frac{\pi}{180} = \frac{100}{1.5} \times 0.0175 = 1.17 \text{ s}$$

如果 $T_s = 2$ s（超过临界值），离散化后相位裕度变为负值，系统不稳定。

### 根轨迹视角

在 z 域根轨迹中，随着增益 $K$ 增大，闭环极点从开环极点出发，向开环零点移动。当极点穿过单位圆时，系统变得不稳定。

**采样周期的影响**：$T_s$ 增大时，ZOH 等效离散对象 $G(z)$ 的零极点位置变化，根轨迹形状改变。通常 $T_s$ 越大，根轨迹越早穿过单位圆，稳定范围越小。

## 离散系统的稳定裕度

### 增益裕度

在相位穿越频率 $\omega_{pc}$（$\angle L(j\omega_{pc}) = -180°$）处：

$$GM = \frac{1}{|L(e^{j\omega_{pc} T_s})|}$$

用 dB 表示：$GM_{dB} = -20\log_{10}|L(e^{j\omega_{pc} T_s})|$

### 相位裕度

在增益穿越频率 $\omega_{gc}$（$|L(e^{j\omega_{gc} T_s})| = 1$）处：

$$PM = 180° + \angle L(e^{j\omega_{gc} T_s})$$

注意：离散系统的频率响应是 $L(e^{j\omega T_s})$，不是 $L(j\omega)$。

### 计算方法

1. **解析法**：代入 $z = e^{j\omega T_s}$，求幅值和相位
2. **数值法**：用 MATLAB/Python 的 `margin` 函数（离散版本）
3. **图形法**：在 z 域 Bode 图或 Nyquist 图上读取

### 离散 vs 连续的裕度差异

| 特性 | 连续系统 | 离散系统 |
|------|---------|---------|
| 额外相位延迟 | 无 | $-\omega T_s / 2$（ZOH） |
| 相位裕度 | $PM_c$ | $PM_d \approx PM_c - \omega_{gc} T_s / 2$ |
| 增益裕度 | $GM_c$ | 基本不变（低频特性） |
| 高频行为 | 增益持续下降 | 在 Nyquist 频率处可能反弹 |

> 💡 **设计准则**：为保证离散化后相位裕度足够，选择 $T_s$ 使得 $\omega_{gc} T_s < 0.3$（采样频率 > 20 倍带宽）。这样相位损失 < 8.6°。

## 深入讨论

### 连续 vs 离散稳定性的本质区别

连续系统的稳定域（左半平面）是**无界**的——极点可以离虚轴任意远。离散系统的稳定域（单位圆内）是**有界**的——极点被限制在有限区域内。

这意味着：
1. 离散系统天然"更脆弱"——参数变化更容易让极点跑出稳定域
2. 采样周期越大，稳定域"有效面积"越小（ZOH 延迟吃掉相位裕度）
3. 离散系统有"最高频率"（Nyquist 频率），连续系统没有

### Schur-Cohn 判据

除了 Jury 判据，还有 Schur-Cohn 判据——基于矩阵行列式判断多项式根是否在单位圆内。

给定 $P(z) = a_0 z^n + a_1 z^{n-1} + \cdots + a_n$，构造 Schur-Cohn 矩阵：

$$M = \begin{bmatrix} a_0 & a_1 & \cdots & a_{n-1} \\ a_n & a_{n-1} & \cdots & a_1 \\ \vdots & & \ddots & \vdots \\ a_1 & a_2 & \cdots & a_n \end{bmatrix}$$

$P(z)$ 的所有根在单位圆内 ⟺ $M$ 的所有顺序主子式满足特定符号条件。

Schur-Cohn 判据在理论上更优雅，但计算量比 Jury 判据大。现代软件都用直接求根。

### 结构稳定性与鲁棒稳定性

本课讨论的是**结构稳定性**（给定参数，系统是否稳定）。实际系统中参数有不确定性，需要**鲁棒稳定性**分析。

离散系统的鲁棒稳定性可以用：
1. **小增益定理**（离散版本）：$\|L(z)\|_\infty < 1$
2. **μ 分析**（离散版本）：考虑结构化不确定性
3. **Kharitonov 定理**（离散版本）：区间多项式的鲁棒稳定性

> 💡 离散鲁棒稳定性分析与连续版本的理论框架相同，只是稳定域从左半平面变成单位圆。详见 [鲁棒稳定性分析](/robust/robust-stability)。

### 非线性系统的离散稳定性

对于非线性离散系统 $x[k+1] = f(x[k])$，Lyapunov 稳定性理论同样适用：

**离散 Lyapunov 定理**：如果存在正定函数 $V(x)$ 使得 $V(f(x)) - V(x) < 0$，则原点渐近稳定。

与连续版本的区别：连续看 $\dot{V}(x) < 0$，离散看 $\Delta V(x) = V(x[k+1]) - V(x[k]) < 0$。

离散 Lyapunov 方程（线性系统 $x[k+1] = Ax[k]$）：

$$A^T P A - P = -Q$$

其中 $Q > 0$，解 $P > 0$ ⟺ $A$ 的所有特征值在单位圆内。

## 小结

1. **离散系统稳定性条件**：所有极点在 z 平面单位圆内（$|z_i| < 1$）
2. **Jury 判据**：直接从多项式系数判断，不需要求根。二阶简化公式：$P(1) > 0$，$P(-1) > 0$，$|a_2| < a_0$
3. **w 变换 + Routh**：$z = \frac{w+1}{w-1}$ 把单位圆映射到左半平面，然后用 Routh 判据
4. **采样周期的影响**：$T_s$ 越大，相位裕度越小，稳定范围越窄。经验法则：$\omega_{gc} T_s < 0.3$
5. **离散稳定裕度**：增益裕度和相位裕度的定义与连续相同，但频率响应用 $L(e^{j\omega T_s})$ 计算
6. **工程实践**：现代软件直接求特征根。Jury 和 w 变换主要用于理论分析（求参数范围）

## 答案

### 习题 1

**(a)** $P(z) = z^2 + 0.5z - 0.6$

Jury 条件（$a_0 = 1, a_1 = 0.5, a_2 = -0.6$）：
- $P(1) = 1 + 0.5 - 0.6 = 0.9 > 0$ ✓
- $P(-1) = 1 - 0.5 - 0.6 = -0.1 < 0$ ✗（需要 $(-1)^2 P(-1) > 0$，即 $P(-1) > 0$）

**不稳定**。验证：根为 $z = \frac{-0.5 \pm \sqrt{0.25 + 2.4}}{2} = \frac{-0.5 \pm 1.628}{2}$，即 $z_1 = 0.564, z_2 = -1.064$。$|z_2| > 1$，确实不稳定。

**(b)** $P(z) = z^3 - 1.5z^2 + 0.8z - 0.1$

Jury 条件（$a_0 = 1, a_1 = -1.5, a_2 = 0.8, a_3 = -0.1$）：
- $P(1) = 1 - 1.5 + 0.8 - 0.1 = 0.2 > 0$ ✓
- $(-1)^3 P(-1) = -(−1 − 1.5 − 0.8 − 0.1) = 3.4 > 0$ ✓
- $|a_3| = 0.1 < 1 = a_0$ ✓
- $b_0 = a_0^2 - a_3^2 = 1 - 0.01 = 0.99$
- $b_2 = a_0 a_2 - a_3 a_1 = 0.8 - (-0.1)(-1.5) = 0.8 - 0.15 = 0.65$
- $|b_0| > |b_2|$：$0.99 > 0.65$ ✓

所有条件满足 → **稳定**。

### 习题 2

$P(z) = z^2 - 1.8z + 0.9$

代入 $z = \frac{w+1}{w-1}$：

$$\left(\frac{w+1}{w-1}\right)^2 - 1.8\frac{w+1}{w-1} + 0.9 = 0$$

乘以 $(w-1)^2$：

$$(w+1)^2 - 1.8(w+1)(w-1) + 0.9(w-1)^2 = 0$$

展开：

$$(w^2 + 2w + 1) - 1.8(w^2 - 1) + 0.9(w^2 - 2w + 1) = 0$$

$$w^2 + 2w + 1 - 1.8w^2 + 1.8 + 0.9w^2 - 1.8w + 0.9 = 0$$

$$0.1w^2 + 0.2w + 3.7 = 0$$

Routh 表：

| $w^2$ | 0.1 | 3.7 |
|-------|-----|-----|
| $w^1$ | 0.2 | 0 |
| $w^0$ | 3.7 | |

第一列：$0.1, 0.2, 3.7$，全正 → **稳定**。

验证：根为 $z = \frac{1.8 \pm \sqrt{3.24 - 3.6}}{2} = 0.9 \pm j0.3$，$|z| = \sqrt{0.81 + 0.09} = \sqrt{0.9} = 0.949 < 1$ ✓

### 习题 3

连续系统：$L(s) = \left(2 + \frac{0.5}{s}\right) \frac{1}{s+1} = \frac{2s + 0.5}{s(s+1)}$

求增益穿越频率 $\omega_{gc}$：

$$|L(j\omega_{gc})| = 1$$

$$\left|\frac{2j\omega_{gc} + 0.5}{j\omega_{gc}(j\omega_{gc} + 1)}\right| = 1$$

$$\frac{\sqrt{4\omega_{gc}^2 + 0.25}}{\omega_{gc}\sqrt{\omega_{gc}^2 + 1}} = 1$$

数值求解得 $\omega_{gc} \approx 0.64$ rad/s。

连续系统相位裕度：

$$\angle L(j\omega_{gc}) = \arctan\left(\frac{2\omega_{gc}}{0.5}\right) - 90° - \arctan(\omega_{gc})$$

$$= \arctan(2.56) - 90° - \arctan(0.64) = 68.7° - 90° - 32.6° = -53.9°$$

$$PM_c = 180° - 53.9° = 126.1°$$

要求相位裕度损失 $\leq 10°$：

$$\frac{\omega_{gc} T_s}{2} \times \frac{180°}{\pi} \leq 10°$$

$$T_s \leq \frac{20° \times \pi}{\omega_{gc} \times 180°} = \frac{20 \times 3.1416}{0.64 \times 180} = 0.546 \text{ s}$$

**最大允许采样周期**：$T_s \approx 0.55$ s。

### 习题 4

开环 $L(z) = \frac{K}{z - 0.5}$，单位反馈。

闭环特征方程：

$$1 + \frac{K}{z - 0.5} = 0 \implies z - 0.5 + K = 0 \implies z = 0.5 - K$$

稳定性条件：$|z| < 1$

$$|0.5 - K| < 1$$

$$-1 < 0.5 - K < 1$$

$$-0.5 < K < 1.5$$

**使闭环稳定的 $K$ 范围**：$-0.5 < K < 1.5$。

验证：
- $K = 0$：$z = 0.5$，$|z| = 0.5 < 1$ ✓
- $K = 1$：$z = -0.5$，$|z| = 0.5 < 1$ ✓
- $K = 1.5$：$z = -1$，临界稳定
- $K = 2$：$z = -1.5$，$|z| = 1.5 > 1$，不稳定 ✓
