# 复数基础

## 为什么需要复数

你学过解一元二次方程。比如 $x^2 - 4 = 0$，解是 $x = \pm 2$，没问题。

但如果方程是 $x^2 + 1 = 0$ 呢？移项得 $x^2 = -1$。任何实数的平方都是非负的，所以这个方程在实数范围内**无解**。

数学家不想让方程"无解"，于是做了一个大胆的决定：**定义一个数 $i$，使得 $i^2 = -1$**。

这个 $i$ 就叫**虚数单位**（imaginary unit）。有了它，$x^2 + 1 = 0$ 的解就是 $x = \pm i$。

> 在工程文献中，虚数单位通常写作 $j$ 而非 $i$（因为 $i$ 已经被电流占用了）。本课程的数学部分用 $i$，控制理论部分用 $j$。

## 复数的定义

一个**复数** $z$ 写成：

$$
z = a + bi
$$

其中：
- $a$ 是**实部**（real part），记作 $\text{Re}(z) = a$
- $b$ 是**虚部**（imaginary part），记作 $\text{Im}(z) = b$
- $a$ 和 $b$ 都是实数

几个例子：

| 复数 $z$ | 实部 $a$ | 虚部 $b$ | 说明 |
|----------|----------|----------|------|
| $3 + 4i$ | 3 | 4 | 标准复数 |
| $5$ | 5 | 0 | 虚部为零 → 就是实数 |
| $2i$ | 0 | 2 | 实部为零 → 纯虚数 |
| $0$ | 0 | 0 | 零 |

**关键认识**：实数是复数的特例（虚部为零的复数）。复数不是"虚构的数"，而是实数的自然扩展。

## 复数的四则运算

### 加法和减法

实部和实部相加，虚部和虚部相加：

$$
(a + bi) + (c + di) = (a + c) + (b + d)i
$$

**例子**：$(3 + 4i) + (1 - 2i) = 4 + 2i$

### 乘法

展开后利用 $i^2 = -1$ 化简：

$$
(a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i
$$

**例子**：$(3 + 4i)(1 + 2i) = 3 + 6i + 4i + 8i^2 = 3 + 10i - 8 = -5 + 10i$

### 除法

利用**共轭复数**消去分母的虚部。$z = a + bi$ 的共是 $\bar{z} = a - bi$。关键性质：

$$
z \cdot \bar{z} = (a + bi)(a - bi) = a^2 + b^2 \quad \text{（实数！）}
$$

所以除法就是分子分母同乘分母的共轭：

$$
\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{(ac + bd) + (bc - ad)i}{c^2 + d^2}
$$

**例子**：

$$
\frac{3 + 4i}{1 + 2i} = \frac{(3 + 4i)(1 - 2i)}{(1 + 2i)(1 - 2i)} = \frac{3 - 6i + 4i - 8i^2}{1 + 4} = \frac{11 - 2i}{5} = \frac{11}{5} - \frac{2}{5}i
$$

## 复平面

复数 $z = a + bi$ 可以用平面上的一个点 $(a, b)$ 表示。这个平面叫**复平面**（Argand图）：

- 横轴：实轴（real axis）
- 纵轴：虚轴（imaginary axis）

复平面上的点、向量、复数三者一一对应。

### 模和辐角

复平面上的点 $(a, b)$ 到原点的距离叫**模**（magnitude）：

$$
|z| = \sqrt{a^2 + b^2}
$$

从正实轴逆时针转到该点的角度叫**辐角**（argument）：

$$
\arg(z) = \arctan\!\left(\frac{b}{a}\right) \quad \text{（注意象限）}
$$

## 极坐标形式

用模 $r$ 和辐角 $\theta$ 表示复数：

$$
z = r(\cos\theta + i\sin\theta)
$$

其中 $r = |z|$，$\theta = \arg(z)$。

### 欧拉公式

欧拉公式建立了复数和指数函数的联系：

$$
e^{i\theta} = \cos\theta + i\sin\theta
$$

所以复数可以写成更简洁的**指数形式**：

$$
z = r\,e^{i\theta}
$$

**为什么欧拉公式重要？** 在控制理论中，$e^{i\omega t}$ 表示频率为 $\omega$ 的正弦振荡。复数 $s = \sigma + j\omega$ 中的虚部 $j\omega$ 就对应振荡频率，实部 $\sigma$ 对应衰减（$\sigma < 0$）或增长（$\sigma > 0$）。

### 极坐标下的乘除法

极坐标形式让乘除法变得极其简单：

**乘法**：模相乘，辐角相加

$$
r_1 e^{i\theta_1} \cdot r_2 e^{i\theta_2} = (r_1 r_2)\, e^{i(\theta_1 + \theta_2)}
$$

**除法**：模相除，辐角相减

$$
\frac{r_1 e^{i\theta_1}}{r_2 e^{i\theta_2}} = \frac{r_1}{r_2}\, e^{i(\theta_1 - \theta_2)}
$$

**例子**：$(2e^{i\pi/3}) \cdot (3e^{i\pi/6}) = 6e^{i\pi/2} = 6i$

## 复数在控制理论中的角色

传递函数 $G(s)$ 是复变量 $s$ 的函数。$s$ 的取值决定了系统的行为：

| $s$ 的位置 | 物理含义 |
|------------|----------|
| $s = j\omega$（虚轴上） | 纯正弦振荡，频率 $\omega$ |
| $s = \sigma + j\omega$，$\sigma < 0$（左半平面） | 衰减振荡 |
| $s = \sigma + j\omega$，$\sigma > 0$（右半平面） | 发散振荡（不稳定） |
| $s = 0$（原点） | 直流（常数） |

传递函数的**极点**（分母为零的 $s$ 值）如果在左半平面，系统稳定；如果在右半平面，系统不稳定。这就是为什么复平面在控制理论中如此核心。

## 小结

- 复数 $z = a + bi$ 是实数的自然扩展，$i^2 = -1$
- 四则运算：加减按分量，乘法展开化简，除法乘共轭
- 复平面上，模 $|z| = \sqrt{a^2 + b^2}$，辐角 $\arg(z) = \arctan(b/a)$
- 欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$ 让乘除法变得简单
- 在控制理论中，$s = \sigma + j\omega$ 的实部控制衰减/增长，虚部控制振荡频率
