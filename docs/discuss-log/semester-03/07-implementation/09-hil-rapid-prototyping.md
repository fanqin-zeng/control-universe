## Phase 1: 内容规划

参与者：郑核、苏绘、孙助、柯验、秦构、周联、何仿、赵工、林码、何疑。

[郑核] 只交付IMPL-09。先修为已交付控制器部署、实时控制；不隐含依赖尚未生产的实现案例。9198已被其它serve-pages进程占用，保留其进程，rank1使用9199静态预览与独立目录/索引；8191/8991当前无监听，启用前再查。

[周联] 贯穿问题：风扇控制程序在电脑模型中正常，接控制板之后却发生旧指令覆盖、超期或接口量纲错误，如何在真实电机前验证？四目标：辨别MIL/SIL/PIL/HIL和快速控制原型的被替换部分；写接口及采样应用时序合同；检查模型步长和仿真器/控制器各自实时预算；注入超期并区分功能回归、硬件证据和安全结论。页面只做软件排练，不冒称板级HIL。

[何仿] 实验合同：归一化一阶对象dx/dt=(-x+u)/tau，tau=0.5s，初值x0=0、目标r=1，P增益K=2、限幅0..2。控制帧T=20ms，100帧=2s；显式Euler默认每帧10子步h=2ms，边界1/2/5/20子步。独立精确ZOH影子对象使用同一实际施加命令序列，仅隔离数值积分误差，不作为另一个重整定闭环。

[何仿] 每拍先处理上一拍任务结果：C<=20ms的命令在本拍边界锁存（恰等于期限时先完成再锁存）；超期丢弃、计连续失败；hold继续保持上次u，zero3在连续3次失败后置u=0，下一次有效命令自动恢复。启动尚无结果不算失败。随后采样当前x，算下一命令并记录注入的假定C，最后保持当前u推进对象。虚拟成本不实际sleep，不模拟CPU排队/取消/抢占，不能证明真实RTOS可调度。

[何仿] 四工况：clean成本可调默认4ms；edge固定20ms；burst第20..29号任务成本25ms，其余4ms；overload全部25ms。最后第99号任务在窗口末截止，计入100次提交的超期数，但其结果的应用区间在窗口外。降级区间计k0..99实际输出，启动空命令不是超时。指标x100、u序列、超期任务数、降级帧数、最大Euler/精确同输入差；无随机种子，最多几千子步，秒级运行。

[柯验] 先用Fraction每帧乘子(1-h/tau)^n独立复算，再对照实际TS逐子步循环、原始Notebook逐子步和精确指数影子。数值容差1e-10，任务/降级计数与状态严格相等；默认、20/21ms边界、2种策略及至少4工况。正文数值和题答案都指向原始cell。

[苏绘] 十H2：先替换哪一半；从模型到实物的验证层次；接口与时间合同；步长不是运行速度；可运行的虚拟台架；超期和故障注入；怎样准备真正的HIL；验收证据与停止条件；习题；答案。SVG画真实控制器/实时仿真器与本页软件排练边界。Explorer改工况、子步、策略、clean成本，双图状态/命令并列，面板显示误差及计数。三Notebook各两cell：默认与解析复算；工况策略扫描；期限/步长边界。

[孙助] 五题覆盖SIL与HIL区别、首两帧命令/状态、20/21期限边界、零输出降级的跟踪代价、实际HIL缺证据清单。独立习题和答案H2。

[林码] 浏览器执行了控制代码就算硬件在环吗？[周联] 不算。PIL需要目标处理器，HIL需要实际被测硬件与实时模拟接口。快速控制原型通常保留真实对象、替换控制器实现，本页都未接入。
[赵工] zero3是否就是安全停机？[秦构] 明称教学零输出降级，没有对象危害分析不能冠以安全；过期结果不晚到补写。

[何疑] hold和zero3用同一K/成本序列，无独立整定，限定机制观察。normal/edge两策略持平；burst零输出会牺牲跟踪；overload初始无输出，两策略状态可能持平。影子精确解只共享实际施加输入，不与Euler闭环偷换反馈轨迹；步长比较不推广到任意对象。先最小实验再定数字。

[共识] 按上述十节、接口顺序和计数窗口生产；所有硬件/实时性能主张等待设备实测，本课不预填签发。
