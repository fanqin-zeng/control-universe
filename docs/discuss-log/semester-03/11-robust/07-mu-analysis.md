[郑核] 读者已交付先修：不确定性建模、鲁棒性能、矩阵分解；上一课名义消去对9rad/s失配失稳，引出双轴定位台的耦合回传。问题是两个驱动通道各自增益漂移，是否应允许误差任意串到另一通道？本课只分析固定互连，不生产D-K设计或相邻ROBUST-08。
[卫韧] 五目标：把物理假设写成块结构与归一化；从最小致奇异扰动定义μ；对可解析双向耦合计算精确μ并构造扰动；区别可行D上界与扰动下界；正确区分单频、全频稳定与增广鲁棒性能。非目标：通用μ精确算法、混合实μ完整求解器、μ综合最优性与实机功能安全。
[林矩] 主模型M(s)=A/(s+1)，A=[[0,b],[c,0]]，默认b2/c.125。对独立复标量diag(δ1,δ2)，μ=sqrt(abs(bc))/sqrt(1+w²)，满块μ=max(absb,absc)/sqrt(1+w²)。对D=diag(d,1)可行上界max(abs(db),abs(c/d))/sqrt(1+w²)；满块不得套非标量D。实重复标量i反例说明ρ≤μ非任意结构通则，块的交换子重复标量与full块不能写反。
[苏绘] 双轨合同：四滑块b/c/d/观察频率及两结构选择，双图显示频率与缩放，默认d.25/w0严格复现主例。真实SVG显示z=Mw、w=Δz正反馈与性能虚块e→d方向。三Notebook五cell：矩阵/见证，频率与反例/实μ，性能增广/四题复算。图轴固定、图例留空隙、明确频率旋钮不改变系统全频半径。
