[林矩] 采用y[k]=b u[k-1]+v[k]、u[k-1]=r[k-1]-f y[k-1]、v[k]=ρv[k-1]+w[k]；r是加到控制输入端的独立注入，不是输出设定值。严格先测过去输出→选u→受新创新w形成y，无代数环。真b=.8；f0/.5/.8，|ρ|≤.8；闭环极点-bf稳定。默认f=.5、ρ=.5、A=.5、σw=.5，归一化固定。

[钱锐] z=u与输入相关最强，却可继承同一扰动相关；无外部r时有效工具的分母应报不可识别，不加epsilon装作估计。有限样本相关接近0也不能证明工具有效。

### 教授团队（学术准确性）
