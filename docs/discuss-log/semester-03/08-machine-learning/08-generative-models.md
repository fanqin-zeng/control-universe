[钱锐] 从包装机重量分布引入：预测平均重量不能代替生成整批重量。四个目标：写加噪边缘和噪声损失；区分条件均值与随机反向生成；推导独立高斯端点的条件流匹配；用解析输运核查Euler误差。所有数值先待测。不训练图像模型，不把独立配对称为最优耦合。

[柯验] 逐量容差1e-10，UI显示舍入另定5e-7；实际TS/Python逐量对独立高精度Gaussian条件协方差/仿射矩阵乘积，正文与答案全部列A.1。默认与边界先实跑再写数值。

[苏绘] 加噪/训练/采样方向用SVG；纯计算两Notebook共四cell；Explorer调m,s,a,t,N和错误符号，固定轴看标准差而非只看均值。无需AI位图。
