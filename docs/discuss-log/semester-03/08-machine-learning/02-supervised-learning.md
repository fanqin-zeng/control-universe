## Phase 1: 内容规划

参与者：郑核、钱锐、苏绘、孙助、柯验、何仿、何疑。

[郑核] 空占位按新写技能，learning矩阵九人加秦构验收。承接已交付ML-01/凸优化；只用已讲的平方损失、梯度和概率，不先讲神经网络或自动微分。四目标：把任务/标签/损失对应；推导一维回归与L2惩罚；从Bernoulli得到二分类交叉熵；说明fit/predict与停止条件、阈值/概率和部署边界。

[钱锐] 回归贯穿原房间加热例子，x为参考功率偏差、y归一化温升。分类另用振动特征预测下次巡检是否需检修，不能把两种标签互换。逻辑回归p=σ(b+wx)，以四个对称可分点解释准确率与有限最优解的不同。

[何仿] 回归训练x=[-1,0,1]，标签[0,1,2+a]；a为固定单点扰动，非随机。原工况真值1+x，验证x=[-.5,.5]、测试x=[-.75,.75]预先锁定。目标为半均方误差加λw²/2，截距不惩罚；λ候选0/.5/1/2，a=0/.5/1/1.5/2。分类x=[-2,-1,1,2]、标签[0,0,1,1]；初值b=w=0，全批梯度步长.5、预算0/1/5/20/40/200，梯度范数≤1e-10才称停止；否则注明达到预算。无随机种子或环境交互步数；记录实际更新次数与墙钟时间。

[苏绘] 开头用真实SVG并列“预测温升数值”和“预测需检修类别”；一个React组件切换回归/分类，回归调λ/a，分类调λ/预算/阈值。Notebook两组分别复核推导/选模和分类梯度/边界。固定坐标、无动画、inline样式。

[孙助] 四题：回归手算与惩罚系数；一次梯度更新；分类概率/阈值；可分性与数据泄漏，提供步骤答案且原始cell复算。

[柯验] 实际TS回归对独立增广矩阵NumPy最小二乘；分类迭代对独立高精度标量递推，正则化最优解另用SciPy根求解核验。正文/原始cell/真实组件逐量容差1e-9；概率显示舍入单列。全控件域验证轴范围。

[何疑] 先定义同训练集、同超参数候选、验证选后才测试。至少a=0/1/2三工况，保留干净数据λ0胜出、扰动下适度收缩可能改善。不同λ的总目标不是同一量，禁止据总目标排序泛化；分类只讲固定训练集，不冒充测试准确率或校准。
