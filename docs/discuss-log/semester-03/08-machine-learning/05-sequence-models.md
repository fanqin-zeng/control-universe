[钱锐] 从停热后余温引入；按learning矩阵承担学术主责。H2合同：停热以后仍有余温、先规定预测时刻、窗口与循环状态、沿时间反向传播、截断梯度保留状态、一步预测与自由滚动、门控模型与工程接口、习题、答案、继续学习。每个主节对应一目标，练习四题分别核窗口/前向、共享梯度、detach/reset、时间切分与滚动协议。

[苏绘] 展开结构用SVG，标明h0→h1→h2与重复的同一a；Notebook1复算状态和BPTT，Notebook2复算评估及边界。Explorer调a、T、输入、h0、截断长度K；画状态与对初态敏感度，读数同时给完整/截断梯度。两曲线量同为无量纲；显式轴范围覆盖全部选项，不隐藏增长。无数值的门控解释用图文。

[何仿] 合同：无量纲标量线性循环h_t=a h_(t-1)+x_t，末端L=h_T²/2，h0默认0，a默认.5，T默认4，x默认[1,0,0,0]；K默认2，截断只保留最后K条参数边，边界状态数值照传。扫a=[0,.5,1,1.5]、T=[4,8,16]、输入脉冲/常值/交替、h0=[0,.25]、K=[1,2,4,T]，共288配置含重复K；计算确定性，无种子、无环境步、CPU秒级。默认数值待测。

[何疑] 不整定或训练架构，图是同一指定递推的状态/导数，不作学习性能排名。另用真实系数.8、固定预测系数[.5,.8,1.1]、初值1、无输入的四步冷却，比较信息协议，不据测试选参；全量含正确模型持平与失配。窗口仅示因果输入定义，不把未整定窗口模型当弱基线。

[林码] 必须分开state reset、detach与梯度清零。推理一步只传数值，不需保留图；独立序列重置，同一连续记录跨块保留数值但可截断图。不能把隐藏状态叫可测物理状态。
