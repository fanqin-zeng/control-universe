## Phase 1: 内容规划

参与者：郑核、苏绘、孙助、柯验、钱锐、何疑、何仿。

[郑核] 本课从空占位新写，按learning矩阵九人加秦构执行验收。新机器学习章由钱锐主责数学边界，林码检验学习接口；不补写IMPL课程。先修只用已交付概率和线性代数。目标四项：定义样本/预测/损失；区分经验风险与总体风险；设计三份数据的信息隔离；解释有限样本、分布变化与闭环保证的边界。

[钱锐] 用加热功率预测下一分钟温升，先说明固定初温/室外条件。训练模型只输出温升；反馈控制还需选择功率、约束及稳定性分析。风险是对明确分布的期望，有限测试均值不是已知总体风险。

[何仿] 最小实验采用归一化功率x∈[-1,1]、温升y=1+2x。五训练点附固定扰动[1,-1,1,-1,1]乘幅值a；四验证点、六测试点预先锁定。常数/直线/四次多项式均最小二乘，验证选择后才测试。测试关系额外加d*x²模拟工况变化。全为确定性教学数据，不称IID抽样、真实采集或多种子统计。无训练迭代/环境步；报告求解次数与实际运行时间。

[苏绘] 开篇用本地SVG标明功率→房间→下一分钟温升；三份数据用表说明。React只调模型次数、扰动幅值和工况变化，固定轴/默认恢复。Notebook两实验：模型选择与边界，信息隔离和答案复算。

[孙助] 四题分别对应损失、三份数据、过拟合边界和部署检查，给逐步答案；数值全部进入原始Notebook复算。

[柯验] 实际TS求解器对独立NumPy lstsq，遍历3模型×3扰动×3变化；默认、无扰动持平和变化失败都记录。容差1e-9，单位为归一化温升平方。所有正文数值待最小实验输出后填入。

[何疑] 不从固定五点推广算法优劣。常数与直线均独立拟合，四次允许五参数；报告复杂度/训练代价及无扰动持平。展示测试曲线是教学剖析；实际选模流程不允许看后再调。

[共识] H2：从房间温升提出问题、把经验写成学习问题、训练误差与总体风险、三份数据各做什么、复杂度与过拟合、工况变化与控制边界、习题、答案与讨论。完成最小实验再扩写。
