## Phase 1: 内容规划

参与者：郑核、林矩、陈控、苏绘、孙助、柯验、钱锐

[林矩] 本课要完成三件事：① 把"状态反馈 = n 个自由度"的威力感建立起来（对比输出反馈的 1 个自由度）；② 给出极点配置的两条路径——可控标准型比较系数（可解释）与 Ackermann 公式（可计算），并让学生理解**两者是同一件事的两种坐标**；③ 讲清楚前馈 N 的存在性：纯状态反馈只能"调节到零"，跟踪需要 N 抵消稳态。这三件事分别对应"为什么行、怎么算、还差什么"三问。

[陈控] 从经典控制过来的学生最大的困惑是："根轨迹磨半天配两个极点，你们直接解方程配 n 个，代价是什么？"这个代价必须在正文里诚实回答——①需要全部状态可测（观测器下一课讲）；②依赖精确模型；③K 随极点距离平方增长（执行器饱和）。§与经典控制的对比表要保留，且"极点不要放得太远"的工程考量是本课的成人礼段落。

[钱锐] 我预习时跑了 `place(A, B, [-5, -5])`——**直接 ValueError**！place 基于 KNV 算法，要求每个极点重数 ≤ rank(B)；acker 支持 SISO 重根但数值病态。正文例 1/例 4 用的恰好是二重极点 −5,−5，所有 notebook 一跑就炸。这必须变成教学内容而不是绕开：place vs acker 的差异本来就是工具课的核心知识点。

[柯验] 对账口径：① 例 1/2/4/5 与答案 1/2/3/5/6/9 全部矩阵与特征值用 numpy/control 复算；② 重点盯两处：答案 7 的 K 公式（B=[0;ωn²] 不是 [0;1]，我怀疑原稿漏因子）与答案 10 的零点不变性证明（我读到后半段疑似循环论证）；③ S6 实跑为签发必跑项（fix-021 规矩），本课两个 notebook 的 cell 必须真跑。

[苏绘] 双轨分配：NB1（place/acker 对比）与 NB2 静态 cell（开环 vs 闭环阶跃）是"工具行为演示 + 单次对比"——静态输出最佳；NB2 的交互 cell（极点滑块）是典型的"拖参数看趋势"——转 React 组件 StateFeedbackPoleExplorer，滑块 p∈[−10,−0.5] 默认 −5，**默认读数必须复现正文手算链 K=[23,7]、N=25**（fix-014 教训：组件默认值即对账第三方）。

## Phase 2: 内容生成

### 第一轮 — 概念讲解

[林矩] 概念链按"输出反馈 1 个自由度 → 状态反馈 n 个自由度 → A−BK 特征多项式系数逐个可调"展开。例 1 的 Callout（k₁、k₂ 分别对应常数项与一次项）是关键直觉，保留。Ackermann 推导的四个步骤里，第 4 步（eₙᵀ C⁻¹ Aⁱ = eₙ₋ᵢᵀ）是最不直观的，推导思路一节只需"可证"并指向习题 8 的完整证明——分层正确。

[陈控] §前馈补偿的 N 公式框起来是对的，但要加一句与经典控制的接口：N 的作用等价于"直流增益校正"，与 PID 里 I 项消除稳态误差殊途同归——状态反馈方案没有积分器，靠前馈硬拉稳态，**模型失配时稳态就会漂**（这正是后课 LQR+积分增广的动机）。这句话放 Callout，一句话即可。

[钱锐] §极点配置与零点：正文说"K 只影响分母不影响分子"——这句话 SISO 下对，但建议措辞更严谨：状态反馈不改变**传递函数零点**（传输零点）；MIMO 下还有别的自由度玩法。就本课 SISO 范围，现有表述可接受，不加术语负担。

### 第二轮 — 学生反馈

[小初]（转述）"为什么要叫'极点配置'而不是'特征值配置'？还有 u=−Kx+r 里的负号，是规定还是物理？"——正文 §闭环系统应先给一句"负号 = 负反馈约定，与经典控制 u=−ky 同源"；"极点=特征值"的等价在 state-space 一课已建立，本课开头链接即可。

[李稳] 两点：① 例 3（不可控系统 Ackermann 无解）放在公式之后很好，但它其实是上一课 PBH 的复习——加一句"与上一课例 1 的 λ=2 不可控一致"形成回环（正文已有，确认保留）；② 前馈 N 推导假设了 (A−BK) 可逆（闭环无原点极点）——学生容易忽略，需在公式旁注一句。

[赵工]（转述）工程视角的痛点：K=[23,7] 意味着状态反馈增益比输出反馈大一个量级，噪声放大怎么办？§极点选择的工程考量已回答一半（饱和/鲁棒性），建议把"量测噪声"三个字明确写进去，观测器一课再展开。

### 第三轮 — 调整完善

[柯验] 数值裁决：① **答案 7(b) 实质性错误确认**——B=[0;ωn²]，特征多项式为 s²+(2ζωn+k₂ωn²)s+ωn²(1+k₁)，原稿按 B=[0;1] 推出 K=[3ωn²,(2.8−2ζ)ωn]，实测（ωn=2,ζ=0.5）闭环极点 −4.30/−12.10 ≠ 目标 −2.8±j2.86；正确 K=[3,(2.8−2ζ)/ωn]，实测 −2.8±j2.857 ✓ 已重写并附数值抽查；② **答案 10 证明的循环论证确认**——"使 C(sI−A+BK)⁻¹B=0 等价于使 C(sI−A)⁻¹B=0"正是待证结论；且中间一段矩阵维度混乱（BK·(sI−A+BK)⁻¹B 不可乘）。重写为**块矩阵一行证明**：Σ_cl(s)=Σ_open(s)·[[I,0],[K,I]]（右乘行列式为 1 的块下三角阵），秩不变故零点集不变——干净且覆盖 MIMO；③ 其余例 1/2/4/5、答案 1/2/3/5/6/9 全部复算一致；④ NB 系列三处运行时错误修复：place 重根 ValueError（重构为 try/except 教学）、acker 返回一维数组的 reshape、JS 模板字面量 `\n` 求值陷阱（f-string 跨行 → SyntaxError，改 `\\n` 转义——这条登记进秦构清单）。

[孙助] 落实：① 负号约定句 + 极点=特征值回链；② N 公式旁注"(A−BK) 非奇异前提"；③ 经典接口 Callout（N≈直流增益校正，模型失配会漂 → LQR+积分预告）；④ 答案 6 补一句"多余自由度 → LQR 会给出最优的那一个（预告）"；⑤ 工程考量加"量测噪声"。

[秦构] StateFeedbackPoleExplorer 实现：解析 K=[p²−2,−2p−3]（比较系数直出）、N=p²、闭环二重极点响应 y=1−e^{pt}(1−pt)、开环 y=0.5(1+e^{−t}−2e^{−2t})；固定轴 t∈[0,4]、y∈[0,1.6]；读数区 K/N/ωn 三个数与正文手算链逐位对应；注册单一来源、MDX 显式引用、animation:false。

[苏绘] 复核通过。补充：读数区"p 越远 |K|∝p²"一句把 §工程考量可视化地接上了，好。
