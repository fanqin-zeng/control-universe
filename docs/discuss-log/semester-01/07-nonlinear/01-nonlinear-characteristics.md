[陈控] 这一课是整章的**入口**，也是学生第一次被告知"你学了一学期的工具是有有效期的"。要立的直觉只有一条主线：**非线性 = 叠加原理失效**，而失效不是一个哲学说法，是可以拿两个输入当场量出来的数。所以开篇的 NB1 必须先量线性系统的残差（$10^{-14}$ 量级）再量硬弹簧系统的残差（80%），两行数字并排，比任何定义都有说服力。第二条直觉：非线性系统的"增益"随信号幅值变化——$A(u_2)$ 与 $A(2u_2)$ 的比值线性是 2.000000、硬弹簧是 1.163721，这就是后面描述函数法的种子，这里只埋线不展开。

[林矩] 数学骨架四条：① 叠加原理的两个成分（可加性 + 齐次性）要分开测，硬弹簧破坏的主要是齐次性；② 周期不是常数——Duffing 硬弹簧周期随振幅单调**减小**（$\alpha=0.5$：$A_0=0.1$ 时 6.271439，$A_0=1.5$ 时 4.647763，−26.029%），软弹簧单调**增大**（$\alpha=-0.3$：6.290267 → 9.151281，+45.647%），这是"线性化没有振幅概念"的最直接证据；③ Lindstedt-Poincaré 一阶修正 $\omega\approx\omega_0(1+\tfrac{3\alpha A_0^2}{8})$ 在小振幅处几乎完美（0.000%），到 $A_0=1.5$ 偏 5.178%（硬）/8.780%（软）——渐近式的适用域必须量化，不能只说"小振幅"；④ 软弹簧的势垒逃逸：$x_b=\sqrt{-1/\alpha}=1.825742$、$V(x_b)=0.833333$，实测 $A_0=1.820/1.825$ 有界、$1.830$ 在 5.215 s 逃逸——**阈值不是能量判据 $E<V(x_b)$ 而是 $A_0$ 是否越过 $x_b$**，因为 $E=V(x_b)$ 在 $x_b$ 处是重根，能量判据在此退化（正文加 warning callout 专门纠正）。

[卫韧] 三个"线性化会说谎"的机制，每个配一次实测：① **误差随工作点漂移**——$\tanh$ 型饱和在 $x=1.05$ 处线性化误差 1.05%，$x=2.00$ 处 22.22%；1% 误差带只有 $[0.8680,1.1521]$（+0.1521/−0.1320），远小于教科书插图给人的印象；② **多平衡点**——带恒定转矩的摆 $\ddot\theta+0.2\dot\theta+\sin\theta=\tau$：$\tau=0$ 有两个平衡点（0 稳定焦点、$\pi$ 鞍点），$\tau=0.95$ 有两个（71.805° 稳定、108.195° 鞍点），$\tau=1.0$ 只剩一个且特征值 $[-0.2,-0.]$ **非双曲**（鞍结分岔点，线性化给不出结论），$\tau=1.05$ 一个都没有 → 持续旋转（平均角速度 5.246291 vs $\tau/d=5.25$）；③ **局部稳定 ≠ 全局可达**——粘滑系统里 $v_b=0.35>v_{\min}$ 时线性化预测平滑滑动稳定（$\tau=2m/(dF/dv)=122.3$ s），实测小扰动确实按此衰减（拟合 $\tau=119.9$ s，偏差 −2.0%），**但冷启动（$v_0=0$）仍然粘滑**，因为吸引域只有 $c=v_0/v_b\in[0.500,1.500]$。这条是本课最反直觉的结论，必须单独一个 warning callout。

[领域-机器人] 谐波减速器的回程间隙和关节的 Stribeck 摩擦是机器人定位精度的两个主要非线性源。间隙的签名是**回程误差**（同一指令位置正反向到达差 $2b$），摩擦的签名是**低速抖动（粘滑）**。NB3 的 Stribeck 曲线 $F(v)=(F_c+(F_s-F_c)e^{-|v|/v_s})\mathrm{sgn}(v)+\sigma v$ 在 $v\to0$ 的斜率是 $-4.0000\ \mathrm{N\cdot s/m}$（**负阻尼**），最小值 $F_{\min}=0.306298$ 出现在 $v_{\min}=0.264914$（解析 $v_s\ln\frac{F_s-F_c}{\sigma v_s}=0.264916$，差 $2\times10^{-6}$）——这两个数就是"为什么低速爬行"的完整答案。

[领域-过程控制] 阀门死区 + PI 是流程工业最常见的振荡源。关键工程事实：死区在**小信号时输出恒为零**，所以控制器看到的被控对象在小误差区里"没有增益"，积分器就会一直累加 → 饱和 → 大幅超调 → 反向再饱和 → 极限环。NB8 的三组数字（21.052% / 80.181% / 2.254%）可以直接放进调试规程：先看峰值 $|u_{raw}|$ 是否超限幅（6.9615 = 23.20 倍就是明确的积分饱和指纹），再决定是调增益还是加抗饱和。

[领域-航天] 再入段的质量、气动密度、阻力系数都在变，$m(t)\dot v=F-mg-\tfrac12\rho v^2C_DA$ 里阻力项对 $v$ 是二次的——**旧稿说它是线性 ODE 是硬错误**，必须纠正，并说明"线性 in 状态"与"系数时变"是两件独立的事（系数时变但状态线性 → 仍是线性系统；状态非线性 → 非线性系统）。这个区分学生极易混淆，正文单独一段。

[共识] 教学目标：① 用两个输入当场量出叠加原理的破坏程度（残差与齐次性比值）；② 说出六种常见非线性的物理来源与**可辨识签名**（有记忆/无记忆、奇对称/非奇对称、谐波/互调产物）；③ 用四个维度分类（光滑性、记忆性、对称性、时变性）并解释每个维度对应哪种分析工具；④ 解释线性化失效的三种机制（误差随工作点漂移、多平衡点、局部≠全局），并各给一个实测反例；⑤ 用五条判据 + 决策表判断"何时必须做非线性分析"；⑥ 独立完成 Duffing 手算例（周期偏移、Lindstedt 修正、软弹簧逃逸阈值）与 PI 抗饱和对照。大纲 11 个 H2：引言 / 什么是非线性系统？ / 常见非线性类型 / 非线性的分类 / 为什么线性化会失效？ / 何时需要非线性分析？ / 实例与案例 / 深入讨论 / 小结 / 习题 / 答案。**结构决定**："何时需要非线性分析？"一节不放 notebook（5 条判据 + 决策表已经足够），把两个综合案例（PI 抗饱和、粘滑）集中在"实例与案例"。可视化：1 个新交互组件（`NonlinearityExplorer` 六种非线性）+ 9 个 notebook 组件。

### 第一轮 — 概念讲解

[陈控] "什么是非线性系统？"一节的写法：先给定义（不满足叠加原理），立刻上 NB1 把定义变成两个数字。线性系统 $\ddot y+0.2\dot y+y=u$ 的 $\max|y(u_1+u_2)-y(u_1)-y(u_2)|=1.01\times10^{-14}$（相对 5.813027 的 $1.7\times10^{-13}\%$），硬弹簧 $\ddot y+0.2\dot y+y+0.5y^3=u$ 同一组输入给出残差 1.705805，相对误差 **80.32953%**。齐次性一行：线性 $A(u_2)=0.813714$、$A(2u_2)=1.627427$、比 2.000000；硬弹簧 1.623869 / 1.889730 / 比 **1.163721**——输入翻倍，输出只涨 16%。

[林矩] 紧接 NB2 讲"周期依赖振幅"。这是线性系统里根本不存在的概念（$\omega_n$ 是常数），却是非线性系统最容易测到的量。硬弹簧四个振幅的周期偏移 $-0.187\%/-4.367\%/-14.587\%/-26.029\%$，软弹簧 $+0.113\%/+2.945\%/+13.793\%/+45.647\%$，两列并排；Lindstedt 一阶修正列在旁边，小振幅 0.000%、大振幅 5.178%/8.780%——**修正项不是万能的，它自己也有适用域**。软弹簧逃逸段：$x_b=1.825742$、$V(x_b)=0.833333$，$A_0=1.820$ 有界（周期 20.222879，13 圈）、$1.825$ 有界但周期已涨到 26.006924（9 圈，接近同宿轨道）、$1.830$ 在 5.215 s 逃逸、$1.900$ 在 3.185 s 逃逸。周期发散 + 阈值行为是同宿分岔的签名。

[卫韧] "常见非线性类型"一节按物理来源组织（摩擦、间隙、饱和、死区、继电器、滞环、平方律），每种给一句"在哪个部件上出现"和一句"用什么签名识别它"。NB3 三件事：滞环环面积实测 1.200000（闭式 $4cA=4\times0.2\times1.5$，差 $7.4\times10^{-9}$），$c=0.1\to0.600000$、$c=0.4\to2.400000$ 验证线性关系；间隙 $2b=0.6$、最大回程误差 0.300000 $=b$、平均 0.255003；Stribeck 曲线六个点 + 负斜率 + $v_{\min}$ 实测与解析对到 $10^{-6}$。

[方数] "非线性的分类"一节给四个维度，每个维度后面挂一句"所以该用什么工具"：光滑性（光滑 → 线性化/谐波平衡；不连续 → 描述函数/Filippov）、记忆性（无记忆 → 静态非线性映射；有记忆 → 状态增广，滞环必须加一个状态变量）、对称性（奇对称 → 只产生奇次谐波，实测偶次 $\le5.4\times10^{-17}$；非奇对称 → 产生直流偏移和偶次谐波）、时变性（自治 → 相平面可用；非自治 → 只能看 Poincaré 截面）。NB4 是这一节的证据库：立方非线性的基波/三次闭式与 FFT 逐位对上、饱和的描述函数四个振幅点、双频互调七个频率分量。

[周联] "为什么线性化会失效？"三种机制各配实测。**机制一（误差随工作点漂移）**：$\tanh$ 饱和在 $x_e=1$ 处 $f_{lin}(x)=1.6000x-0.4000$，误差 1.05→1.05 处 1.19%、1.10→0.4538%、1.20→1.6563%、1.50→8.0460%、2.00→22.2222%；三条误差带 $<1\%$ → $[0.8680,1.1521]$、$<5\%$ → $[0.7283,1.3746]$、$<10\%$ → $[0.6383,1.5738]$，**注意带是不对称的**（+0.1521/−0.1320），因为 $\tanh$ 的曲率不对称。**机制二（多平衡点）**：NB7 摆的恒定转矩扫描。**机制三（局部≠全局）**：NB6 跳跃共振（同一 $\omega$ 有三个振幅解，其中中间支不稳定，初始条件决定落在哪一支）+ NB9 吸引域。

[何仿] NB6 的实现细节要交代清楚，否则读者会以为是画图技巧：谐波平衡解三次方程 $[\,(\omega_0^2-\omega^2+\tfrac{3\alpha A^2}{4})^2+(\zeta\omega)^2\,]A^2=F^2$ 得 1–3 个实根，仿真用**升频/降频延拓**（每个 $\omega$ 用上一个 $\omega$ 的末状态做初值，各跑 120 s，取末 12 个周期做整周期傅里叶投影），延拓方向不同就会跟到不同分支，跳跃点因此不对称。实测仿真基波与谐波平衡同分支最大偏差 0.05807，THD 0.01–6.69%，$\max|x|$ 比基波大 9.62%（波形变尖）。

[吴规] "何时需要非线性分析？"给 5 条判据，每条一句话 + 一个可测量 + 本课哪个 notebook 是它的证据：① 信号幅值相对工作点的比值（NB5 的误差带）；② 是否存在多个平衡点或运行点会跨越它们（NB7）；③ 是否有自激振荡源（负阻尼、负斜率摩擦曲线 → NB3/NB9）；④ 执行器是否长时间饱和（NB8 的 $u(0)/M=9.33$）；⑤ 精度/安全要求是否超出线性化误差带（NB6 的多解与跳跃）。最后给决策表：线性化够用 / 需要局部非线性修正（描述函数、增益调度）/ 必须做全局非线性分析（相平面、Lyapunov、数值仿真）。

## 附录 C：环境与工具链问题（供后续课程复用）

1. **间隙环面积的 settle 相位陷阱（已归档为 fix-018）**：有记忆非线性（间隙/滞环）在做上升支扫描前必须先跑几个周期进入周期轨道，且**settle 循环的末相位必须停在 $\theta=-\pi/2$（$u=-A$）**，与上升支起点重合。若停在 $\theta=0$（$u\approx0$，下降支），`prevY` 会带着下降支残留（间隙时 $\approx+b$），使上升支被钉住直到 $u>2b-A$，环面积从 0.84 错算成 0.52（−38%），而 $\max|y-u|$ 仍正确——**只有面积读数出错，最难发现**。
2. **cell 代码逐字拼接 + 逐字校验（已归档为 fix-017）**：把内核验证过的 harness（`.agent/nc-harness*.py` 的 `CELLS`）用脚本替换占位符写进 MDX，而不是手抄；拼接后必须再用脚本把 MDX 里的 cell 抽回来与 harness 做**字符串全等**比对（本课 9/9 `ALL MATCH`）。占位符不要写 `%%NBn%%`——经过一层 `%` 格式化会折叠成 `%NBn%`，使 cell 首行 `# 注释` 变成 `%# 注释`，IPython 直接报 `UsageError: Line magic function '%#' not found`，而页面照常 200、组件照常初始化，只有点"运行"才暴露。拼接脚本同时断言 cell 内无反斜杠/反引号/`${`（单引号 JS 模板字面量的三个雷）。
3. **harness 合并去重**：同一编号的 cell 在多个 harness 里出现时（本次 NB9 在 h6 里是过时版本），用 `dict(h6.CELLS[:8]); update(dict(h8.CELLS))`，并断言最终 key 集合恰为 NB1..NB9。
4. Windows 系统代理使 urllib 对 127.0.0.1:8891 的 POST 返 502 → `build_opener(ProxyHandler({}))`；控制台 GBK → `PYTHONIOENCODING=utf-8` + 重定向到日志文件。
