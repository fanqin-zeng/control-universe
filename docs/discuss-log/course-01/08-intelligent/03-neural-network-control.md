## Phase 2: 内容生成

### 数值实验

**训练数据**：6 个初始条件（5°–30°），36,000 样本，MSE 损失，1000 epochs。

**结果**：
- NN-Supervised：rms 2.66°，TV(u) 14.1，J = 0.059
- NN-ES：rms 2.85°，TV(u) 13.4，J = 0.054（最优）
- PID：rms 2.67°，TV(u) 16.0，J = 0.057
- Fuzzy PD：rms 21.10°（失败）

**鲁棒性**：训练域内（5°–30°）三种方法接近，域外（35°–45°）NN 退化更快。

### 关键发现
1. NN-Supervised ≈ PID（几乎完美复制）
2. NN-ES > PID（在代价函数 J 上超越 5.3%）
3. NN 都有稳态误差（无积分作用）
4. NN 远优于模糊控制（2.7° vs 21°）
