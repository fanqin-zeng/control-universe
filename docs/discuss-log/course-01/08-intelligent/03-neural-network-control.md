## Phase 1: 内容规划

**[陈控]**：上一版课程最大的问题是把所有神经网络都叫"NN"，只讲了一个 2→10→1 的浅层前馈网络。实际上在控制领域，神经网络至少有四种截然不同的角色，必须分类讲清楚：
1. **静态逼近器**（前馈网络）——用 NN 替代 PID/模糊的映射 $u=\pi(e,\dot e)$
2. **动态模型**（递归网络/Neural ODE）——辨识被控对象 $\dot x = f_\theta(x,u)$
3. **策略网络**（深度 RL）——直接输出控制动作 $a=\pi_\theta(s)$
4. **值函数**（Q-learning/Actor-Critic）——评估状态好坏，间接驱动策略

**[林矩]**：从数学结构上补充。静态映射型是无记忆的代数函数；动态映射型 $u_t=\pi_\theta(e_{0:t})$ 有记忆，适合处理非马尔可夫或部分可观测系统；值函数型满足 Bellman 方程 $V(s)=\max_a[r+\gamma V(s')]$；Neural ODE 把网络嵌入微分方程，连续时间建模。这四类的训练目标、稳定性分析难度完全不同。

**[卫韧]**：工程上最关键的是**稳定性保证**。浅层 NN 还能用 Lyapunov 或描述函数近似分析，深度网络几乎不可能给出解析稳定性证明——这是当前学术界最活跃的 safe learning-based control 方向。课程必须诚实说明：NN 控制"能跑"不等于"可认证"。

**[方数]**：数学基础需要覆盖：万能逼近定理（静态逼近的存在性）、策略梯度定理 $\nabla_\theta J = \mathbb{E}[\nabla_\theta \log\pi_\theta \cdot A]$（RL 的核心）、Bellman 方程。但 REINFORCE/PPO 的完整推导超出本课范围，讲直觉即可。

**[周联]**：工程实现上，现在 PyTorch/JAX 是标配，但我们的 Jupyter 环境只有 numpy。所以：
- 前馈 NN（静态逼近）可以用 numpy 手推反向传播，完整展示训练
- 深度 RL 只能展示**预训练权重的推理**+ 简化版 REINFORCE，不能现场训练 PPO
- 重点放在概念理解和定量对比，不是训练工程

**[何仿]**：仿真验证方案：用同一个倒立摆，训练不同深度/宽度的前馈网络（监督学习），再用进化策略和简化 REINFORCE 直接优化，最后横向对比 PID。所有数字必须来自实际运行。

**[吴规]**：需求侧视角：规划模块关心的是 NN 控制器的**推理延迟**和**泛化边界**。深度网络推理慢、训练域外退化快，这对实时控制是硬约束。课程要给出定量数据。

**[领域-自动驾驶]**：真实场景中，NN 控制最成功的是端到端学习（pixels→actions）和 learned dynamics for MPC。特斯拉 FSD、Waymo 都用深度网络。但安全关键场景仍保留经典控制器做 fallback。课程应引用这些工业案例。

**[苏绘]**：交互组件需要大幅扩展，上一版只有一个不能调参的 NeuralNetworkExplorer：
1. **升级 NeuralNetworkExplorer**：增加网络结构选择（浅/中/深）、训练方式选择（监督/ES/RL）、初始角度滑块，实时闭环仿真
2. **新增 ControlSurfaceExplorer**：可视化控制曲面 $u(e,\dot e)$，对比 PID 的平面 vs NN 的非线性曲面，让读者直观看到"NN 学到了什么"

**[共识]**：
- 教学目标：理解 NN 在控制中的**四种角色**，掌握静态逼近的完整训练流程，了解深度 RL 的直觉，认识稳定性/安全性的局限
- 核心难点：策略梯度的直觉解释（不要求推导）；深度 vs 浅层的权衡
- 应用案例：倒立摆（与模糊控制两课保持一致）+ 自动驾驶端到端学习引用
- 前置知识：模糊控制基础、模糊控制器设计（已完成）
