## Phase 1：内容规划

**[陈控]** 上一课讲了模糊集合、推理、解模糊化——都是开环的。本课要回答的核心问题是：把模糊控制器放进闭环，到底能不能控住倒立摆？如果能，代价是什么？如果不能，问题出在哪？

**[林矩]** 数学上，Mamdani 型控制器是一个分段连续但不可微的静态非线性映射 $u = \Phi(e, \dot{e})$。闭环稳定性分析非常困难——Lyapunov 方法要求 $V$ 沿轨迹递减，但 $\Phi$ 的不可微性让 $\dot{V}$ 的符号判断变得极其复杂。Takagi-Sugeno 型可以绕过这个问题，但工程上 Mamdani 更常用。这是一个真实的矛盾。

**[卫韧]** 工程上，模糊控制器的核心挑战是比例因子整定。$G_e$、$G_{ce}$、$G_u$ 三个参数决定了闭环性能，但它们与控制器增益之间的关系是隐式的、非线性的。不像 PID 有 Ziegler-Nichols 公式，模糊控制没有通用的整定方法。

**[方数]** 需要的数学基础：隶属度函数的分段线性性、min/max 聚合的几何意义、重心法积分的数值计算。不需要新的数学工具，但需要把上一课的静态分析扩展到闭环动态。

**[周联]** 工程实现的关键是：规则库的设计必须保证负反馈。上一课的 fcd-log 显示，如果规则表写反了（正反馈），控制器会把摆推得更远。另外，比例因子的选择必须让归一化后的输入落在隶属度函数的有效支撑内——如果 $G_e$ 太小，$20^\circ$ 的偏差映射到归一域只有 $-0.35$，只激活 ZO 和 NS 的尾部，控制量几乎为零。

**[吴规]** 上游需求：模糊控制器应该比 PID 更容易整定（不需要精确的模型），或者至少在模型不确定性下表现更鲁棒。如果两者都做不到，工程上就没有理由用模糊控制。

**[共识]** 本课的教学目标：
1. 掌握 Mamdani 型模糊 PD 控制器的完整设计流程（规则库 → 比例因子 → 闭环仿真）
2. 用数值实验测量模糊 PD 的真实性能，与 PID 定量对比
3. 理解比例因子整定的敏感性和困难
4. 了解模糊 PID 的改进思路和局限性
5. 理解 Mamdani 型稳定性分析的困难和 TS 型的优势

## Phase 2：内容生成

### 第一轮：核心概念

**[陈控]** 模糊 PD 控制器的结构很直观：输入是误差 $e$ 和误差变化率 $\dot{e}$，输出是控制量 $u$。规则库的形式是"IF $e$ is NB AND $\dot{e}$ is ZO THEN $u$ is NB"。对于倒立摆稳定，$e = -\theta$（这样 $e$ 为负表示摆向右倒），$u$ 为负表示向左推。规则表必须保证负反馈：$e$ 为负时 $u$ 为负，$e$ 为正时 $u$ 为正。

**[林矩]** 规则表的数学表达：对于 $n$ 个语言值 $\{L_1, \ldots, L_n\}$（从 NB 到 PB），稳定化规则为 $R[i][j] = \text{round}((i+j)/2)$。这个公式的物理意义是：当误差和误差变化率都指向同一个方向时，控制量取两者的"平均"方向；当它们指向相反方向时，控制量取中间值（减速但不反转）。

**[何仿]** 数值实验显示（NB2），$n=5$ 的 PD-like 规则表给出不稳定的闭环：$\text{rms}\,\theta = 21.10^\circ$，6 秒末角度仍为 $21.69^\circ$。这意味着控制器根本没有把摆拉回来。问题出在比例因子：$G_e = 2.0$ 把 $20^\circ$ 映射到归一域的 $-0.698$，这个值只激活 NS 的尾部（隶属度约 0.2），控制量太弱。

**[卫韧]** 这就是模糊控制的核心困难：比例因子整定。增大 $G_e$ 可以增强控制作用，但 $G_e$ 太大会让归一化输入超出 $[-1, 1]$ 的范围，导致隶属度函数饱和。实验显示（NB3-Ge），$G_e$ 从 1.0 增加到 3.0，$\text{rms}\,\theta$ 从 $41.67^\circ$ 降到 $13.71^\circ$，但仍然没有稳定到 $\pm 5^\circ$ 以内。

**[周联]** 更糟糕的是，$G_{ce}$ 和 $G_u$ 的调节几乎没有效果（NB3-Gce、NB3-Gu）。这说明问题不在微分增益或输出增益，而在比例增益本身不够。但模糊控制器的比例增益是隐式的——它由规则表、隶属度函数和解模糊化方法共同决定，不像 PID 的 $K_p$ 可以直接调节。

**[方数]** 从数学上看，Mamdani 控制器的输入-输出映射 $\Phi(e, \dot{e})$ 在原点附近的梯度决定了等效比例增益。对于三角形隶属度函数和重心法解模糊化，这个梯度是分段常数，且最大值受限于隶属度函数的重叠度。当 $n=5$ 时，相邻语言值的中心间距为 $0.5$，重叠度为 $0.25$，这限制了等效增益的上限。

**[苏绘]** 可视化策略：需要一个交互组件让读者调节 $G_e$、$G_{ce}$、$G_u$ 三个比例因子，实时观察闭环响应。坐标轴固定（$\theta \in [-30^\circ, 30^\circ]$，$t \in [0, 6]$ s），禁用动画。另外需要一个 notebook 展示规则库的构造和输入-输出映射曲面。

### 第二轮：学生反馈

**[小初]** 我不明白为什么规则表要这样设计。为什么 $e$ 为 NB 时 $u$ 也要为 NB？

**[孙助]** 这是因为误差的定义是 $e = -\theta$。当 $\theta > 0$（摆向右倒）时，$e < 0$（为负）。要 stabilizing，需要 $u < 0$（向左推）。所以 $e$ 为负时 $u$ 也要为负，这就是负反馈。

**[李稳]** 我想问的是：为什么模糊 PD 不能稳定，但常规 PID 可以？两者的区别在哪里？

**[林矩]** 关键区别在于增益的可调性。PID 的 $K_p$、$K_i$、$K_d$ 是独立的参数，可以直接调节。模糊 PD 的等效增益由规则表、隶属度函数、比例因子共同决定，调节一个比例因子会同时影响多个方向的增益。实验显示，常规 PID 用 $K_p = 40$、$K_i = 10$、$K_d = 6$ 可以达到 $\text{rms}\,\theta = 2.67^\circ$，而模糊 PD 最好的情况也有 $\text{rms}\,\theta \approx 13^\circ$。

**[赵工]** 工程上这意味着什么？是不是模糊控制不适合倒立摆？

**[卫韧]** 不是不适合，而是 Mamdani 型的模糊 PD 不适合。如果要改善，可以：
1. 增加语言值数量 $n$（但计算量增加）
2. 用 TS 型代替 Mamdani 型（结论部是线性函数，增益可以更高）
3. 加积分项（模糊 PID）
4. 用非线性隶属度函数（高斯型，但支撑无限）

**[钱锐]** 我想挑战一下：模糊控制的优势不是在于不需要模型吗？如果我们需要精确调节比例因子，那不还是需要模型吗？

**[陈控]** 这是一个好问题。模糊控制的优势在于：规则库可以从操作员的经验直接提取，不需要精确的机理模型。但比例因子的整定确实需要一些试错或自动整定方法（如遗传算法、梯度下降）。本课不深入这些自动整定方法，但要让读者意识到这个困难。

## Phase 4：内容定稿

**[郑核-签发]** 内容通过审校，可以输出 MDX。

**关键发现（叙述服从测量）**：
1. Mamdani 模糊 PD 用 $n=5$ 规则、$G_e=2.0$、$G_{ce}=0.5$、$G_u=12$ 时，$\text{rms}\,\theta = 21.10^\circ$，6 秒末角度 $21.69^\circ$——**没有稳定**
2. 增大 $G_e$ 到 3.0 可以改善到 $\text{rms}\,\theta = 13.71^\circ$，但仍远未稳定
3. $G_{ce}$ 和 $G_u$ 的调节几乎无效（所有组合都在 $21^\circ$ 附近）
4. 常规 PID 用 $K_p=40$、$K_i=10$、$K_d=6$ 达到 $\text{rms}\,\theta = 2.67^\circ$，稳态 $-0.19^\circ$——**完全稳定**
5. 模糊 PD + 积分（$K_i=8$）可以改善到 $\text{rms}\,\theta = 18.22^\circ$，但仍振荡（稳态 $-21.09^\circ$）
6. PD-like 规则表（$\text{rms}=21.10^\circ$）优于 P-like（$14.53^\circ$ 但振荡）和 D-like（$115.97^\circ$ 完全不稳定）

**教训**：
- 模糊控制不是"智能"的万能药——对于倒立摆这种快速不稳定系统，Mamdani 型的隐式增益限制是致命的
- 比例因子整定是模糊控制的核心工程挑战，没有通用方法
- 常规 PID 在这个问题上完胜模糊 PD，因为 PID 的增益可以直接调节
