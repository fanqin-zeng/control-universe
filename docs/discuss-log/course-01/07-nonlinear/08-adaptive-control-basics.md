## Phase 1: 内容规划

参与者：陈控、林矩、卫韧、方数、周联、吴规、[领域-机器人]、[领域-航空航天]

[陈控] 自适应在经典脉络里的位置：**它是"整定"这件事的自动化**。工程师调 PID 靠试凑，增益调度靠查表，自适应靠在线测量。本课要立的第一个直觉是——自适应不是"更聪明的 PID"，它是**把设计公式里的未知数当成状态变量一起积分**。第二个直觉更重要：跟踪无差和参数收敛是两件事，前者容易后者要 PE，这个区分是全课的主线。

[林矩] 数学骨架三条：① 误差方程 $\dot e = a_m e + b\tilde k_1 x_p + b\tilde k_2 r$ 是"线性时变 + 参数误差驱动"结构；② CLF $V = e^2 + \frac{|b|}{2\gamma}(\tilde k_1^2+\tilde k_2^2)$ 的交叉项被自适应律**精确**吃掉，$\dot V = a_m e^2$；③ Barbalat 给 $e\to0$，但**给不出** $\tilde k\to0$——那需要 PE。**新增一条旧稿完全没有的结构结论**：$\dot V = a_m e^2$ 只约束了 $e$ 这一个方向，所以 $V$ 有界不代表 $\tilde k$ 有界；参数项在 $V$ 里的权重是 $\frac{|b|}{2\gamma}=7.5\times10^{-3}$（$\gamma=200$），$V$ 几乎不增加就能容纳巨大的 $\tilde k$。这是"γ 大 ⇒ 漂移没人管"的数学根源。

[卫韧] 自适应的主场是**匹配的参数不确定性**，它的三条死穴必须全部量化：(1) **未建模动态**——Rohrs 反例，$\gamma$ 有硬上界，越界直接发散；(2) **量测噪声**——纯积分自适应律把白噪声积分成随机游走，$\sigma$-修正/$e$-修正/死区/投影四种手段各自的价格要单独报价；(3) **匹配条件**——$\theta$ 落在 $B$ 列空间外时最小二乘残差恒等于 $|\theta|$，与 $K$ 无关，这是结构性的，调增益没用。这里要和「反步法设计」一课接口一致：反步的 tuning function 能处理**不匹配**的参数化不确定性，靠的是每级注入虚拟控制，不是靠更大的增益。

[方数] 四件数学家务：(1) **PE 要数值化**——用 $\lambda_{\min}\!\big(\int_t^{t+T_0}\varphi\varphi^{\mathsf T}\big)$ 而不是肉眼看"信号够不够丰富"，四种参考（阶跃/单正弦/多正弦/调节）各算一个数；(2) **可辨识性要数值化**——单频参考下 $\varphi$ 的两列近共线，回归矩阵接近奇异，用 $\hat J$ 收敛到**负惯量** $-1.99$ 这个反常识结果把"参数错了控制还对"钉死；(3) **恒等式验证要用解析式而非数值微分**——$\dot V$ 的验证偏差因此落在机器精度（$10^{-14}$ 量级），而不是被差分截断误差污染；(4) **RLS 的正确性用"与批量 lstsq 逐点比对"来证**，并用 $P_0$ 扫描证明偏差按 $1/P_0$ 精确缩放——这才叫实现了同一个目标函数。

[周联] 工程账五条全给数字：① 在线计算量（一阶例子每步不到 10 次浮点运算，旧稿说"计算量大"是错的）；② 除零风险（STR 的确认等价 $K_p=(z_d-\hat\alpha)/\hat\beta$，$\hat\beta(0)=0$ 时第一步就 nan）；③ 噪声幅度标定的**方法论红线**：离散噪声幅度必须是 $\text{std}\cdot\sqrt{2\tau_n/dt}$，否则连续时间噪声强度会随步长变化，所有"噪声下"的结论都不可比；④ 执行器限幅（$\gamma=1000$ 时 $\max|u|=60$ 顶到限幅）；⑤ 采样率与 RK4 稳定域（$dt$ 必须随 $\gamma$ 收缩，否则测到的是积分器发散不是系统发散）。

[吴规] 需求侧只问一件事：**什么时候该用自适应，什么时候该用增益调度**。所以案例 2 必须是三方同台（固定增益 / 增益调度 / MRAC），而且要给调度两种版本——表精确 vs 表有 30% 误差。验收指标写成可测清单：rms|e|（分段：爬升段/顶点后）、max|e|、末值、max|u|、恢复时间、收敛时刻（$|e|$ 首次持续低于阈值）。"自适应更灵活"这类词一律换成报价单。

[领域-机器人] 案例 1 用单连杆机械臂的**负载突变**：$J=J_0+mL^2$、$mgL$ 都随抓取物体跳变，$B$（轴承粘性摩擦）不随负载变——所以正确做法是**只自适应 $[J, mgL]$，$B$ 离线标定**。$t=3$ s 时负载从 1 kg 跳到 5 kg，$J$ 从 0.45 跳到 1.45（3.2 倍）、$mgL$ 从 4.905 跳到 24.525（5 倍）。对照组要有两个：定增益计算力矩（冻结 $m=2$ kg）和纯 PD（不补偿重力/惯量）。

[领域-航空航天] 案例 2 用飞行器**爬升剖面**：0→10000 m 用 60 s，大气密度比 $\sigma$ 从 1 掉到 0.3084，$a_0,a_1,b$ 同比例按 $\sigma$ 衰减。这个例子的好处是**直流增益严格不变**（分子分母同乘 $\sigma$ 约掉了），所以固定增益不会失稳，只是 $\omega_n$ 和 $\zeta$ 都按 $\sqrt\sigma$ 下降（3.000→1.666，0.900→0.500）——高空既变慢又变振荡，误差来自带宽下降的相位滞后。**必须纠正一个常见误解**：理想增益 $k_1^*$ 会**改变符号**（+0.175→−0.330），而且三个增益涨的倍数完全不同（$k_r^*$ 涨 3.24 倍恰好 $=1/\sigma$、$k_2^*$ 涨 4.56 倍、$k_1^*$ 只涨 1.88 倍还要翻号）——旧稿"三个增益都涨约 3 倍"是错的。

[共识] 教学目标：① 说清"跟踪无差 ≠ 参数收敛"并用 $\lambda_{\min}$ 与直流增益匹配流形两个数值证据支撑；② 独立完成一阶 MRAC 的 CLF 推导与手算设计，并解释 $\gamma$ 的两面性；③ 写出高阶匹配条件、用最小二乘残差判定匹配是否有解；④ 实现 RLS + 确认等价 STR，并说清遗忘因子权衡与除零保护；⑤ 定量说出五条局限（PE / γ 上界 / 噪声 / 匹配条件 / 除零）各自的代价与缓解手段的价格；⑥ 用两个真实案例回答"何时用自适应、何时用调度"。大纲按 catalog 既有 13 个小节执行。可视化：1 个交互组件 + 9 个 notebook + 1 张概念图。

[苏绘] 可视化决策：交互场景 = MRAC 实验台（拖 $\gamma$、$\sigma$、噪声幅度、切参考信号、开关未建模极点，看响应/误差/参数平面三联图）→ React 组件 `MracExplorer`（三面板全部固定坐标轴；`animation:false`；行内样式；参数平面画出**直流增益匹配流形**这条线，让"停在流形上而不在理想点"变成看得见的几何事实）。代码演示场景 = 9 个 notebook（恒等式验证 / 手算复核 / γ 两面性 / 高阶匹配 / RLS / STR / 噪声与四种修正 / 机械臂 / 飞行器）。**额外任务**：概念图用 matplotlib 计算图重画（MRAC 直接法回路 + STR 间接法回路，并在 STR 那半边标出"确认等价的两个失效点"）。
