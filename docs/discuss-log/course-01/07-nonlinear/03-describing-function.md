## Phase 1: 内容规划

参与者：陈控、林矩、卫韧、方数、周联、吴规、[领域-电力电子]、[领域-机器人]

[陈控] 这一课在经典脉络里的位置：**它是 Nyquist 判据的"振幅推广"**。线性环里判稳定看 $G(j\omega)$ 是否穿过 $-1$；非线性环里把增益换成随振幅变化的 $N(A)$，于是 $-1$ 变成一条轨迹 $-1/N(A)$，"穿过"变成"相交"，交点就是极限环。要立的第一个直觉是：**描述函数不判断稳定，它预测振荡**——它回答的是"振多大、多快、稳不稳"，不回答"从任意初值收敛到哪"。第二个直觉是这套方法的便宜之处：一张 Nyquist 图加一条实轴上的轨迹，纸上就能给出振幅和频率，这是相平面做不到的（相平面只能二阶）。

[林矩] 数学骨架四条：① 傅里叶基波投影 $a_n,b_n$ 与复数惯例 $N=(b_1+ja_1)/A$（因为输入取 $\sin$，不是 $\cos$）；② 谐波平衡 $N(A)G(j\omega)=-1$ 是两个实方程、两个未知数 $(A,\omega)$，一般有孤立解，但**可能退化成一族**（$G$ 整段落在负实轴上时）；③ 稳定性用 Loeb 判据：交点处 $A\uparrow$ 后 $-1/N$ 的新位置落在 Nyquist 曲线"不包围"的一侧则稳定，等价于"把 $N(A)$ 当环路增益时闭环仍稳定"；④ 尺度性质：静态非线性的 $N$ 只依赖 $A$ 与参数的比值（如 $A/a$、$h/A$、$b/A$），不依赖 $\omega$。**新增一条旧稿完全没有的结构结论**：$A_1/A_p = 32/\pi^3$ 对继电器-双积分器轨道是恒等式，所以 DF 的周期公式在那个退化例子里其实是精确的，失效的只是"振幅可预测"。

[卫韧] 描述函数的主场是**弱非线性 + 良好低通**的环路；它的死穴必须逐条量化，不能像旧稿那样只写"强非线性时可能失效"：(1) **滤波假设**——谐波漏回来会移动继电器的切换时刻，这是相位效应，THD 小也挡不住；(2) **谐振峰**——$3\omega_0$ 附近有结构模态时 DF 直接崩；(3) **退化几何**——$G$ 整段在负实轴上（双积分器）时解不孤立；(4) **阶数不足**——继电器 + $1/s$ 是滑动模态，切换频率随 $dt$ 发散，DF 判"无解"结论对但机理错；(5) **串联不可乘**、**看不见平衡点与吸引域**。这里要和「滑模控制」一课接口一致：抖振正是那一课的主题，DF 的盲区就是滑模的主场。

[方数] 四件数学家务：(1) **闭式必须核过**——五个常用 $N(A)$ 全部用 40000 点傅里叶积分在 $A\in[0.4,6]$ 的 60 个点上逐点相减，光滑被积函数应到 $10^{-9}$、含跳变的只到 $10^{-4}$（收敛阶不同，本身就是教学内容）；(2) **复数惯例要用反例钉死**——把 $(a_1+jb_1)/A$ 与闭式对比，差 $2.26$、相位从 $-17.5^\circ$ 跳到 $+107.5^\circ$；(3) **手算例要能手算**——$\omega_0=\sqrt2$、$G=-1/3$、$A_0=4/(3\pi)$，全程不依赖数值求解，再用仿真仲裁；(4) **给"滤波好不好"一个可算的量**——单比值 $|G(j3\omega)/G(j\omega)|$ 只是筛查，改用泄漏指标 $L=\sum_{n\ge3,n\ \text{odd}}|G(jn\omega_0)|/n\big/|G(j\omega_0)|$，并且要实测 $L$ 与幅值误差**不单调对应**的反例。

[周联] 工程账五条，全部要数字：① 精度定价（每个环路给 $L$ / THD / 幅值误差 / 周期误差四列）；② 仿真步长与切换计数（抖振实验必须扫两个 $dt$ 证明频率 $\propto 1/dt$，否则读者会以为是真实物理频率）；③ 离散噪声/步长红线沿用上一课结论（本课无噪声实验，故不涉及）；④ 执行器寿命指标：继电器每秒切换次数（滞环把频率钉在 $0.349$ Hz，无滞环时 $294$ 次$/5$ s 且随 $dt$ 增长）；⑤ 内核 30 s/cell 上限——所有 cell 必须实测计时，最慢的一格要报出来。

[吴规] 需求侧只问一件事：**什么时候该信 DF 的数、什么时候必须仿真**。所以正文必须有一张"定价表"（$L$ → 误差），还要有一张"失效清单"（判据 → 实测证据 → 缓解手段与价格）。验收指标写成可测清单：预测幅值 vs 实测基波（整周期傅里叶）、预测周期 vs 实测过零周期、THD、切换次数、起振时间。"工程上很常用""精度较高"这类词一律换成报价单。第三个需求：DF 的**反问题**（给振荡指标解元件参数）比正问题更有工程价值，必须单列一个案例。

[领域-电力电子] 案例 1 用**滞环继电器振荡器**：滞环电流调制器（hysteresis current-mode control）和温控继电器都是这个结构，滞环宽度决定开关频率、继电器幅值决定输出幅值，工程上需要在不搭仿真的情况下算出开关频率。这个例子还能顺带纠一个常见误解：**二阶环路 + 理想继电器永远不会自激振荡**（相位最多趋近 $-180^\circ$ 而不达到），是滞环提供的相位滞后把总相位推到 $-180^\circ$。而且 $G=K/(s(s+1))$ 配滞环继电器时谐波平衡**可闭式求解**（$\omega=\sqrt{1-r^2}/r$、$4MKr^3=\pi h\sqrt{1-r^2}$），既能当正文算例又能当习题。

### 第一轮 — 概念讲解

[陈控] 引言用"伺服轴只在大指令下振荡"开场：降增益振荡消失但刚度变差、调回去又振——这正是饱和与线性环路共同产生极限环的日常版本。第二段直接立定价表（五个环路的 $L$ / THD / 幅值误差），把"这个近似好不好"从信仰问题变成测量问题，并当场给出反直觉读数：$-20$ dB 经验门槛只是筛查，第二行踩在门槛上误差就有 $10.6\%$。

[林矩] 定义一节：先给傅里叶级数与系数积分，再由 $y_1=A|N|\sin(\omega t+\varphi)$ 对比系数导出 $b_1=A|N|\cos\varphi$、$a_1=A|N|\sin\varphi$，于是 $N=(b_1+ja_1)/A$。三条结构性事实（奇对称无记忆 → 实数；带记忆 → 虚部为负；$N$ 只依赖 $A$，且 $A$ 是**环节输入端**幅值）。滤波假设单独成段，并立刻用实测打脸"谐波很小"的错觉：饱和在 $A=2$ 时自己就产生 $22.6\%$ 的三次谐波。

[卫韧] 稳定性判据一节：Loeb 判据的 Nyquist 读法（$A\uparrow$ 后 $-1/N$ 落在不被包围侧 → 稳定），再用"等效增益"语言重述一遍（把 $N(A)$ 当 $K$，用线性判据检查），并用 Routh 交叉核对：$0.5s^3+1.5s^2+s+K$ 稳定当且仅当 $K<3$，与极点实部数值（$K=2.9$ 全负、$K=3.1$ 出现 $+0.009$）一致。双交点算例给出完整的吸引域图像：$A_1$ 是边界、$A_2$ 是稳定极限环。

[方数] 常见非线性一节：五行闭式表（理想继电器 / 滞环继电器 / 饱和 / 死区 / 间隙），每行都标注实数还是复数、虚部符号、以及 $A$ 的阈值条件（$A>h$、$A\ge a$、$A>b$）。然后当场拆穿"串联可乘"这个省事做法，并给出正确做法（组合映射整体做傅里叶积分）。

[周联] 手算例一节：$G_3=1/(s(s+1)(0.5s+1))$ 的分母展开 $(j\omega)(j\omega+1)(0.5j\omega+1)=-1.5\omega^2+j(\omega-0.5\omega^3)$，虚部为零给 $\omega_0=\sqrt2$，$G=-1/3$，$A_0=4/(3\pi)=0.424413$；仿真仲裁 $0.445089$（$+4.87\%$）。**并加跑第二个环路**（$0.05s+1$）：$\omega_0=\sqrt{20}$、$A_0=0.060630$、实测 $+10.58\%$，用来说明"把极点推远反而更差"，因为 $\omega_0=\sqrt{1/T_c}$ 跟着涨。

[吴规] 应用案例一节按三种用法组织：正向预测（滞环振荡器）、诊断（饱和伺服的 $K<3$ 门槛）、反推设计（给 $A$、$f$ 解 $h$、$K$）。汇总表把四个有极限环的算例并排：幅值误差最大 $3.05\%$、周期误差最大 $1.67\%$、THD 最大 $0.0413$。

## 附录 C：环境与工具链问题（供后续课程复用）

1. **urllib 走系统代理导致内核服务器 502**：本机注册了系统代理（`127.0.0.1:33210`），Python 的 `urllib.request` 默认读取系统代理设置，对 `http://127.0.0.1:8891/api/notebook` 的 **POST** 被代理拦下并返回 `502 Bad Gateway`（GET `/health` 却能通过，极易误判为服务器故障）。修法：harness 用 `urllib.request.build_opener(urllib.request.ProxyHandler({}))` 绕过代理。
2. **内核 API 响应结构**：`POST /api/notebook/<id>/execute` 返回 `{"outputs": [...]}`，需要解包 `['outputs']`，否则报 `TypeError: string indices must be integers`。
3. **heredoc 吞一层反斜杠**：`python - <<'PY'` 里写 `\times` 会被吞成 TAB、`\rvert` 变成 CR。凡含反斜杠的脚本/MDX 一律用 Write/Edit 工具落盘，改完立即检查 CR/TAB 计数为 0。
4. **30 s/cell 上限**：本次最慢 cell 4.05 s（NB6 cell1，两次 $1.2\times10^6$ 步级联仿真），余量充足；但 NB4 的二分阈值实验（14 次 × 60 s 仿真）已用 dt$=5\times10^{-4}$ 压到 3.8 s，后续同类实验沿用该步长。
