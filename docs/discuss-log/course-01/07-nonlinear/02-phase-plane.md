## Phase 1: 内容规划

参与者：陈控、林矩、卫韧、方数、周联、何仿、吴规、[领域-机器人]、[领域-精密仪器]

[陈控] 这一课在整门课里的位置：**它是"线性化失效之后"的第一件工具**。前面所有课都在用线性化（传递函数、状态空间、Lyapunov 间接法），而相平面是第一个不需要线性化就能给出全局图像的方法，代价是只能看二阶。要立的直觉有两条：① 相图上的每条曲线是一次完整的人生（一条轨迹 = 一个初值的全部未来），平衡点分类只是"出生地附近的天气预报"；② nullcline 是骨架——流在 nullcline 上不是零，而是**切向**的，只有交点才静止，这个误解必须当场纠正。

[林矩] 数学骨架五条：① 自治性 $\dot x=f(x)$ 保证轨迹不相交（唯一性），这是相图能"读"的前提；② 平衡点分类 = Jacobian 的 $(\operatorname{tr},\det)$ 二参数族，$\Delta=\operatorname{tr}^2-4\det$ 是焦点/节点分界、$\det=0$ 是非孤立、$\operatorname{tr}=0,\det>0$ 是线性中心；③ Hartman-Grobman 只在双曲点（$\operatorname{Re}\lambda\neq0$）成立，$\det=0$ 与 $\operatorname{tr}=0$ 两类非双曲点必须各给一个反例；④ 鞍点的稳定/不稳定流形是**分界线**，吸引域边界由它决定——这比"能量判据"精确；⑤ Poincaré-Bendixson 的完整前提：正不变紧集、**挖去全部平衡点**、二阶连续 → 必有闭轨；旧稿漏了"挖去"二字。

[卫韧] 三个"线性化会说谎"的现场必须量化：① 非双曲中心（$\dot x_1=x_2,\ \dot x_2=-x_1+a x_2 r^2$）：$J(0)$ 对一切 $a$ 都是 $\begin{bmatrix}0&-1\\1&0\end{bmatrix}$，但 $a>0$ 时有限时间爆破、$a<0$ 全局渐近稳定、$a=0$ 才是真中心——解析解 $r(t)=r_0/\sqrt{1-2ar_0^2t}$、$t^*=1/(2ar_0^2)$ 要逐字核对；② 能量判据的适用域：$E<\Delta V$ 只在势阱内部有效，初值在势垒外侧时 $E<\Delta V$ 也逃逸；③ 受迫系统的稳定性不能看相图，要看 Poincaré 截面上的 Floquet 乘子，且 **Liouville 公式给出 $\det(DP)=e^{-dT_p}$ 与驱动幅值 $A$ 无关**——这条恒等式是本课最硬的结构结论，必须实测验证。

[方数] 数学家务四件：① 迹-行列式分类表要用 2000 次随机矩阵抽查（tr/det → 特征值 → 分类三条路互核）；② 首次积分 $H=\delta x-\gamma\ln x+\beta y-\alpha\ln y$ 的守恒性要用相对漂移实测（区分"真中心"与"线性化假中心"）；③ 极限环的"孤立"与"一族"要用两个对照系统钉死（Van der Pol 的振幅与初值无关 vs Lotka-Volterra 的振幅由初值决定）；④ 所有闭式（小 μ 周期 $2\pi(1+\mu^2/16)$、大 μ 的 $(3-2\ln2)\mu$、爆破时刻 $t^*$）都要与数值解对到 $10^{-3}$ 以内，对不上的写进正文当误差来源。

[周联] 工程账：① 每个 notebook cell 实测计时并报最慢一格（内核 30 s/cell 上限）；② 受迫 Duffing 的变分方程用**增广状态**一次积分同时拿 $P(s)$ 与 $DP(s)$，不要有限差分（但保留一次有限差分交叉核对，报差值）；③ 沿参数延拓要用上一个 $A$ 的解做初值，**延拓失败本身就是分岔信号**，残差要打印；④ 混合系统（无轮辐轮）的碰撞律 $w^+=w^-\cos(2\alpha)$ 与 Poincaré 映射斜率 $dP/dw$ 都要实测，"恢复到 1% 需要多少步"是工程师真正要的数。

[吴规] 需求侧三问：① 给我一个"拿到一个二阶系统先做什么"的清单（画 nullcline → 找平衡点 → 分类 → 看流形 → 必要时 PB）；② 告诉我每个结论的**价格**（线性化免费但局部、相图全局但只二阶、PB 只给存在性不给位置、Floquet 要算变分方程）；③ 高维怎么办——Poincaré 截面 + Floquet 乘子是接口，必须给出与二阶相图的对应表（闭轨 ↔ 截面不动点、稳定性 ↔ $|\mu|<1$、分岔 ↔ 乘子穿单位圆）。

[领域-机器人] 无轮辐轮（rimless wheel）是被动动态行走的标准模型：连续相是 $\ddot\theta=\frac{g}{l}\sin(\theta-\gamma)$ 类的摆方程，离散相是触地碰撞 $w^+=w^-\cos2\alpha$，极限环 = 周期步态，乘子 $|dP/dw|<1$ = 步态自稳定。这个案例的价值在于：**相平面方法天然覆盖混合系统**，只要把截面取在碰撞前一刻。参数取 $\alpha=24^\circ$、坡角 $12^\circ$，是文献里能走起来的组合。

[领域-精密仪器] MEMS 谐振式传感器与振动能量采集器都是受迫 Duffing：$\ddot x+d\dot x+x-x^3=A\cos\omega t$ 型（软弹簧）。工程上关心的是：同步周期轨道在多大驱动幅值内保持稳定、失稳后变成什么（周期倍化 → 混沌的前兆）。所以 NB10 必须把"判别式变号点"与"失稳点"**分开测**——前者只是乘子从复数对变实数对，后者才是乘子穿出单位圆，两者在 $A$ 轴上相差约 0.02，混为一谈会误导设计裕度。

[共识] 教学目标：① 会画并会读相图（nullcline 骨架、轨迹方向、平衡点标记）；② 用 $(\operatorname{tr},\det,\Delta)$ 完整分类并说出两类非双曲点为何失效；③ 独立完成 Duffing 手算例（平衡点、分类、势垒、逃逸阈值）并用仿真仲裁；④ 用鞍点流形解释吸引域边界，说出能量判据的适用域；⑤ 陈述 Poincaré-Bendixson 的完整前提并会构造环域；⑥ 用 Poincaré 截面 + Floquet 乘子判断受迫/混合系统周期轨道的稳定性，说出 $\det(DP)=e^{-dT_p}$ 的后果；⑦ 识别 saddle-node / flip / Hopf 三类截面分岔的乘子签名。大纲 15 个 H2：引言 / 相平面与向量场 / Nullcline 与平衡点 / 平衡点分类：迹-行列式平面 / 线性化何时失效 / 手算例：非线性振子的完整相平面 / 鞍点分界线与吸引域 / Poincaré-Bendixson 定理与极限环 / 应用案例 / 高维推广：Poincaré 截面与 Floquet 乘子 / 分岔：相图的拓扑突变 / 局限性讨论 / 小结 / 习题 / 答案。**顺序调整**：手算例放在鞍点分界线之前（先有完整算例的平衡点与势垒，分界线才有落点）。可视化：2 个新交互组件（`PhasePlaneExplorer` 五系统、`TraceDetExplorer` 迹-行列式平面）+ 12 个 notebook 组件（NB10 拆上/下）。

[方数] 分类一节：$(\operatorname{tr},\det)$ 平面三条分界线（$\Delta=0$ 抛物线、$\det=0$ 横轴、$\operatorname{tr}=0$ 纵轴）划出八种情形表，每行给特征值签名与相图形状；再用 2000 次随机矩阵把"tr/det → 分类"与"直接算特征值 → 分类"互核，0 例不一致。补一句与控制课的接口：$\operatorname{tr}=-2\zeta\omega_n$、$\det=\omega_n^2$，迹-行列式平面就是阻尼比平面。

[周联] 手算例一节（Duffing $\dot x_1=x_2,\ \dot x_2=-x_1-dx_2+0.2x_1^3$，$d=0.5$）：平衡点 $0,\pm\sqrt5$；原点 $\operatorname{tr}=-0.5,\det=1,\Delta=-3.75,\lambda=-0.25\pm0.968246j$（稳定焦点）；$\pm\sqrt5$ 处 $\det=-2$（鞍点）。势函数 $V=x^2/2-0.05x^4$，$\Delta V=V(\sqrt5)-V(0)=1.25$。逃逸表：$E=0.4/0.8/1.2/1.24/1.2499$ 都留在阱内，$x_0=2.30/2.50/3.00$ 全部逃逸到 $10^{13}$——**其中 $x_0=2.5$ 的 $E=1.171875<1.25$ 仍然逃逸**，这一行就是能量判据的死刑判决书。
