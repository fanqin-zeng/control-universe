## 负面案例：标注线渐入动画影响拖动体验

**问题描述：** ECharts 默认给 markLine 添加了渐入动画效果。当用户持续拖动 T 滑块时，每次参数变化都会触发动画重新播放，导致虚线标注"一直出不来"或闪烁，影响使用体验。

**用户原话：** "用户很有可能一直在拖动，那么线就一直出不来，动态效果反而影响了使用体验"

## 正面案例：禁用动画，即时响应

**解决方案：** 在主曲线 series 上设置 `animation: false`，禁用所有动画效果。这样当用户拖动滑块时，标注线会立即出现在新位置，无延迟、无闪烁。

**代码变更：**
```diff
  {
    type: "line",
    data: curveData,
    smooth: true,
    showSymbol: false,
+   animation: false,
    lineStyle: { width: 3, color: "#3b82f6" },
```

## 教训

- 交互式可视化中，"即时反馈"优先于"视觉效果"
- 当用户高频操作时（如拖动滑块），动画会成为干扰而非增强
- ECharts 默认启用动画，需要在交互场景中显式禁用
