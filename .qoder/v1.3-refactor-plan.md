# v1.3 重构计划

> 根据"可视化双轨制"原则，对所有已编写课程的代码块进行分类重构。

## 重构原则

每个代码块按以下决策树分类：

```
这个代码块有可调参数吗？
├── 否 → 保持 <JupyterNotebook>（静态输出）
└── 是 → 读者需要拖动参数看变化趋势吗？
    ├── 否 → 保持 <JupyterNotebook>（静态多曲线对比）
    └── 是 → 改为 React 交互组件（<XxxExplorer>）
```

**关键判断**：
- ipywidgets 代码 → **必须重构**（已坏，无法运行）
- 有 slider 且展示"参数→特性"映射 → 改为 React 组件
- 纯计算/演示/验证 → 保持 JupyterNotebook
