## 负案例

用户浏览器运行报 `name 'feedback' is not defined`。根因三层：
1. `from scipy.signal import lti, feedback, step, margin` —— **feedback/margin 属于 control 库**，scipy 从无此二名（ImportError 被 setup 吞掉后表现为 NameError）；
2. **scipy ≥1.12 移除了 lti 的算术运算符**（`C*plant`、`GH/(1+GH)` 全部 TypeError）——内核 scipy 已是 1.18.1，E3 时代（旧 scipy）S6 全绿是版本侥幸，且 E3 当时 S6 实为 SKIPPED；
3. 连带 API 漂移：`bode(plot=)` kwarg 移除且返回三元组、`scipy.signal` 无 `tf`、`cont2discrete` 返回 5 元组、numpy 2.x 禁止 1×1 数组隐式转标量、`freqresp` 二元组按三元解包。
