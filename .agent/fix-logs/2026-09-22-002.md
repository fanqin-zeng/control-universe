## 负面案例：横坐标轴随 T 动态缩放

**问题描述：** 拖动 T 滑块时，横坐标轴范围 `tEnd = Math.max(6*T, 3)` 会跟着变化，导致 T/3T/4T 标注线在屏幕上的位置几乎不变。用户无法直观感受到"参数变化导致指标在时间轴上移动"的效果。

**用户原话：** "现在拖动修改参数时，几个指标在屏幕上都是相同的位置"

## 正面案例：固定横坐标轴，让标注线移动

**解决方案：** 将 `tEnd` 改为固定常量 `30`（覆盖 T 最大值 5.0 时 6T=30 的范围）。这样当 T 变化时，T/3T/4T 的竖线标注会在固定的坐标轴上左右移动，视觉上更直观地展示参数对响应速度的影响。

**代码变更：**
```diff
- const tEnd = useMemo(() => Math.max(6 * T, 3), [T]);
+ const tEnd = 30;
```

## 教训

- 交互控件中，"固定参考系 + 移动目标"比"动态缩放 + 目标不动"更利于理解参数影响
- 设计动态可视化时，优先考虑让用户看到"什么在变"，而不是"什么都跟着变"
