## 负案例

用户运行"三种方案阶跃响应与开环增益对比"等 notebook 时，图表中文标签全部渲染为方框，stderr 刷 `UserWarning: Glyph 38454 (\N{CJK UNIFIED IDEOGRAPH-9636}) missing from font(s) DejaVu Sans`。根因：这些 notebook 的 setupCode 只 `import matplotlib.pyplot` 而**未配置 `font.sans-serif`**，matplotlib 回退到 DejaVu Sans（无中文字形）。

## 正案例

1. **先测后修（叙述服从测量）**：本机 matplotlib fontManager 实测含 Microsoft YaHei / SimHei / SimSun / KaiTi / DengXian；设 rcParams 后渲染"阶跃响应对比 超调量分布 ±2%"0 警告 → **走补字体方案，不改英文标签**。
2. 全仓扫描（规则：setup 含 `import matplotlib.pyplot`、无 `font.sans-serif`、且 cell 实际调用 plt 绘图）命中 21 处，统一在其 setupCode 追加 `plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei', 'DejaVu Sans']` 与 `plt.rcParams['axes.unicode_minus'] = False` 两行；cell 一字未动。
3. 复验（内核 8891 实跑）：case-study 6 cell / time-domain 2 cell —— **0 error、0 Glyph 警告**，课程级从 WARN 升为 **PASS**；`npm run check` 退出码 0。

## 清单更新（秦构）

1. setupCode 模板新增必查项：凡 `import matplotlib.pyplot` 且 cell 绘图，必须带上两行 rcParams（Windows 内核字体已实测可用；跨平台部署时随 TR1/TR2 复测）。
2. fix-021 的补丁模板（lti 算术 + feedback/margin）与本次字体行**合并为同一 setup 起手式**，新课一律从此复制。
