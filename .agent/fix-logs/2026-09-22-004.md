# Fix-004: Jupyter Notebook ipywidgets 不可用

| 字段 | 值 |
|------|-----|
| 日期 | 2026-09-22 |
| 文档 | classic/system-modeling.mdx |
| 章节 | 阻尼的关键作用 |
| 类型 | BUG |

## 现象

Notebook 运行后报错：`NameError: name 'interact' is not defined`

## 根因分析

**三层原因叠加导致此问题：**

1. **依赖缺失**：`requirements.txt` 未包含 `ipywidgets`，导致 `from ipywidgets import interact, FloatSlider` 失败
2. **Setup 错误被静默吞掉**：`scripts/jupyter_server.py` 在执行 setup code 时丢弃了错误输出（`execute(km, kc, setup)` 的返回值未检查），前端无任何报错提示
3. **架构不兼容**：即使安装了 ipywidgets，`interact()` 生成的是交互式 widget，需要 Jupyter Notebook 前端渲染。我们的轻量级 HTTP 服务器只处理 text/image/html 输出，**无法渲染 widget**

## 修复方案

**弃用 Jupyter Notebook，改用 React 交互组件 `SuspensionExplorer`**：
- 创建 `components/wiki/suspension-explorer.tsx`，使用 ECharts 渲染
- 提供 ζ 滑块（0.05 ~ 2.0），实时显示阶跃响应曲线
- 显示物理参数：阻尼状态、阻尼系数 c、质量 m、刚度 k
- 固定 x 轴范围，禁用动画（应用 fix-002、fix-003 的教训）

## 教训 / 规则

> **Jupyter Notebook 组件中禁止使用 ipywidgets / interact。**
>
> 本项目的 Jupyter 服务器是轻量级 HTTP 服务，不支持 widget 渲染。所有 notebook 代码必须是"运行一次即出图"的静态脚本模式。如需交互控件，应使用 React 组件（如 `SuspensionExplorer`、`FirstOrderStepExplorer`）而非 Python widget。
