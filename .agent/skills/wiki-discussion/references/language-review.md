# 初学者课程的表达与顺读审查

2026-10-18用户裁决；适用于所有后续新写、重构与润色。每课读者都是第一次学这一课；已学先修只减少必要回顾，不能当作读者熟悉本课术语。

## 文简：先把话写清楚

- 从读者要解决的问题组织讲解；先说对象和动作，再给名称、符号与式子。每段只推进一个问题，公式前解释为什么要列，公式后解释每一项与结果。
- 用具体中文替代工作汇报式名词。不要写“跨结构优劣排名/通道与取舍”；写“只看控制器名称，判断不了谁更快。还要看参数怎么选，以及你希望减少超调还是加快响应”。不能只换同义词，必须说明对象、比较条件和想传达的意思。
- 技术条件只在确有误解风险的位置解释其后果。例如叠加先说明零初始状态下两次输入对应的输出如何相加；非线性失效用具体例子。固定非零初值的例外若不服务当前问题，移到选读，不在开头插入。
- 主线只保留达到学习目标所需内容；长数表、求解器精度、额外行业案例、历史纠错说明放合适的实验/选读或过程档案。不能把一课写成所有例外的汇编，也不能借删说明改掉定理条件。
- 可以自然幽默，不强行加梗，不用玩笑代替定义。不以字数短当易懂，也不牺牲正确性。
- 页面不展示验收、交付、目录维护状态等内部流程。保留读者需要的运行/错误反馈、必要依赖说明与可操作的停止范围；常规运行说明不在每个代码框重复。

## 沈读：从头读到尾，不偷看后文

顺读前读 `.agent/semester-03/language-memory.md`，只把有来源的已学概念和本次明确的读者起点当作已知。按页面出现顺序阅读正文、图注、控件文字、公式解释、习题和答案；不能借作者知识或后文定义“倒填”首次出现的解释。

逐项记录：位置/当时已知/新术语或跳步/为什么会卡住/修改/重读结果。尤其拦截：首次出现无解释、只为证明作者严谨而插入的旁枝、含混指代、翻译腔与报告腔、一口气引入多概念，以及移走关键条件造成的错误。可移动补充说明，不能直接删掉保证结论成立的假设。

沈读与文简分工独立：文简改稿，沈读在改稿后重新从头顺读；不得以“文简已润色”代替审核。未消除的理解阻塞可否决语言放行，郑核不能绕过。教授仍核技术正确性，柯验仍核数字，陆阅仍核整课节奏与负荷。

终稿完整顺读后才更新记忆：课程ID/标题、终稿SHA256、阅读日期、已理解概念及所在小节、仍未学/易混点。只登记本次实际读到并解释清楚的内容，不把已发布课程表当作学会清单。前置假设与实际已读分列；不模拟遗忘、不借记忆扩充本课先修。返修改变讲解顺序或概念时，重新顺读并追加版本记录。用户指出问题时保留旧记录并修正，不把审核通过冒充用户认可。

## 接入 Phase 1–4

Phase1明确主线、选读和第一次出现的概念；Phase2文简改表达，学生反馈后重改；Phase3沈读按上述顺序审终稿，在“体验与脉络”组记录问题和重读证据；Phase4需语言放行及终稿记忆。沿用数值、锚点和构建门槛，不把这些过程话语放进课程正文。此次CLASSIC-01是待用户精读的试点，其余存量润色须等用户确认方向后按计划逐课开展。
