# W08：轻量MDX扫描器的数学不等号误判

MATH-11首次源码含7个JupyterNotebook，extractNotebooks只有6个，严格nb-cells只执行6个且报PASS。display公式P(a<X\le b)中的<X被scanMdx当成大写JSX标签起点，吞掉其后的CDF实验。该语法在数学环境合法，公共扫描器应识别数学语境，不应靠作者空格保证工具覆盖。

本课将数学排版改为P(a < X\le b)，提取恢复7个；原生kernel、浏览器与真实生产DOM都要核七个，固定验收脚本断言7，解除本课覆盖阻断。scanner-count.json对最终正文内存替回原写法复现7对6，nb首次6实验输出保留。未改公共解析器，旧课程不受本次修改影响。

后续：独立工作包为scanMdx增加数学上下文识别，补正/负夹具；审计全仓原始Notebook标签、AST/真实MDX渲染与轻量扫描数量差异，确认没有遗漏实验。预期合法a<X数学不能吞Notebook，真实JSX仍正确识别；跑nb-cells/verify/glossary及相关回归。W08尚未完成，不能因本课排版规避而勾已修。

归因三字段：本该拦住的角色为秦构（实验逐字/实跑覆盖）；拦截缺口是提取与校验共用同一轻量扫描、没有对原始标签数和真实渲染数做独立覆盖比对；本课补固定七项计数、原生/Pyodide全量及生产七模式核对，公共扫描器/全仓夹具审计仍交W08。
