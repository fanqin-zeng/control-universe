# 自适应失配实验的数值敏感性

NONLINEAR-08第4组第6cell故意破坏匹配条件。原生与Pyodide在打印0.01s精度下停止时刻同为15.20/41.08s，但停止前最后记录的K不同：第一例分别[4811.548,−10546.409]和[3393.387,−7650.316]；第二例[−281.619,−4684.749]与[145.650,−6899.278]。两环境完整输出保留在reconciliation-before.json、pyodide-before.json以及最终报告。

这不是普通舍入误差可接受的定量复现，因此最终validator对该cell单列原始数值，不把其K末值纳入正常容差；仅核停止事件在已声明打印精度一致。正文没有断言这些末值，并明确它们不用于定量比较，也不把阈值触发当连续时间必失稳证明。其余数值仍逐项比较，不整体放宽容差。

后续W14：保留当前源和模型，增加独立高精度/刚性积分器、步长层级及阈值层级，在数值逃逸前比较轨迹和实际Lyapunov余项；检查模型确有不稳定轨迹还是显式RK4在快速自适应参数下先失效，再决定是否可以提出物理失稳结论。不得将这些教学失配配置推广成所有不匹配自适应系统的结论。

当前课程已修正原不当推论，常参数匹配定理、原始实验资产及其余数值不依赖上述末值；W14是扩展数值解释的待办，不可预填完成。
