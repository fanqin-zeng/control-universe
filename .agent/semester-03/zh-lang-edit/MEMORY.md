# 润色工作记忆

> 跨课、跨会话积累的润色经验。每条附最多2个具体例子。详细规则见 HANDOFF §7。

## 用户批阅提炼的规则（来源：complains/MATH-01-complains.md，2026-10-19）

### 1. 动词搭配要符合中文习惯

中文有固定的动宾搭配，不能按英文直译。

- MATH-01："它这一刻开得多快" → "这一瞬间的速度"。车是"开"的没错，但"速度表告诉你它开得多快"这个句式本身就是英语 "the speedometer tells you how fast it's going" 的直译。

### 2. 不要回答读者没问的问题

前文没出现的东西不要突然提；读者没产生的疑问不要提前解答。

- MATH-10（待润色时补充）

### 3. 举例必须落到具体数字

说"比如"就要给具体数字，抽象举例等于没举。

- MATH-01 批阅4：用户示范改写——"比如记下 $t=0$ 和 $t=2$ 的位置 $s(0)=0$ 与 $s(2)=4$，那么显然我们能知道小车在0~2秒内的平均速度是 $(4-0)/(2-0)=2$ m/s"。旧稿只说"例如记下相隔一秒的两个位置，用走过的距离除以一秒"，没有数字。

### 4. 没有信息量的句子删掉

删掉后读者不缺任何东西的句子，就不该存在。

- MATH-01 批阅5："微积分研究的正是这两件事……它们并非互不相干……"——主语歧义、信息量为零。整段删除。
- MATH-01 批阅15："每一步只用了平方展开和约去公因子"——读者只关心懂没懂，不关心操作清单。

### 5. 不要俯视读者

读者不是小学生，不需要解释他们显然知道的东西。

- MATH-01 批阅12："s(2)不是s乘以2"——高中生知道函数记号。
- MATH-01 批阅11："函数是把输入对应到输出的规则"——高中生知道函数。

### 6. 术语首次出现要就地解释

自造或生僻名词在引入处挂名，不要裸用。

- MATH-01 批阅14："差商"裸用 → 改为"看 $t=2$ 附近的平均速度——这个量有个名字，叫**差商**"。

### 7. 不要替读者规划阅读路径

教好你该教的，读者自己决定怎么学。

- MATH-01 批阅10："你可以先学到……再接着学……"——整句删除。

### 8. 语气要给人入口，不要划界限

工具介绍要邀请，不要免责声明。

- MATH-01 批阅9：旧稿"Python用来核对结果，不是必学内容" → 用户改写"后文可能会用到Python代码来辅助理解，这是一种现代非常通用的语言（至少是2026年前后），若有余力，可以试着随便改改代码，对加深印象会有帮助。"

## 润色中发现的问题

### 9. 元叙述（告诉读者"后文会讲"）

读者不关心你的教学安排，他只需要现在理解这个词。

- MATH-01 L184："收敛（趋近一个确定的有限值，**这个词后文还会正式见到**）" → 删"这个词后文还会正式见到"
- MATH-01 L357："可以先理解为复数的大小，**下一课会讲**" → 删"下一课会讲"

### 10. 替读者规划路径（"为下一课做好准备"）

教好你该教的，读者自己决定怎么学。

- MATH-01 L385："把它们学扎实，就为下一课做好了准备" → 整句删除

### 11. "告诉你"是教案口吻

教学文本不需要反复说"告诉你"——直接给信息就行。

- MATH-01 L13："秒表能**告诉你**它在每个时刻的位置" → "秒表能**记下**它每个时刻的位置"
- MATH-01 L44："**它们**还没有**告诉我们**" → "仅凭这两个平均速度，还看不出"

### 12. 模型B的教训：按清单修复 ≠ 内化原则

模型B逐条处理了用户的25个批阅点，但没有把批阅背后的写作原则推广到全文。结果：具体批阅点修了，但同类问题（元叙述、替读者规划路径、教案口吻）在其他地方仍然存在。**润色不是grep，是通读后按原则找所有同类问题。**
