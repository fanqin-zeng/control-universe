# CLASSIC-01润色试点经验（待用户精读）

这些是本轮改稿发现的可复用经验，不代表用户已认可试点。用户反馈继续追加；其它课尚未润色。

1. 不是把难词换短就够了。把“约化/输入初值失配”改成“忽略电感后，启动电流从0变成模型给出的1A”，读者才知道问题是什么。
2. 公式可以保留，出现顺序要改。先解释静止位置、点号、弹簧和阻尼，再列方程与定义阻尼比；交互图的术语也要算首次出现，不能让控件抢跑。
3. 初值说明服务当前问题。建模课用“已经充电的电容仍会驱动电流”解释给初值的必要；不在这里绕进叠加原理的固定初态例外。
4. 限制条件应帮助判断。电机简化导致启动电流不同值得保留；“不作求解器排名”这类并未发生的争论不必常驻正文。求解器配置留在对应选读实验，验收数与构建设置放档案。
5. 选读不等于藏起来就算润色。跨领域材料保留，但展开后仍须解释符号、对象和新术语；答案也要审核，不能用“全阶/约化”把前面费力解释的东西又缩回黑话。
6. 页面不向学习者汇报维护状态。前置课程只帮助导航，运行框只在有操作状态时反馈；技术结果与语言体验分开记录。
7. 沈读记忆只记实际读懂的内容，不把数学18课的交付状态当成已学；用户确认独立留空，才能避免“自己改、自己审、自己说用户满意”。

8. 精确输出与教学读数分开。首次理解回弹不需要七位小数；正文保留适当有效位，精确值留原实验。改动位置后还要重查“开篇图/上式”等指代，不能只检查公式和术语。
