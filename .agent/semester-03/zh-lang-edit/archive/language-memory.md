已理解（限定到本课实际解释的程度）：

1. 从按下车身松手的问题出发，选向下为正、静平衡为零；增量坐标只记录离原位多远。点/两点分别表示速度/加速度。
2. 弹簧看两端位移差，阻尼看相对速度；质量/刚度/阻尼系数与单位，牛顿第二定律列式；反作用力不重复加到同一物体。
3. 输入与初始条件的区别：自由释放、恒力与支座移动回答不同问题；机械能与耗散功率，J与W不同。阻尼比/欠阻尼/临界/过阻尼与自然频率的本例含义。
4. 选读：双物体分别列式，再用矩阵收集系数；对称性来自本例元件，不推广到所有机械系统。
5. 角位移/角速度/力矩/转动惯量与扭转弹簧；没有的元件不因方程形式相似而添加。
6. RLC元件关系、电容电压与电流初始条件；电荷坐标与电压坐标换元；力—电压类比不改变单位。
7. 电机电压—电流—力矩与反电动势，保留电流/转速两式；忽略电感会改变启动电流。稳态转速与时间常数仅掌握本课说明的含义，不记为已掌握一般一阶响应理论。
8. 单位、能量、极限、平衡、独立数值与真实数据验证各自作用；简化须针对所关心量和允许误差。
9. 选读：热容/热阻/散热与集总模型、Biot经验条件；液压压差/流量/压缩存储与删压缩后的额外阻尼；辐射平衡与附近时间常数必须对应同一工作点。
10. 选读：LV增长/捕食/死亡、正数量平衡、首次积分与闭轨不自动吸引；SIS易感→感染→易感、恢复流与基本传播数；反应釜进出料/反应与换热；库存收支和价格行为假设不同。
