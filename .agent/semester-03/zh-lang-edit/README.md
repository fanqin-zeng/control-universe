# 学期3中文课程润色交接

本目录交给负责中文表达的模型使用。任务是把课程写成初学者能逐步学会的中文教材，而不是百科条目。你本身就是编辑，不需要虚构角色、开讨论会、写Phase 1–4日志，也不需要维护角色学习记忆。过程只需在本目录留下每节课的实际润色记录。

## 开始前

1. 读本README、[完整计划](PLAN.md)、[逐课记录模板](RECORD-TEMPLATE.md)，再读用户指定课程及其先修。PLAN列全205课，按学期3原生产顺序；当前40课生产完成，未完成课程先等正文生产完成，不替它们新写内容。每次只处理一节小课。
2. 使用专用分支 `codex/semester-03-zh-lang-edit`。先检查分支和工作区，用户已有改动不要提交、覆盖或清理。普通开发在master进行；本分支可以长期保留。不要在master直接交付新的润色结果。
3. 如需同步master，先确认工作区干净，再合并最新origin/master；冲突逐处核对，不用整文件覆盖。不得重置、强推、改写历史。新课程的生产状态应参照全局checklist更新，不能凭catalog旧版交付状态判断。

## 怎么润色

- 始终把读者当作第一次学习本课的人。承认人的理解能力和阅读速度有限：一段推进一个问题，先给具体情境，再解释概念，最后引入符号和公式。不要把材料齐全当成教学完成。
- 使用当代中文母语者常用的句式，主语、对象、原因和结果说清楚。少用抽象名词串和作者自创的缩写说法；可以有自然的小玩笑，不为搞笑而打断讲解。
- 从头顺读整篇，包括图注、交互控件、公式前后、代码说明、习题与答案。每遇到一个新术语或符号，检查读者在此之前是否知道它；不能用后文解释来替前面的缺失开脱。先修只作明确假设，不假装所有领域术语都已学过。
- 先问一句话帮助读者理解什么。删去或移走没有教学作用的自我辩护、验收声明、维护信息和无关例外；不能为了句子短就删掉结论成立的必要条件。需要的条件就近解释，较长拓展可以标为选读，但展开后仍要讲明白。
- 不要只做同义词替换。例如“跨结构优劣排名”“通道与取舍”没有明确对象，应说清具体在比较什么、改变了什么、会付出什么代价；讲非线性叠加失效时，不要突然绕进固定非零初态的线性系统例外；“最短的反例”应直接展示例子并讲它说明什么。
- 页面不应向学生报告“已交付”“目录未登记前置依赖”或默认实验已验收等内部状态。共用界面这些提示已在37e9b15清理；仍有冗余请记录位置，跨课程公共组件改动先向维护者说明，避免批量影响。
- 数值显示用足以支撑理解的精度，精确计算可留在实验；保留单位、符号和结论边界。图、公式、算例、实验、习题不能因难写而直接消失，确需迁移时记录去向和理由。

## 范围与最低核验

本任务以语言和讲解顺序为主，不自行更改数学模型、公式含义、代码算法、参数、数值答案、组件默认值、先修或章节结构。发现技术疑点，记录原文、理由与建议，请维护者处理；不要用语言润色掩盖技术变更。

保留MDX有效语法、原H2/小节与旧锚点、链接、组件引用和Notebook代码。展示公式的开闭 `$$` 必须各自独占一行。修改内容后至少检查diff，顺读终稿，并执行 `npm run check`；涉及页面执行 `npm run verify -- <chapter>/<lesson>`（开发服务通常8080，按当前服务配置核验）。涉及构建时执行 `npm run build`。写明实际命令、结果和未运行原因，不编造通过。未能执行的浏览器实验、Python源指纹/支持清单刷新等，明确留给维护者；源变更后不能沿用旧指纹声称新稿已实测。

## 每课如何留记录

复制RECORD-TEMPLATE到 `records/<课程ID>.md`，写明起始提交、改动位置与原因、关键前后对照、首次术语与顺读问题、资产保留情况、实际检查和待确认问题。返修追加版本，不覆盖用户反馈或捏造验收。记录在目录内即可，不另写角色讨论日志。

PLAN中的该课状态改为“修改中”，提交完成后改为“待合入”，附记录链接。一次提交对应一节课，正文、记录和计划一起提交，只包含本课及明确授权文件。可推送专用分支，提交或推送绝不等于已合入master。

## 合入规则：只在用户发话后

另一模型不要自行合入master或发布GitHub Pages。用户明确告知维护Agent需要合入后，维护Agent才检查本轮diff：范围、中文可读性、首次解释、无无关说明、数学/代码/锚点未误改；执行适当的目录与单课页面检查，必要时补实验/指纹和构建。发现问题就留记录、修正或向用户说明，不能无条件合并。

审核通过后将用户指定的提交范围合入master并推送，记录真实提交和用户授权，将对应状态改为“已合入”。长期分支保留。只合指定成果，不能顺带带入尚未授权课程；分支有混合成果时先挑选指定提交。Pages发布另需用户授权。
